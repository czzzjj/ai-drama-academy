# DR-21 · 找错：五句反馈的处理方案

> 难度：★★★ ｜ 素材类型：人类反馈原话 + 生产 agent 的处理方案 ｜ 建议用时：30 分钟
> 作答规则见 [`60-casebook/drills/README.md`](README.md)：只读本文件作答，作答完成前不得打开答案文件。允许对本文件运行 `50-rubrics/scripts/` 中的任何脚本取证。
> 题面素材是学院按真实生产情境构造的训练素材；五句反馈是委托方档案中人类主创的原话（逐字），处理方案为构造。

## 现场

- 前三集的打斗段落（BOSS 战）被人类主创打回，先后留下下面五句反馈。人类主创只给这一句话，不做解释。
- 生产 agent 为每句话各写了一条处理方案，准备照做。

## 素材：反馈与处理方案（原样）

| # | 人类原话 | 生产 agent 的处理方案 |
|---|---|---|
| ① | 「无电影级运镜」 | 每镜加 2 个以上专业运镜词（dolly in / orbit / crane up），把固定镜头数降到 0 |
| ② | 「苏晓冲击镜头过于耿直，没有运镜和合理的打斗逻辑」 | 冲击镜头加环绕运镜；动作从"冲刺 + 劈砍"增加到"冲刺 + 翻滚 + 旋身 + 劈砍 + 回旋踢" |
| ③ | 「几乎没有做 BOSS 打斗」 | 提示词加 `an epic, intense boss fight with lots of action`，打斗镜头数从 3 个加到 8 个 |
| ④ | 「全是几个简单动作的慢镜头」 | 动作幅度调大：每个动作写 `powerful, dynamic, large movement` |
| ⑤ | 「片段式、剧情跳跃、无法理解」 | 镜头之间加转场特效（闪白、甩镜），开头加一张字卡交代前情 |

## 你的任务

这五条方案都是把人类的**设计层**用词当成了**参数层**指令。请逐句重新翻译：

1. 写出每句话的设计层释义：人类真正在说哪个维度的什么问题。
2. 为每句话提出 **2 个可检验的假设**，每个假设配一个最小 A/B 样：固定什么、只变什么、怎么判（人类二选一 / 冷观众复述 / 可数的画面事实）。
3. 指出原方案会造成什么新问题。
4. 写出 A/B 结果出来之后怎么沉淀，避免下次再问同样的问题。

请输出：①根因（分条）②修正方案（可直接执行）③应新增的判据
