# DR-11 答案 · 对白容量物理约束（结构性缺陷被当成随机缺陷）

> 题面：[`60-casebook/drills/DR-11.md`](../DR-11.md) ｜ 对应案例：**D3**（主）；P9、M5（设计阶段核算）、P7/M10（三方台词对账）、T-2（7.5 字/秒、帧网格）
> 训练技能：[`20-craft/script-doctor/SKILL.md`](../../../20-craft/script-doctor/SKILL.md)、[`20-craft/storyboard-long-take/SKILL.md`](../../../20-craft/storyboard-long-take/SKILL.md)、[`20-craft/video-prompting-h3/SKILL.md`](../../../20-craft/video-prompting-h3/SKILL.md)

## 标准答案

### ①根因（分条）

1. **台词装不下这一镜**：36 个可发声字 ÷ 7.5 字/秒 = 4.80s，加 3 处停顿（一字一顿）1.80s 与换句气口 0.30s，台词本身就要 6.90s；7.29s 只剩 0.39s 表演留白（判据要求 ≥1s）——`dialogue_capacity.py` 报 `D3-margin`〔委托方实证·D3、T-2〕。
2. **一字一顿句被严重低估**：按模型 4 字 + 3 顿估 2.33s；委托方实测一字一顿句约 6.5s。按实测上界代入，本镜需约 12.07s → 吸附到 12.25s（294 帧）〔委托方实证·D3〕。
3. **规划语速用错了**：7.5 字/秒是塞得下的**硬上限**，不是好听的语速；自然语速约 4.1 字/秒，按它算本镜需 11.88s〔学院立场·[`00-orientation/evidence-reconciliation.md`](../../../00-orientation/evidence-reconciliation.md) R3；外部调研·F-ZEN-05〕。另外对白镜实际比计划长 1.5–2.5s（开口延迟 + 说完）〔外部调研·F-ZEN-06〕——seed 3 开头"月升之前"缺失符合开口延迟/片头截断的特征〔外部调研·F-H3-24〕。
4. **随机缺陷与结构性缺陷没分清**：3 个 seed 各缺**不同**的句子 = 容量不足的典型特征——每个 seed 只是在"超载"里随机丢掉不同部分。换 seed 无解〔委托方实证·D3〕。说话节奏主要绑在 seed 上，所以"先换 seed"对随机缺陷是对的〔外部调研·F-H3-19〕，但第 3 个 seed 仍缺就必须停。
5. **返工计划三条全错**：继续抽 seed（结构性缺陷靠运气）；加 `speaks quickly`（硬塞，表演没有呼吸，且 7.5 已是上限）；时长不动（把整集时长放在台词完整性之上）。
6. **容量没在设计阶段核算**：镜长在分镜阶段就定成 7.29s，没有"镜长 ≥ 台词时长 + 留白"这道闸门；问题拖到生成后才以缺句的形式暴露〔委托方实证·D3、P9〕。

### ②修正方案（可直接执行）

按处理顺序：删字 → 拆到听者反应镜 → 延长（≤15.08s）→ 拆镜。本题推荐**拆镜**（一字一顿是表演重点，值得单独一镜）：

1. **方案 B（推荐）：一人一镜**

| 段号 | 镜号 | 时长(s) | 拍数 | 内容 | 运镜 | 运镜因果 | 起始帧方位 | 对白 | 短镜理由 |
|---|---|---|---|---|---|---|---|---|---|
| SEQ-03 | SHOT-014 | 8.00 | 2 | 殇月俯身压低声音警告→苏晓不动，只抬起眼 | 缓推 | 因为殇月压近，所以推近两人之间的距离 | 殇月=LEFT; 苏晓=RIGHT | 殇月：月升之前离开这座城，否则天亮时，你会和城里的人一样。 | — |
| SEQ-03 | SHOT-015 | 8.00 | 1 | 苏晓直视殇月，一字一顿拒绝，说完握紧刀柄 | 固定 | 因为这句话本身就是动作，所以不动，把注意力交给她的嘴和眼 | 殇月=LEFT; 苏晓=RIGHT | 苏晓：我……不……会……走。 | — |

   - SHOT-014：23 字，需 4.07s / 8.00s（利用率 51%），按自然语速也不赶；
   - SHOT-015：一字一顿句按实测上界 6.5s + 留白，8.00s（192 帧）；先单句试生成 1 次实测时长，用 `--stagger-sec` 回填后再定稿。
2. **方案 A：保留一镜、延长**：分镜 12.25s（294 帧）；声明 `- 尾部余量: 1.42`，提示词 `- 时长: 13.67`、`- 帧数: 328`（提示词时长 = 分镜时长 + 尾部余量，帧数取网格值），台词必须在余量开始前说完。
3. **提示词同步**：两份文档台词逐字一致；不加 `speaks quickly`；台词不放在片头 0.5s 和尾部余量区间内。
4. **跑闸门**：`dialogue_capacity.py --storyboard … --prompts …` 0 error，`D3-stagger` 已按实测处理，`D3-rushed` 已处理或在 `内容` 写明"赶词为设计（理由…）"；时长用 `h3_frame_grid.py --seconds` 吸附。
5. **出片后对账**：`transcript_reconcile.py` 三方对账 `TR-missing` 为 0；口型用 `--windows` 打印的 `lips.jpg` 第二通道确认（D5：单通道不判决）。
6. **整集时长**：多出的 ~4–9s 由剪辑消化（裁剪其他镜的静场、剪掉尾部余量），不得以牺牲台词完整性换时长。

## 常见错答（扣分）

- **"多抽几个 seed"**：结构性缺陷当随机缺陷——本题的核心错。根因 ② 不得分。
- **"加 speaks quickly / 压缩停顿"**：一字一顿是剧本要求的表演，压掉就是改剧本；且 7.5 字/秒已是上限。修正 ① 不得分。
- **"延长到 9s"**：按 7.5 字/秒模型够了，但没算一字一顿的实测上界——大概率再次缺句后"二次延长"（正是 D3 的现场）。修正 ① 只得 1。
- **"用后期配音补缺的句子"**：可作季级备选，但不回答"为什么缺"，且不解决口型。

## 哪个脚本本可以拦下

```bash
python3 50-rubrics/scripts/dialogue_capacity.py --storyboard 60-casebook/drills/DR-11.md --prompts 60-casebook/drills/DR-11.md
```

实际输出：`D3-margin`（error：台词本身 6.90s 装得下，但只剩 0.39s 留白 < 1s，需 7.90s；建议改为 12.25s / 294 帧，或删句）+ `D3-stagger`（warn：一字一顿句按实测 ≈6.5s 代入需 ≈12.07s）+ `D3-rushed`（warn：按自然语速需 11.88s），汇总利用率 108%，退出码 1——**在分镜阶段就能拦下，不需要花 3 个 seed**。
出片后：把素材 3 每行另存为 `transcripts.tsv`（`SHOT-014<TAB>文本<TAB>置信度`，每个 seed 一个文件），运行
`python3 50-rubrics/scripts/transcript_reconcile.py --storyboard 60-casebook/drills/DR-11.md --prompts 60-casebook/drills/DR-11.md --transcripts s1.tsv`
seed 1 报 `TR-missing`（error：缺「再也醒不过来」）；多个 seed 都报 `TR-missing` → 回到 `dialogue_capacity.py`，不再抽卡。

## → 装载后的行为改变

- 下次写剧本或分镜，**先**数字、跑 `dialogue_capacity.py`，**再**定镜长；镜长 = max(动作链所需, 规划语速下的对白时长 + 开口延迟 + 留白)。
- 下次台词放不下，按"删字 → 拆到听者反应镜 → 延长 → 拆镜"处理；**禁止**写 `speaks quickly` 硬塞。
- 下次缺句，第 3 个 seed 仍缺就**停止**抽卡，在 `qc/<SHOT>.md` 写"结构性缺陷：容量"。
