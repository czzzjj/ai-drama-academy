# DR-18 答案 · 补丁式迭代：修点不修面，修症状处不修病灶

> 题面：[`60-casebook/drills/DR-18.md`](../DR-18.md) ｜ 对应案例：**F3**（主）；A5④（指令矛盾）、A2、A3、A4、M2、M3、D3（随机 vs 结构性）、G1、G5
> 训练技能：[`20-craft/screening-review/SKILL.md`](../../../20-craft/screening-review/SKILL.md)、[`20-craft/production-director/SKILL.md`](../../../20-craft/production-director/SKILL.md)、[`20-craft/action-choreography/SKILL.md`](../../../20-craft/action-choreography/SKILL.md)

## 标准答案

### ①根因（分条）

**直接原因**
1. **每轮只修最新一条反馈**：反馈是抽样，不是全集。r2、r3 同期的「几乎没有做 BOSS 打斗」「全是几个简单动作的慢镜头」被记进待办，从没处理〔委托方实证·F3、A2、A3〕。
2. **补丁叠加，制造指令矛盾**：SHOT-025 现在同时写着 `Real-time speed throughout, no slow motion` 和 `a dramatic slow motion impact moment`，还写着 `The camera orbits around the fighters` 和 `The god stays on the LEFT…`。模型会执行写下的**所有**指令，指令打架它就乱编〔委托方实证·A5④〕。"公开记录的返工原因"里就有"负面补丁淹没动作"〔外部调研·S-ZEN-23〕。
3. **r4 的空间问题是 r1 的补丁造成的**：r1 加的 `orbits around` 是左右维度运镜，和起始帧"神左 / 苏晓右"冲突〔委托方实证·A5①〕。r4 只是在后面追加一句方位声明，冲突源 `orbits` 还在。「又变成……」里的"又"字，就是回归的证据。

**方法论原因**
4. **修在症状处，不修在病灶处**：四轮全改视频提示词的措辞，病灶却分别在分镜（运镜因果，A4）、事件设计（写事件不写形容词，M3）、起始帧（史诗感由画面级决定，M2）、分镜 + 起始帧（空间，A5）、动作设计（打斗、速度层次，A2、A3）。素材 3 显示：分镜、起始帧、动作设计四轮一字未动〔委托方实证·F3；[`00-orientation/production-lifecycle.md`](../../../00-orientation/production-lifecycle.md) §3〕。
5. **没有质量模型，也就没有分母**：自评表四轮空白，不知道一共有几维、还剩几维；"自评已修复"只覆盖被点名的那一维〔委托方实证·F3、G8〕。
6. **没有回归检查**：每轮 4 镜整镜换 seed 重出，会把已经合格的维度重新掷一次骰子；又从不和上一轮比较，退化维度没人拦〔委托方实证·F3；学院推断：验证法——保留上一轮已验收片段作基线，逐维两两比较，统计退化维度数〕。
7. **评价词当修复**："spectacular / breathtaking / epic / massive"渲染不出来，生成器渲染的是事件〔委托方实证·M3、G5〕。
8. **"人类每次都能找到新问题"是错误归因**：问题一直都在，只是人类每次只说最刺眼的那条〔G1〕。

### ②修正方案（可直接执行）

1. **r5 不提交、不加句。** 先把四轮所有反馈（含待办里的两条）逐字写进 `review/defects.md`，每行列：反馈原话 | 设计层翻译 | Q 维度 | 病灶阶段 | 全片同类搜索结果 | 处置 | 回归结果。
2. **8 维全量自查**：按 [`50-rubrics/quality-model.md`](../../../50-rubrics/quality-model.md) 给 SEQ-05 打分，每维附时间码；**没被点名的维度同等对待**。
3. **回病灶阶段修，按上游先修的顺序**：
   - **动作设计**：把"冲、挥、被击退、站起"重写成战术链和至少一个完整交手回合（例：苏晓佯攻右腿 → 神横扫落空 → 苏晓抓住收臂的空隙踩臂上跃 → 刀砍中石面迸火 → 神甩臂把她击飞 → 落地滑行停住）。打击拍可以密，空间拍 ≤2–3〔委托方实证·A2；学院立场 R4〕。
   - **分镜**：一镜一条完整动作链，运镜只走高度 / 距离维度，每个运镜写因果句；删除 orbit〔A4、A5、M4〕。
   - **起始帧**：史诗感在起始帧里定（低机位、尺度对比、纵深），按海报级抽卡验收〔M2、P3〕。
   - **提示词**：**从头重写，不在旧稿上叠加**。删除所有评价词和补丁句；特效写成"能量从哪来、在哪接触、怎么扩散、留下什么后果"的事件链〔M3〕；保留实时速度句，"慢"只在设计需要时写，并在元数据声明 `- 慢动作: 设计选择（理由…）`。
4. **重写附"改写前后回归表"**：台词、起止时长、锚点句、镜头目的四项未丢；被新设计取代的旧补丁句已删除〔外部调研·S-ZEN-23〕。
5. **全量回归**：生成前脚本全部重跑并保存 `--json`，与上一轮比较，出现新的 error 代码就不提交；重出镜与上一版并排对照，逐维写"更好 / 相同 / 更差"。
6. **处置规则**：同一症状第二次出现，禁止再"换 seed"或"加句"，必须改设计；同一维度连续 2 轮无改善，上溯一个阶段〔委托方实证·D3；外部调研·S-ZEN-24〕。
7. **交付附"已知未修问题"清单**，主动告诉人类还剩什么，不等人类抽样。

## 打分规则（满分 10）

| 维度 | 满分 | 得分点 | 部分得分 |
|---|---|---|---|
| 根因 | 4 | ①只修最新一条，两条待办被忽略（0.5）②补丁叠加 → 实时 vs 慢动作、orbit vs 定侧的矛盾（1）③r4 是 r1 的补丁引起的回归（0.5）④修在提示词，病灶在分镜 / 起始帧 / 动作设计（1）⑤没有质量模型 / 回归检查（1） | 只答"应该一次改全"不说机制 → 最多 1.5 分 |
| 修正 | 4 | ①defects 表 + 8 维全量自查（1）②按病灶阶段改，并给出具体的动作链 / 交手回合（1.5）③提示词从头重写，附回归表（0.5）④全量回归 + 处置规则（重复症状改设计）（1） | 方案仍是"在提示词里再加 / 改一句"→ 修正最多 1 分 |
| 判据 | 2 | ①defects 表必填"全片同类"和"病灶阶段"（1）②脚本全集 JSON 比对或 8 维回归（1） | — |

## 常见错答（扣分）

- **"把 r1–r4 的补丁句措辞写得更精确"**：还是在症状处修。修正②不得分。
- **"删掉 slow motion 那句就好"**：只修了一个矛盾，没碰病灶，也没处理两条待办。
- **"r5 先处理'打斗缺席'这一条"**：还是一次修一条，只是换了一条。根因①只得一半。
- **"人类标准太高 / 太善变"**：错误归因。根因⑧对应的认识缺失，根因总分最多 2 分。

## 哪个脚本本可以拦下

```bash
python3 50-rubrics/scripts/prompt_lint.py season-01/ep03/video-prompts.md --anchors season-01/ep03/anchors.md --storyboard season-01/ep03/storyboard.md --json > qc/r4/prompt_lint.json
python3 50-rubrics/scripts/direction_audit.py season-01/ep03/video-prompts.md --storyboard season-01/ep03/storyboard.md --json > qc/r4/direction_audit.json
```

- `prompt_lint.py` 对 SHOT-025 应报 `VP-realtime` error（出现未被否定的 `slow motion`，与实时速度句矛盾），以及 `VP-adjective` warn（spectacular、breathtaking、epic）。
- `direction_audit.py` 对 `orbits around` 报 `DIR-camera` error（单轴定侧下的左右维度运镜）。r1 补丁一加进去就能拦下，r4 的"又乱了"根本不会发生。
- 每轮把 `--json` 存到 `qc/r<n>/`，用 python 或 jq 比较两轮 error 代码集合（没有专用比对脚本）。
- **脚本盲区**："只修一条""待办没处理""没有全片搜同类"没有脚本能拦，靠 `review/defects.md` 的必填列。

## → 装载后的行为改变

- 下次收到任何一条反馈，**先**把它和所有未处理的反馈一起入表，归维度、搜全片、定病灶；**禁止**直接改视频提示词。
- 下次改提示词，**从头重写并附回归表**，禁止在旧稿后面追加补丁句。
- 下次同一维度两轮没改善，**上溯一个阶段**（提示词 → 起始帧 → 分镜 → 剧本 / 动作设计）。
