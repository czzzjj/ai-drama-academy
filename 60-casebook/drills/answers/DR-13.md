# DR-13 答案 · QC 工具会骗人：单通道就下判决

> 题面：[`60-casebook/drills/DR-13.md`](../DR-13.md) ｜ 对应案例：**D5**（主）；P7、M10（三方对账 / 双通道）、B1（错误重出换来的漂移）、F2（退出码当质量）、E4（采用版与提示词不一致）
> 训练技能：[`20-craft/shot-qc/SKILL.md`](../../../20-craft/shot-qc/SKILL.md)、[`20-craft/edit-and-assemble/SKILL.md`](../../../20-craft/edit-and-assemble/SKILL.md)

## 标准答案

### ①根因（分条）

**直接原因**
1. **把 ASR 在静音和环境声上的幻觉当成了"生成器加了人声"**：两个无对白镜分别转出"字幕by索兰娅""谢谢观看"，重出后又转出"请不吝点赞"。这些都是公开记录过的 Whisper 类幻觉文本，和画面内容无关，置信度 0.93 也说明不了任何问题〔委托方实证·D5 症状一；外部调研·S-COMFY-16、S-COMFY-17、S-CASE-28〕。Whisper 的默认阈值拦不住这种高置信的背诵式幻觉〔外部调研·S-COMFY-14〕。
2. **低置信、单窗口的一个词，直接判成"多出台词"**：SHOT-031 置信 0.41，剧本在同一位置写的是"低笑一声"，这正是"气声被误听成台词"的特征。没做多窗复核，也没看口型，就判阻断〔委托方实证·D5 症状二〕。
3. **工具降级之后，退出码 0 被当成了"通过"**：环境里没有 OCR，`burnin_text_scan.py` 会报 `D1-ocr-degraded`（warn），只给启发式 `visual` 条目。启发式从不单独判 error，所以退出码 0 只说明"没有可自动确认的 error"，不说明"没有文字"。3 条 visual 没人看〔委托方实证·D5、D1〕。
4. **字幕取自转写**：CUT-021 的字幕"你根本不懂"少了剧本里的"我"。字幕必须逐字取自剧本，转写只用来定位时间、查缺句〔委托方实证·P7；外部调研·S-ZEN-26〕。

**方法论原因**
5. **没有先证伪工具，就开始改产出**：顺序反了。先确认"工具说的是不是真的"（音轨里有没有人声能量、画面上有没有张嘴），再决定要不要重出〔委托方实证·D5 修正〕。
6. **单通道判决**：QC 结论只有转写这一个通道，没有抽帧或听感做第二通道〔委托方实证·D5 判据、M10〕。
7. **循环对账**：用转写生成字幕，再拿字幕去对转写，"100% 一致"是同一来源自己对自己，证明不了任何事。真正该对的是剧本 ↔ 提示词 ↔ 转写三方〔委托方实证·P7、M10〕。
8. **为一个假缺陷换来真缺陷，还做了全集推广**：SHOT-009 淘汰了画面最好的 seed 1；SHOT-031 接受了殇月脸型漂移，这是阻断缺陷（[`50-rubrics/definition-of-done.md`](../../../50-rubrics/definition-of-done.md) §3）〔委托方实证·B1〕；还准备给 6 个已验收的镜加"no voice"补丁后重出，会把已经合格的维度重新掷一次骰子〔委托方实证·F3〕。

### ②修正方案（可直接执行）

1. **立刻撤销队列**里那 6 个无对白镜的重出任务；全集撤回"no voice"补丁。
2. **SHOT-009 / SHOT-014 先证伪工具**：`ffprobe` 确认有没有音轨；`ffmpeg -i <clip> -af volumedetect -f null -` 量能量；听一遍；看接触表有没有人张嘴。若没有人声，就判为 ASR 幻觉，**恢复 seed 1**（画面最优，提示词回到产出 seed 1 时的那一版，保证提示词与采用版一致，E4），在 `qc/SHOT-009.md` 写清证伪过程。
3. **SHOT-031 做多窗复核 + 口型**：跑 `transcript_reconcile.py --windows`，按它打印的命令生成 3 个时间窗的转写和口型接触表 `lips.jpg`。若 3 窗互斥、置信都低、口型闭合，就判为误听〔D5 原判定〕。**恢复原采用版本**；seed 7 因脸型漂移判不通过。
4. **烧录文字补第二通道**：打开 `qc/burnin/*.burnin-strip.jpg`，逐条看那 3 条 visual；或装 OCR 后端（rapidocr 等）重跑。QC 报告写明"OCR 降级：是/否"。
5. **字幕重建**：剪辑单 `字幕` 列全部从 `storyboard.md` 的 `对白` 列逐字复制。SHOT-018 缺不缺"我"，按三方对账 + 多窗 + 听感判定：确实缺 → 跑 `dialogue_capacity.py` 核容量。容量不足属于结构性缺陷，回分镜延长镜头或删字，不换 seed（D3）。
6. **改日报模板**：每条结论都写两个通道的证据文件名；没有第二通道证据的，只能写"待复核"，不能写"阻断"。

## 常见错答（扣分）

- **"给无对白镜加 `no voice, no speech` 就好"**：这是在修一个不存在的缺陷，还会给已验收的镜带来回归风险。
- **"0.93 是高置信，说明确实有人声"**：幻觉文本恰恰常以高置信出现（S-COMFY-14、S-COMFY-16）。根因①只得 0.5。
- **"seed 7 脸型偏差可以接受，台词优先"**：身份漂移是阻断缺陷，为一个假缺陷付出真代价。根因⑤不得分。
- **"字幕取转写能保证声画一致"**：转写会丢字、会幻觉。字幕的事实来源只有剧本。

## 哪个脚本本可以拦下

```bash
python3 50-rubrics/scripts/transcript_reconcile.py --storyboard season-01/ep03/storyboard.md --prompts season-01/ep03/video-prompts.md --transcripts qc/transcripts.tsv --windows --video-dir season-01/ep03/assets/clips
python3 50-rubrics/scripts/burnin_text_scan.py season-01/ep03/assets/clips/ --out-dir qc/burnin --json
```

- `transcript_reconcile.py` 对这份转写应报：SHOT-009 / SHOT-014 `TR-unscripted` 和 `TR-hallucination`（"字幕by索兰娅""谢谢观看"都在内置的已知幻觉表里）；SHOT-031 `TR-extra` 和 `TR-lowconf`（visual）；SHOT-018 `TR-missing`。它不会给出"重出"结论，只会写"需第二通道证据确认后再判"。
- `burnin_text_scan.py` 在无 OCR 环境下报 `D1-ocr-degraded`，启发式只报 visual。**脚本盲区**：退出码 0 不代表通过，visual 条目必须有人看。

## → 装载后的行为改变

- 下次转写和剧本不一致时，**先**证伪工具（音轨能量、多窗、口型），**再**决定是否重出；单通道证据只能写"待复核"。
- 下次脚本报降级或 visual 时，**禁止**用退出码 0 写"通过"；要么补第二通道，要么在报告里写明"未验证"。
- 下次做剪辑单，字幕**只**从剧本复制；转写只用来定位时间、查缺句。
