# DR-10 答案 · 烧录字幕 + 纯黑字卡交给生成器（以及把"需目视"当"通过"）

> 题面：[`60-casebook/drills/DR-10.md`](../DR-10.md) ｜ 对应案例：**D1**、**D2**（主）；D5（工具降级时单通道不判决）、M8（禁令包）、P8
> 训练技能：[`20-craft/video-prompting-h3/SKILL.md`](../../../20-craft/video-prompting-h3/SKILL.md)、[`20-craft/edit-and-assemble/SKILL.md`](../../../20-craft/edit-and-assemble/SKILL.md)、[`20-craft/shot-qc/SKILL.md`](../../../20-craft/shot-qc/SKILL.md)

## 标准答案

### ①根因（分条）

**纯黑字卡（D2）**
1. **确定性画面交给了采样器**：纯黑底 + 精确文字 + 淡出，全是"像素已知"的内容；H3 守不住纯色，会在中段自行加字/水印（委托方实证中正是 "LAVCE"）〔委托方实证·D2〕。"风格统一、一条管线出完"不是理由。
2. **剪辑单把字卡当素材**：CUT-031 的 `来源` 指向生成的 mp4，`画面文字` 却是 `—`——文字本应由剪辑程序化叠层，结果交给了生成器〔[`70-playbooks/format-contracts.md`](../../../70-playbooks/format-contracts.md) §4〕。

**烧录字幕（D1）**
3. **禁令句不在末行**：`No captions…` 后面还接了一行 `Vertical 9:16 composition, high quality, film grain.`——禁令包位置固定为 h3 块最后一个非空行〔委托方实证·D1、M8〕。
4. **高风险组合没有当高风险处理**：竖屏 + 对白镜出字幕的概率更高；H3 社区也报告"无故出字幕"〔外部调研·S-VGEN-11、S-H3-13〕。禁令句是兜底不是保证，烧录文字永远由抽帧核验把关〔学院立场·[`00-orientation/evidence-reconciliation.md`](../../../00-orientation/evidence-reconciliation.md) R1-4〕。

**QC 结论（D5）**
5. **把 visual 当 pass**：OCR 已降级（`D1-ocr-degraded`），启发式**永远不单独判 error**——它只报 visual，要求打开条带接触图逐格看。"0 error → 无烧录文字"是对脚本语义的误读；两条 visual 恰好就是两处真实缺陷〔委托方实证·D5：单通道不判决〕。
6. **"片尾字卡文字正确"无证据**：没有对照剪辑单 `画面文字` 列逐字核对，也没看中段帧。
7. **成片 verify 全绿不覆盖文字**：渲染/响度/坏帧检查不看画面内容（代理指标，F2）。

### ②修正方案（可直接执行）

1. **SHOT-031 退出生成管线**：从 `video-prompts.md` 删除；剪辑单改为
   `| CUT-031 | local:black | 0.00 | 5.17 | — | 第二集 · 完 |`
   淡入淡出在剪辑里做；文字由剪辑程序化叠层（字体、字号、位置由剪辑参数决定）。
2. **SHOT-029 改提示词**：删除 `Vertical 9:16 composition, high quality, film grain.`（画幅由画布参数决定，不靠文字），禁令句回到末行：
   ```text
   non_diegetic_music:
     A soft guqin melody.
   No captions, subtitles, or dialogue text overlays appear at any moment.
   ```
3. **SHOT-029 重出 3 seed**，逐版扫：`burnin_text_scan.py SHOT-029_s{1,2,3}.mp4 --out-dir qc/SHOT-029`，打开 `*.burnin-strip.jpg` 逐格看。3 版都出字幕 → 按结构性缺陷查：参考图上是否有字、`<d>` 内是否有舞台提示、台词是否被重复（任何结论回写 D1 卡）。
4. **QC 结论的写法**：每条 visual 都写"已看 `<文件名>` 第 N 格：有/无文字"；OCR 降级时在记录里写明"OCR 未启用，启发式 + 目视"。有条件就装 OCR 后端（脚本按 rapidocr → paddleocr → easyocr → tesseract 自动探测），但装了 OCR 也不免目视。
5. **成片层复核**：
   - `burnin_text_scan.py final/ep02.mp4 --mode final`：OCR 检出的每段文字与剪辑单 `字幕` / `画面文字` 逐字核对，剪辑单里没有的就是生成器烧录的；
   - `psnr_scan.py final/ep02.mp4 --mode final --edit-list season-01/ep02/edit-list.md`：`local:black` 区间内的冻结应为 info `P8-freeze-designed`；
   - `loudness_verify.py final/ep02.mp4 --allow-black`（片尾黑卡为设计）。
6. **补"不交给生成器"清单**：纯色卡、精确文字（片名/字卡/招牌）、UI 面板、logo/水印、字幕、AIGC 显式标识——一律本地生成 + 剪辑叠层〔委托方实证·D2〕。

## 常见错答（扣分）

- **"在片尾提示词里加 `no watermark, no text`"**：仍然把确定性画面交给采样器；且写出不要的东西可能把它登记成内容〔外部调研·S-COMFY-08〕。修正 ① 不得分。
- **"把画面底部裁掉去掉字幕"**：破坏 9:16（成片 `loudness_verify.py` 的 `T3-aspect` 会拦下）与起始帧构图。
- **"脚本报 0 error 所以通过是合理的"**：没读懂 visual 的语义，根因 ③ 不得分。
- **"加 negative_prompt: subtitles"**：cfg=1.0 下无效（C1、T-2）。

## 哪个脚本本可以拦下

```bash
python3 50-rubrics/scripts/prompt_lint.py 60-casebook/drills/DR-10.md
```

实际输出：`VP-ban`（error：SHOT-029 禁令句存在但不是 h3 块最后一个非空行）+ 3 条 `VP-generator-unsafe`（error：SHOT-031「pure black screen」/「fades to black」、「end card」、精确文字「"第二集 · 完"」），退出码 1——**两镜都在送生成器之前就能拦下**。
出片后：`python3 50-rubrics/scripts/burnin_text_scan.py <clip> --out-dir qc/<SHOT>` 的 visual 必须逐格目视；成片用 `--mode final` 与剪辑单核对。

## → 装载后的行为改变

- 下次分镜，**先**判每一镜是"确定画面"还是"采样画面"；确定画面直接写进剪辑单 `local:` 行，不进 `video-prompts.md`。
- 下次写 h3 块，**先**写末行禁令句，再写正文；禁令句之后不得再有任何行。
- 下次脚本报 visual，**必须**打开证据图逐格看并写结论；**禁止**用"0 error"替代目视。
