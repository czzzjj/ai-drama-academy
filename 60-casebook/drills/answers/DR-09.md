# DR-09 答案 · 验收放水（"看一眼差不多" + 只复验修过的那一项 + 自己复验自己）

> 题面：[`60-casebook/drills/DR-09.md`](../DR-09.md) ｜ 对应案例：**C2**（主）；C1-7（"对比弱"被早期验收误判放行）、C1-6（方位属性）、F1（自证循环）、E4
> 训练技能：[`20-craft/asset-boards/SKILL.md`](../../../20-craft/asset-boards/SKILL.md)、[`20-craft/shot-qc/SKILL.md`](../../../20-craft/shot-qc/SKILL.md)、[`20-craft/screening-review/SKILL.md`](../../../20-craft/screening-review/SKILL.md)

## 标准答案

### ①根因（分条）

**直接原因（验收执行）**
1. **"✅ 全部具备"不是逐特征核验**：必现 4 项、禁用 4 项、方位 1 项被压成 3 行笼统结论，证据栏写"原图"——没有一条特征对应一张裁剪图〔委托方实证·C2〕。
2. **程度属性在错误的尺寸下判**：裂纹对比在"原图 200% 放大"下当然"明显"；观众看的是手机上几百像素宽的画面。对比、大小、数量类属性必须缩到观看尺寸 + 去色后仍一眼可读〔委托方实证·C1-7："黑臂对比弱"被早期验收误判放行〕。
3. **方位属性没单独核**：第 1 轮"骨角 ✅"只核了"有"，没核"在哪一侧"——锚点卡明写"需单独放大核验"〔委托方实证·C1-6〕。
4. **第 2 轮只复验修过的那一项**："其余项：同第 1 轮" 是把上一版的结论套到一张**新采样**的图上。seed 7 是全新的一次生成，任何一项都可能变——小金冠就是这样漏掉的〔委托方实证·C2〕。
5. **证据行指向的文件无法支撑结论**：证据只有火纹裁剪与一张并排图，裂纹、禁用项、骨角均无对应证据；在本题面上跑 `asset_exists.py`，三条证据路径全部报 `E2-missing-ref`——写了文件名 ≠ 留下了证据。

**方法论原因**
6. **自己复验自己**："复验人: 本会话"——同一会话带着"我生成的、我放大看过"的记忆去复验，等于没有复验。LLM 评审会偏好自己的产出〔委托方实证·C2、F1；外部调研·S-CASE-23〕。
7. **高风险资产没有分级**：BOSS 属高风险资产，应一律"裁剪特写 + 与板图并排压图对照 + 独立第二遍复验"〔委托方实证·C2〕。
8. **漏判后的反应是解释而不是补判据**："第 1 轮我确实放大看过"——问题不在态度，在判据：没有"观看尺寸判程度"这条，下一次还会放过。

### ②修正方案（可直接执行）

1. **撤回板图与已出的 4 张关键帧**（参考图与提示词必须同一事实，E4）；板图按锚点卡重做 ≥3 seed（裂纹对比写成可判读条件：`the dark-red cracks glow brightly against the black scales and remain clearly visible from a distance`；金冠追加 `no crown, bare head` 前先写正向状态 `his bare scaled head`）。
2. **先把锚点卡抄成逐项表，表没填满不写结论**：

   | 检查项 | 结果 | 证据 |
   |---|---|---|
   | 禁用 no crown | | `qc/CHR-YANJUN-BOARD/s4/crop-head.png` |
   | 禁用 no jewelry at all | | `…/crop-neck.png`、`…/crop-hands.png` |
   | 禁用 no cape | | `…/crop-back.png` |
   | 禁用 no second horn | | `…/crop-shoulders.png` |
   | 必现 哑光黑鳞甲 | | `…/crop-chest.png` |
   | 必现 暗红细裂纹（程度） | | `…/view-270-gray.png`（观看尺寸 + 去色） |
   | 必现 额头单道竖直火纹 | | `…/crop-crest.png` |
   | 必现 弯骨角 ×1 | | `…/crop-shoulders.png` |
   | 方位 骨角在画面右侧 | | `…/crop-shoulders.png`（结论用画面坐标） |

   静帧裁剪放大：`ffmpeg -i CHR-YANJUN-BOARD.png -vf "crop=500:400:600:300,scale=iw*4:ih*4:flags=neighbor" qc/CHR-YANJUN-BOARD/s4/crop-head.png`
   观看尺寸 + 去色：`ffmpeg -i CHR-YANJUN-BOARD.png -vf "scale=270:-2,format=gray" qc/CHR-YANJUN-BOARD/s4/view-270-gray.png`
   与板图并排：`ffmpeg -i old.png -i new.png -filter_complex hstack qc/CHR-YANJUN-BOARD/s4/side-by-side.png`
3. **每一版都全量重核**：返工后从逐项表第一行开始重核，**禁止**写"其余同上一版"。
4. **独立复验**：开一个新会话，只给它板图、锚点卡与逐项表模板，不给生成提示词、不给首验结论；`复验人` 填该会话标识与日期。独立复验完成前结论只能写"有条件通过（待复验）"，不得放行到关键帧阶段。
5. **证据落盘检查**：结论写完后跑 `asset_exists.py qc/`，任何 `E2-missing-ref` / `E2-empty-asset` 即结论无效。
6. **漏判回流**：把"程度属性按观看尺寸判""返工后全量重核"补进 board 清单，并把本例写成新的找错题回流题库（F4 训练回路）；没亲眼核过的项写"未验证"，不打 ✅。

| 维度 | 满分 | 得分点 | 部分得分 |
|---|---|---|---|
| 根因 | 4 | ①笼统 ✅、无逐特征证据（1）②程度属性在放大状态下判（1）③第 2 轮只复验修过的一项（1）④自己复验自己（0.5）⑤方位只核存在不核侧（0.5） | 只说"验收不仔细" → 0.5 |
| 修正 | 4 | ①逐项表 + 每行裁剪证据（1.5）②观看尺寸 + 去色判程度（1）③返工后全量重核（0.5）④独立会话复验 + 有条件通过（1） | 只给"再认真看一遍" → 0 |

## 常见错答（扣分）

- **"这次放大到 400% 再看"**：放得越大，对比越"明显"——方向反了。根因 ② 不得分。
- **"第 2 轮的金冠是随机出现的，重出就好"**：漏判的原因是没核，不是运气。根因 ③ 不得分。
- **"复验时更仔细一些"**：同一会话复验 = 自证循环（F1）。根因 ④ 不得分。
- **"补上缺失的证据图"**：补图之前得先有逐项表——证据要逐条对应检查项，不是凑文件。

## 哪个脚本本可以拦下

```bash
python3 50-rubrics/scripts/asset_exists.py 60-casebook/drills/DR-09.md
```

实际输出：3 条 `E2-missing-ref`（error：`qc/CHR-YANJUN-BOARD/crop-crest.png`、`side-by-side.png`、`r2-horn.png` 不存在），退出码 1。真实项目中对 `qc/` 目录跑：`python3 50-rubrics/scripts/asset_exists.py qc/`。
**脚本盲区**：它只证明"文件在、非空"，不证明"证据覆盖了每一条特征"，更不判断对比够不够——逐项表是否填满、程度属性是否在观看尺寸下判、复验人是否独立，只能 [目视]。

## → 装载后的行为改变

- 下次写验收结论前，**先**把锚点卡每一条抄成逐项表、每行附一张裁剪图；表没填满不写结论。
- 下次验收对比/大小/数量，**先**缩到观看尺寸再去色判；**禁止**在放大状态下判"够不够"。
- 下次验收返工版，**从第一行全量重核**；**禁止**写"其余同上一版"。
- 下次高风险资产过关后，**开独立会话复验**；复验前只能写"有条件通过（待复验）"。
