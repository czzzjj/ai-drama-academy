# 核心记忆（core-memory）

> 写入方法、分级与更新政策见 [`40-memory/README.md`](README.md)。一行一条，逐字写入长期记忆；与 [`00-orientation/evidence-reconciliation.md`](../00-orientation/evidence-reconciliation.md) 冲突时以后者为准，并在同一次提交里改这里。
> 标注口径：「为什么」里凡外部来源写〔外部调研·S-…/F-…〕，凡未经生产实证写〔学院推断〕；其余为委托方实证。

## Top-12（开工必装；任何阶段、任何技能都先遵守）

- [MEM-01][质量] 交付前必须过外部视角三件套：自我放映、冷观众、独立会话对抗评审；自己的清单全绿只证明 L0。（为什么：check/render/verify 全绿、响度达标，人类主创仍连续多轮打回）〔溯源：F1, F2, T-4〕
- [MEM-02][质量] 每轮迭代先按 Q1–Q8 全维度自查再动手，禁止只修最新一条反馈；每条反馈先定位它属于哪一维、病灶在哪个阶段。（为什么：r1→r5 每轮只修一条，修好一个暴露另一个，每轮都「仍不够」）〔溯源：F3, G1〕
- [MEM-03][交付] final-report.md 第一节必须是 L0–L3 交付声明，缺证据的级别写"未验证"；只有 L0 证据时只能写"技术合格（L0），观感未验证"，全文禁止出现"达标/可发布/质量通过"（R-CUT-16）。（为什么：代理指标全绿 ≠ 观感达标，G8 要可操作的达标定义）〔溯源：F1, F2, G8〕
- [MEM-04][分镜] 生成单位（镜）必须 ≥124 帧（5.17s）并承载一条完整动作链；段 8–15s、每镜空间拍+表情拍 2–3；快剪只在剪辑单里从长镜取 CUT，短剪不是罪、碎镜症是罪。（为什么：29 镜均长 2.96s →「片段式、剧情跳跃、无法理解」）〔溯源：A1, P10, M1, T-2〕
- [MEM-05][空间] 轴线由起始帧钉死：相机只做高度与距离运动，删掉 truck/arc/orbit/weave；宽景用画面位置称呼（the god on the LEFT）；direction_audit.py 0 error 才算提示词定稿。（为什么：r4 复审「又变成苏晓乱跑」，r5 单轴定侧后达标）〔溯源：A5, M4〕
- [MEM-06][关键帧] 画面级（构图/方向/光/史诗感）只在起始帧里定：按海报标准多 seed 抽卡+逐特征验收，不过关不放行到视频；禁止靠提示词文字救构图。（为什么：委托方实证文字救不了构图；同 seed A/B 文字空间地图压不过场景图〔外部调研·S-H3-09〕）〔溯源：P3, P4, M2, S-H3-09〕
- [MEM-07][对白] 设计阶段按规划语速 ≈4.1 字/秒排时长（超→warn 赶词），7.5 字/秒是硬上限（超→error 必缺句），再加开口延迟与表演留白；同镜换 seed 缺不同句 = 结构性缺陷，改时长或拆镜，禁止继续抽卡。（为什么：先 7.5s 缺句，按 4.34s+约 6.5s 重算、11s 重产才齐；规划语速来自 20 次同镜实测〔外部调研·S-ZEN-17〕）〔溯源：D3, P9, M5, S-ZEN-17〕
- [MEM-08][提示词] 送 H3 前 prompt_lint.py 必须 0 error：声明模式并用对应方言、末行固定 `No captions, subtitles, or dialogue text overlays appear at any moment.`、动作镜写 `Real-time speed throughout, no slow motion`、无配乐写 `non_diegetic_music: N/A`。（为什么：生成器自行烧字、默认慢动作、自配泛用配乐；末行禁令只是兜底，烧录文字仍靠抽帧核验）〔溯源：D1, A3, M8, F-ZEN-07〕
- [MEM-09][资产] 关键资产三件套：锚点句 EN 逐字进每条提示词 + ≥3 seed 抽卡 + 逐特征放大裁剪验收；方位类属性单独放大核验；验收记录必须附裁剪/对照证据，禁止只写"通过"。（为什么：尼加狄黑臂对比弱被早期验收一眼放行，复验才查出）〔溯源：P1, P2, M6, C1-7, C2〕
- [MEM-10][验收] QC 结论必须双通道（转写 + 抽帧/听感），单通道不判决；低置信词多窗复核；字幕永远逐字取自剧本，转写只用于定位时间与查缺句。（为什么：无对白音轨被转出幻觉文字，低笑气声被单次转写误听为"救我"，多窗复核后判误听未重出）〔溯源：D5, M10, P8〕
- [MEM-11][回流] 任何缺陷先开缺陷单、回流到病灶阶段（剧本/分镜/板图/关键帧/提示词/剪辑）修，禁止在下游打补丁；换 seed 前先判随机缺陷还是结构性缺陷。（为什么：只修点不修面永远修不完；对白缺句换 3 个 seed 都无解）〔溯源：F3, D3〕
- [MEM-12][合规] 发布前第一步跑合规表（AIGC 显式+隐式标识、剧名与编号、H3 地域与商用授权、Qwen-Image-2.1 许可、配乐许可）；任一"未确认"即上报人类拍板点④，agent 禁止自行发布。（为什么：委托方从未发布，全部依据是外部调研且不构成法律意见〔外部调研·S-PLAT-01、S-H3-14〕）〔溯源：GAP-1, S-PLAT-01, S-PLAT-02, S-H3-14, S-COMFY-02〕

## 质量与交付（L0–L3）

- [MEM-13][学习] 每学一条方法，必须配一次找错题（DR-01–DR-22）或练习并用脚本/评审打分，通过后才写入记忆。（为什么：装了 7 个导演/运镜/分镜技能、嵌满 primitives 句式，质量没有质变）〔溯源：F4, G3〕
- [MEM-14][质量] 代理指标（固定运镜=0、全采用、无坏帧）只当下限；人类说"没有 X"时，先问观众能否感到 X，再看指标。（为什么："固定运镜=0"全绿却被说「无电影级运镜」）〔溯源：F2, A4〕
- [MEM-15][质量] Murch 排序只用于两个好选项冲突时取舍；越轴、乱跑、身份漂移作为独立闸门检查，禁止以"情绪对了"放过。（为什么：学院立场 R7——AI 生成中 2D/3D 错误最高频且直接摧毁"看得懂"〔外部调研·S-STORY-13〕）〔溯源：A5, B1, S-STORY-13〕
- [MEM-16][交付] L1：≥3 名冷观众中 ≥2/3 正确复述主因果链，且无 ≥2 人同标的断点；找不到人类时用未见过任何制作文档的替身会话，只给抽帧+转写，报告标"替身测试，置信度降级"。（为什么：委托方从未做冷观众测试；阈值是〔学院推断〕，用后续真人测试校准）〔溯源：F1, GAP-2〕
- [MEM-17][交付] L2 = L0+L1 + Q1–Q8 每维 ≥2 + 阻断缺陷 0 + 独立评审无未修阻断 + R-PUB 合规全过；L3 再要 ≥3 维 3 分且含 Q1、不劣于 ≥3 部对标中位、≥2/3 冷观众想看下一集。（为什么：级别累进，缺一级证据就不能跳级声明）〔溯源：G8, F1, GAP-1〕
- [MEM-18][交付] 阻断缺陷任一存在即禁止声明 L2：复述失败、身份漂移、段内左右互换、承诺的打斗无交手、生成器加字、缺句轧词、克隆脸、禁用项上主角、缺 AIGC 标识。（为什么：这些是人类主创整改重点或平台下架风险）〔溯源：A2, A5, B1, B3, C1, D1, D3〕

## 叙事、剧本与季

- [MEM-19][剧本] 第一场第一拍写画面内可见的冲突事件，去掉台词与字卡仍可读；最后 10s 停在能写成一句问句的未解问题。（为什么：委托方无平台经验，钩子规则只能来自外部调研与〔学院推断〕，需冷观众校准）〔溯源：GAP-1, F1〕
- [MEM-20][剧本] 动作行写事件不写形容词：把"特效华丽/史诗感"拆成可见事件（冲击环从接触点炸开、地面裂纹扩散）。（为什么：G5 具体化努力反复不够，病在写形容词而不是写事件）〔溯源：M3, G5〕
- [MEM-21][剧本] 每场写"开场状态 → 收场状态"且二者不同；写不出就删场或并入相邻场。（为什么："一个动作一个镜号"的清单化写法没有"一场戏"的设计层）〔溯源：A1〕
- [MEM-22][剧本] 纯色卡、精确文字、UI、logo、片尾字卡在剧本里就标 `[画面文字]`，交剪辑本地生成并程序化叠加，禁止送生成器。（为什么：纯黑字卡送 H3 后中段帧冒出"LAVCE"水印）〔溯源：D2, M8〕
- [MEM-23][季] 开季先写 season-bible 五节（世界规则/角色表/主线支线/伏笔账本/原著取舍表）与 episode-map 每集交接契约；相邻两集卡点类型不同，每集复现上一集最后一拍。（为什么：委托方无季级连续性实践，跨集漂移只能靠账本防）〔溯源：GAP-7, B1〕

## 分镜、运镜与空间

- [MEM-24][分镜] `运镜因果` 必须写成"因为 X（画面内可见事件），所以镜头 Y"；说不出 X 的运镜删掉或改静止。（为什么：「苏晓冲击镜头过于耿直，没有运镜和合理的打斗逻辑」）〔溯源：A4〕
- [MEM-25][运镜] 每次生成只给一个主运镜（高度或距离维度）；顿挫/震动写成事件引起的相机响应（the frame jolts as the blade hits the stone），多个运镜状态拆成多次生成在剪辑里接。（为什么：学院立场 R5——H3 运镜全局、不能分段〔外部调研·S-H3-09、S-H3-11〕）〔溯源：A4, M4, S-H3-09, S-H3-11〕
- [MEM-26][运镜] 需要明显运镜时：不用 turbo 低步数、慎用首帧脚手架句、起幅放在主体最大的一端；`with small amplitude` 视为无效。（为什么：社区实测这几项都会压掉或减半运镜〔外部调研·S-H3-08、F-H3-11〕）〔溯源：A4, S-H3-08, F-H3-11〕
- [MEM-27][空间] 换边只在"设计需要且起始帧支持"时写 `轴线策略: 换边` 并附 `- 换边:` 理由；同场相邻镜左右顺序禁止反转。（为什么：r5 单轴定侧是唯一实测达标的空间方案）〔溯源：A5, M4〕
- [MEM-28][空间] 模型执行你写的全部指令，指令打架它就乱编：定稿前全量 grep left/right/turn/toward/behind/front/arc/truck/orbit 逐条排矛盾。（为什么：起始帧"神左苏晓右"与 trucks left/arcs around 并存，空间被搅乱）〔溯源：A5, M4〕
- [MEM-29][拍] 区分三种拍：空间拍、表情拍每镜 ≤2–3；打击拍（原地攻防）可以密；`拍数` 列只记空间拍+表情拍。（为什么：学院立场 R4——拍多则空间跳变；外部实测约 3 秒 8–9 拍武打可按序打出〔外部调研·S-H3-09〕）〔溯源：A5, P10, S-H3-09〕

## 动作与节奏

- [MEM-30][动作] 打斗写成战术链（诱敌→落空→抓隙→…）+ 七相（意图→预备→发力→接触→反应→回收→后果），每场至少一个同框完整交手回合；含蓄 ≠ 缺席。（为什么：「几乎没有做 BOSS 打斗」——防御性策略被当成了叙事语言）〔溯源：A2〕
- [MEM-31][节奏] 每段设计速度层次（冲刺快→对峙慢→爆发→余波静场）；按真实事件时长排（摔倒约 0.5s，其余给后果）；要慢必须声明 `- 慢动作: 设计选择（理由）`。（为什么：「全是几个简单动作的慢镜头」；时长会被读成事件速度〔外部调研·S-H3-11〕）〔溯源：A3, S-H3-11〕

## 资产、一致性与关键帧

- [MEM-32][资产] 锁外观先写正向可见状态句（plain polished steel, smooth and unadorned），只对生成器已证实会加的物件再追加绝对否定句并 ≥3 seed A/B 验证；禁止写 negative_prompt 字段。（为什么：学院立场 R1——cfg=1.0 下 negative 被跳过〔外部调研·S-COMFY-05〕，官方建议把禁令写成正向〔外部调研·S-COMFY-08〕）〔溯源：C1, T-2, S-COMFY-05, S-COMFY-08〕
- [MEM-33][资产] 关键符号写对抗约束：穷举所有见过的错误变体（exactly one vertical bar; no horizontal line, no cross sign），质感同理（fire-textured, not smooth neon）。（为什么："ф"印记被画成十字、火纹被写成霓虹）〔溯源：D4, M8〕
- [MEM-34][一致性] 送视频同时挂角色板 + 同场已过关键帧（链式参考）；主角每集至少 1 个正脸镜与板图同尺寸并排逐特征比对。（为什么：苏晓某镜漂成"粗犷成熟脸"）〔溯源：B1, P5, M7〕
- [MEM-35][一致性] ≥2 人同框必须写差异化句（three clearly distinct men with different faces, hair and builds）；一个角色只给一张脸参考，禁止把多视角拼图当 reference。（为什么：三人同框克隆脸；几张脸=几个人〔外部调研·S-H3-09〕；平台治理高频 AI 脸〔外部调研·S-PLAT-07〕）〔溯源：B3, S-H3-09, S-PLAT-07〕
- [MEM-36][人群] 人群只写"大虚化、无独立可辨脸的暗形块"，不给任何特征、不建 CHR 卡、人群镜最少化。（为什么："远处人群低语"被扩写成一群持发光平板者）〔溯源：B2〕
- [MEM-37][伪影] 多人物/复杂背景镜，看视频前先写背景元素清单，再对照关键帧与视频首/中/尾格；多出元素即多 seed 重出择优。（为什么：背景持续出现关键帧里没有的"第二骨架"）〔溯源：B4, P8〕
- [MEM-38][光] 光只写被动描述（cold light falls from the upper LEFT），禁止写具体光源物件或光柱；共用段只放每颗都成立的元素。（为什么：同镜被加具象斜光柱；提到什么就长什么〔外部调研·S-H3-09〕）〔溯源：B3, C1, S-H3-09〕
- [MEM-39][规格] 送 first_frame 的关键帧一律 9:16（Qwen 1536×2752）或送入前显式裁 9:16 并记录；板图可用 2:3 1696×2528；交付 1080×1920，768×1344 与 480×864 只是中间稿。（为什么：first_frame 是拉伸到画布，2:3 图约被横向挤压 16%〔学院推断·待核：用正圆测试图验证〕〔外部调研·S-H3-03〕）〔溯源：T-1, T-2, S-COMFY-01, S-H3-03〕
- [MEM-40][关键帧] 冻结提示词按固定顺序写：风格锁→构图→位置+锚点句→场景→光→差异/人群/禁用；起始帧必须是动作链起点，推近镜取主体最大的一端。（为什么：起始帧决定全镜画面级与运镜空间）〔溯源：P3, M2, A4〕

## 视频提示词（H3）

- [MEM-41][H3] 起始帧+角色板+同场关键帧 = `模式: Ref2VA` 六段；只有首/尾帧 = `模式: FL2VA` 三段+官方对齐句、`references: —`；两种方言禁止混用。（为什么：学院立场 R2——两者是不同检查点，API 中首尾帧与 reference 互斥〔外部调研·S-H3-02、F-H3-27〕；委托方节点实际加载哪个〔学院推断·待核〕，用同镜同 seed A/B 确认）〔溯源：T-2, P5, S-H3-02, F-H3-27〕
- [MEM-42][H3] `references` 从 1 起唯一连续，`<Picture N>` 编号与首次引用顺序一致；占位起始帧槽放末位；改 references 后必跑 slot_order_check.py。（为什么：占位槽在 1 号、删掉后剩余从 2 起，18 镜与 16 镜两次集体失败）〔溯源：E1, T-3〕
- [MEM-43][H3] 帧数必须落 17k+5 网格（124–362）；>362 帧拆段；每镜声明 `- 尾部余量: 1.3`，提示词时长 = 分镜时长 + 余量，剪辑时裁掉尾部。（为什么：H3 常在最后 1.2–1.7s 崩解〔外部调研·F-H3-18〕）〔溯源：T-2, P8, F-H3-18〕
- [MEM-44][H3] ≥2 主体且有对白时，为不说话的人写闭嘴句（[S2] does not speak; his lips remain completely closed.），或让其背身/出画。（为什么：不写时 3 次中 2 次口型落错人，加句后 3/3 正确〔外部调研·F-ZEN-08〕）〔溯源：F-ZEN-08, S-ZEN-17〕
- [MEM-45][H3] 定稿镜用默认 20 步；≤8 步（4-step turbo）只用于预览抽卡。（为什么：低步数压掉运镜、削弱参考与语音〔外部调研·F-H3-09〕）〔溯源：T-2, F-H3-09〕
- [MEM-46][H3] 已验收产出与提示词不一致时，先把提示词回写成产出的事实再拿它当参考；参考图与提示词必须是同一事实。（为什么："短距离"提示词产出长竖线，留作参考后与后续重出矛盾）〔溯源：E4〕

## 声音与对账

- [MEM-47][声音] 不写声音 ≠ 静音：每镜写 overall_soundscape（≤3 声源），配乐一律 N/A、整场配乐后期铺一条连续音轨；同场两个同性别说话人必须绑定不同音色来源。（为什么：省略配乐段 3 次中 2 次自配音乐〔外部调研·F-ZEN-07〕；H3 两个男声音色相似〔外部调研·S-ZEN-17〕）〔溯源：GAP-3, F-ZEN-07, S-ZEN-17〕
- [MEM-48][声音] 终混 -16 LUFS ±1、真峰 ≤ -1 dBTP，用 loudness_verify.py 验；成片画幅偏离 9:16 >1% 即 error。（为什么：委托方 -16 LUFS 落在 GY/T 377-2023 容差内〔外部调研·S-COMFY-12〕）〔溯源：T-3, T-4, S-COMFY-12〕
- [MEM-49][对账] 分镜与视频提示词逐镜对齐（时长含尾部余量、台词、方位）；台词三方对账：分镜 `对白` ↔ `<d>` ↔ 转写。（为什么：双文档对账是委托方已固化的正确做法）〔溯源：P7, M10〕

## 验收与流程工程

- [MEM-50][验收] 每条出片依次跑 contact_sheet（首/中/末 0.5s + 关键帧并排 + 放大裁剪）→ psnr_scan → burnin_text_scan → transcript_reconcile，证据放 `qc/<SHOT>/`，结论写 `qc/SHOT-nnn.md`。（为什么：视频验收固定环节是委托方唯一稳定挡住技术缺陷的防线）〔溯源：P8, M10, C2〕
- [MEM-51][验收] 高风险资产与镜头（主角/BOSS/核心道具/多人/打斗）由独立会话做第二遍复验，复验人与日期写进验收记录。（为什么：自己验自己会放水，闭环自欺）〔溯源：C2, F1〕
- [MEM-52][流程] 一切生成走 prepare→confirm→run；生成前 segment_rhythm、dialogue_capacity、h3_frame_grid、prompt_lint、direction_audit、slot_order_check 全部 0 error 才进 prepare。（为什么：三步闸门防误提交，设计期脚本挡结构性缺陷）〔溯源：P6, M9, T-3〕
- [MEM-53][工程] 改集号/镜号必须二进制级全仓替换（保持 LF）+ asset_exists.py 全量复查 + 重渲。（为什么：整季重编号后 143 处旧路径残留，渲染报 30 条素材不存在）〔溯源：E2〕
- [MEM-54][环境] 文件/目录名用英文；多行中文命令写成 .py 执行；长任务挂后台；改技能/插件后重启运行时。（为什么：中文路径在 cmd 吞输出、终端 10 分钟超时、技能装配期一次性扫描）〔溯源：E3-1, E3-2, E3-3〕

## 缺陷回流（症状 → 病灶阶段）

- [MEM-55][回流] 看不懂/碎 → 剧本主因果链或分镜段结构；乱跑/越轴 → 分镜方位+起始帧；无打斗/慢 → 剧本战术链+分镜速度层；缺句 → 分镜时长；禁止先改提示词措辞。（为什么：这些病灶都在上游，r1→r5 在下游改措辞全部失效）〔溯源：A1, A2, A3, A5, D3, F3〕
- [MEM-56][回流] 漂移/克隆脸/禁用项 → 锚点卡+板图+关键帧；烧字/水印/纯色 → 提示词禁令包+剪辑本地生成；槽位/路径 → 工程脚本；提示词与产出不符 → 回写提示词。（为什么：病灶阶段不改，换 seed 只是抽奖）〔溯源：B1, B3, C1, D1, D2, E1, E2, E4〕
- [MEM-57][回流] 缺陷单必填：症状（时间码+原话逐字）、Q 维度、病灶阶段、修法、证据路径、复验结果；人类反馈先逐字记录再解读。（为什么：同一句反馈 agent 与人类理解有偏差，转述会丢信息）〔溯源：F3, G6〕
