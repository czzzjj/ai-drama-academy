# 10 · 质量哲学：外部视角、代理指标与能力公式

> 一句话世界模型：质量是目标观众的反应，不是"符合我的清单"；同一个 agent 评自己的产出天然有偏，只有外部信号（冷观众、独立评审、可证伪的脚本证据）能把环闭上 ｜ 浓缩案例：F1, F2, F3, F4（回答 G1–G4, G8） ｜ 对应技能：screening-review, cold-audience-test, production-director, shot-qc

## 核心判决

**T10.1 · 自己验收自己 = 闭环自欺。** 写提示词、选 seed、写验收、下结论都在同一个会话里完成时，盲区是同一套。
为什么：委托方渲染 rc=0、全镜采用、运镜统计达标、响度达标，人类每次看片都说"不达标"〔委托方实证·F1〕。外部研究：没有外部反馈时，LLM 难以自我纠错，有时纠错后反而更差〔外部调研·S-CASE-24〕；模型能认出自己的输出，自我识别能力与自我偏好强度线性相关〔外部调研·S-CASE-23〕。

**T10.2 · 代理指标是下限，不是上限。每个指标都要写明"它代理什么、证明不了什么"；禁止用指标证明观感。**
为什么："固定运镜=0"全绿，被说「无电影级运镜」；"无坏帧/无烧录/全采用"全绿，被说「片段式、跳跃」〔委托方实证·F2、A4、A1〕。社区实测者有一句同样的告诫："never let one [metric] outrank your eyes"〔外部调研·S-H3-08〕。有一条多 agent 管线用 VLM 打分、60 分及格，自动模式下到重试上限就选最高分继续：分数闸门最终总会放行〔外部调研·S-PIPE-15〕。

**T10.3 · 人类反馈是抽样，不是全集。** 一条反馈 → 归入 Q1–Q8 中的某一维 → 在全片搜同类 → 回到病灶阶段修 → 8 维全部重查。
为什么：r1→r5 每轮只修最新一条（运镜 → 特效 → 史诗 → 空间），修好一处又暴露另一处，人类每轮都说"仍不够"〔委托方实证·F3、G1〕。人类看片时是对多个维度同时打分，只说出最刺眼的一两条。

**T10.4 · 能力 = 知识 × 实践反馈 × 标准内化，三项是相乘关系，任何一项为 0，结果就是 0。**
为什么：委托方装了 7 个导演/运镜/分镜技能，每镜都嵌了专业 primitives 句式，质量没有质变——只做了第一项〔委托方实证·F4、G3〕。实践反馈 = 找错题和练习的判分回路；标准内化 = 好坏样例对和审美判据卡（[`90-curriculum/training-loop.md`](../90-curriculum/training-loop.md)、[`30-taste/judgment-cards.md`](../30-taste/judgment-cards.md)）。

**T10.5 · 交付前必须过外部视角三件套：自我放映 → 独立评审 → 冷观众。三者查的东西不同，不能互相替代。**
为什么：这是委托方自己提出的修正方向〔委托方实证·F1〕。自我放映抓"第一次困惑的时间点"；独立评审抓同一会话的盲区；冷观众抓"没有背景知识就看不懂"。外部实例：一版技术上明显改善的粗剪仍没通过冷观众测试，因果、主角作用、铺垫、结局都不清楚，剧情可懂性因此被设为独立的 P0 门禁〔外部调研·S-PIPE-01〕。

**T10.6 · 每次交付都要声明级别：L0 技术合格 / L1 看得懂 / L2 可发布 / L3 有竞争力。只有 L0 证据时，只能写"技术合格，观感未验证"。**
为什么：委托方历次"全绿"都停在 L0〔委托方实证·T-4、G8〕。级别定义和证据要求见 [`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md)（R-CUT-15、R-CUT-16）。

**T10.7 · 独立评审必须去偏：盲评、交换位置、跨模型家族、两两比较、先给证据再给分。**
为什么：只交换回答顺序，一致率 GPT-4 为 65.0%，Claude-v1 为 23.8%〔外部调研·S-CASE-21〕；以 ChatGPT 为评审，只调换顺序，Vicuna-13B 就在 80 题中的 66 题上"赢了"〔外部调研·S-CASE-22〕；评审知道答案"改过一轮"会打更高分（Refinement-Aware），看到"多数人认为"会随大流（Bandwagon）〔外部调研·S-CASE-25〕；多模态评审在两两比较上接近人类，在绝对打分上偏差明显〔外部调研·S-CASE-27〕。

**T10.8 · 自动评测只做预筛和排序，不做放行；叙事可懂性只能由观众判。**
为什么：2026 年两个多镜头基准的结论一致。MSVBench 与人评相关 0.944，结论是现有方法主要是"视觉插值器，而非真正的世界模型"〔外部调研·S-PIPE-12〕；MSAVBench 与人评相关 0.915，现有系统在导演级控制和细粒度音画同步上最弱〔外部调研·S-PIPE-11〕。VideoScore 与人评的相关达 77.1，管技术层，不管叙事〔外部调研·S-CASE-30〕。视频语言模型自身也会幻觉，识别事实强于识别幻觉〔外部调研·S-CASE-29〕。

**T10.9 · "验证过"的意思是有人看过，并确认它读起来就是预期的那个镜头；不是某个指标同意了。**
为什么："'Verified' means a person watched it and said it reads as the intended shot. Not that a metric agreed."，该作者有 4 条最自信的书面结论被看片推翻〔外部调研·S-H3-08〕。

**T10.10 · 补丁迭代必须设止损线：同一问题换 seed 最多 2–3 次，每次只改一个变量，花掉一半预算仍无进展就换方案。**
为什么：重试纪律来自外部短剧管线〔外部调研·S-PIPE-01〕；多 agent 影片框架的协作修订也设了 3 轮上限〔外部调研·S-CASE-26〕。没有止损线，F3 的打地鼠就会无限延续〔委托方实证·F3〕。

## 机制解释

1. **共享盲区。** 生成者知道"我想要什么"，看片时会用意图补全画面：明明没拍出因果，脑子里已经有了。冷观众没有这份意图，所以能看见缺口。这就是 G4"为什么每次都要人类指出"的结构原因〔委托方实证·G4〕。
2. **自我偏好与修订偏好。** 同一模型更喜欢自己的输出（S-CASE-23），也更喜欢"改过的"版本（S-CASE-25）。所以评审提示词里**禁止出现**"这是第 N 版""已全部修复""指标全绿"一类信息，否则评审在测的是措辞而不是片子。
3. **代理指标会被优化穿。** 一旦指标成为目标，生产就会朝"让指标好看"漂移："固定运镜=0"会诱导出每镜都动、但没有动机的运镜（A4）。指标只能证明"某种错误没有发生"。〔学院推断·验证法：对同一批镜头，比较指标排名与独立评审的两两比较排名；排名相关性低的指标，从放行条件降级为体检项〕
4. **反馈的信息量。** 一句"仍不够"带的信息几乎为零，但它是一个样本：说明至少有一维低于人类的阈值。把它当全集去修，只修掉了一个点；把它当样本，就会去搜整个面（F3）。
5. **乘法而非加法。** 知识再多，没有判分回路就不知道哪里错；有判分没有内化的标准，就只会针对判分器做优化。三项缺一，能力都不会出现质变（F4）。

## 本管线下的变体

**外部视角三件套的落地**

| 环节 | 谁来做 | 输入（只给这些） | 产物 | 判据 |
|---|---|---|---|---|
| 自我放映 | 生产 agent 本人 | 成片，连续看一遍，不暂停，**不打开任何制作文档** | `review/self-screening.md`：观后感、第一次困惑的时间点 | R-CUT-17 |
| 8 维自查 | 生产 agent | 成片 + [`50-rubrics/quality-model.md`](../50-rubrics/quality-model.md) | `review/quality-scorecard.md`：每个分数都附证据时间码 | R-CUT-20 |
| 独立评审 | 隔离会话，优先选另一模型家族（例：生产在 Claude Code，评审在 Codex，或反过来） | 成片、接触表、转写、学院判据；**不给**提示词、修改轮次、指标面板 | `review/independent-review.md`，首行列出输入清单 | R-CUT-18 |
| 冷观众 | ≥3 名无背景的人；没有真人时，用未见过任何文档的 agent 会话作替身，并标注"置信度降级" | 只看成片 | `review/cold-audience/*.md`：复述主因果链、断点时间码 | R-CUT-19 |

**指标速查：每个指标代理什么、证明不了什么**

| 指标（脚本） | 代理的是 | 证明不了 | 溯源 |
|---|---|---|---|
| 渲染 rc=0、素材存在（`asset_exists.py`） | 管线没有断 | 任何观感 | F1、E2 |
| 响度 -16 LUFS、真峰（`loudness_verify.py`） | 音量合规 | 声音层次、静场设计 | F2、GAP-3 |
| 无烧录文字（`burnin_text_scan.py`） | 画面里没有被加字 | 画面好不好看 | D1 |
| 转写逐字对账（`transcript_reconcile.py`） | 台词齐全 | 表演、语气、口型落在谁身上 | D3、D5 |
| 固定镜头=0 / 运镜计数 | 相机在动 | 运镜有动机（因果句） | A4、F2 |
| 均镜长 ≥5s、短镜占比（`segment_rhythm.py`） | 没有碎镜 | 因果链看得懂 | A1 |
| PSNR 无死段（`psnr_scan.py`） | 画面没冻住 | 该动的表情真的动了（还要看 PSNR 中位，R-PRF-08） | P8 |
| 全镜采用 | 每镜都有产出 | 每镜都必要 | F2 |
| 自评 Q1–Q8 全 ≥2 | 自查做过了 | L2（还需外部三件套） | F1 |

- **评审去偏的具体做法**：
  - 两两比较为主（新版对旧版、本镜对锚点参考），交换顺序各跑一次，两次结论一致才算数；不一致就判"无法判定"，交给人〔外部调研·S-CASE-21、S-CASE-22〕。
  - 每次评审混入 1–2 个"明知不存在"的探针项（例如"画面里有没有项链"，实际没有）；评审答"有"，本次评审作废〔外部调研·S-CASE-29〕。
  - 输出用固定字段、限制字数，不因写得长就判通过（冗长偏差，S-CASE-21）。
  - 先列证据（时间码、帧号、截图）再给结论（S-CASE-22 的 Multiple Evidence Calibration）。
  - 外部量表做法可作对照：两家模型各自交换 A/B 盲评，每臂 3 次重复〔外部调研·S-ZEN-19〕。
- **冷观众样本量**：可用性测试中 5 人约能发现 85% 的问题〔外部调研·S-CASE-14〕；理解测试以 ≥60% 正确为"能理解"〔外部调研·S-CASE-15〕。学院 L1 阈值是 ≥3 人中 ≥2/3 能正确复述主因果链〔学院推断，见 definition-of-done；验证法：积累 ≥5 集后，用冷观众复述率与人类主创的通过/打回结论做对照〕。约 90% 的大规模上映片做试映，平均测 3 次〔外部调研·S-CASE-19〕。
- **脚本的定位**：`contact_sheet.py`、`psnr_scan.py`、`burnin_text_scan.py`、`transcript_reconcile.py` 只产出证据、报告事实，不替人下审美判决（CONVENTIONS §8.5）。它们的输出进入 L0；L1 及以上的结论必须引用目视或观众证据。工具本身也会出错（D5），单通道不下判决。
- **冷观众替身的边界**：替身是另一个未见过任何文档的 agent 会话，它和生产者可能同属一个模型家族，共享偏好（S-CASE-23）。替身结论只能写"替身测试，置信度降级"，不能把 L1 写成"已验证"；有条件时，优先用平台的陌生观众通道（见 [`10-theory/09-platform-publishing.md`](09-platform-publishing.md)）。
- **评分量表的用法**：Q1–Q8 每维 0–3 分（[`50-rubrics/quality-model.md`](../50-rubrics/quality-model.md)）；绝对分只用于自查和记录，放行决定依据阻断缺陷清单和两两比较，不依据总分。

| 再装一个技能来解决观感问题 | 知识层加厚，能力不变 | [`60-casebook/cards/F4-skills-not-ability.md`](../60-casebook/cards/F4-skills-not-ability.md) |

## → 行为改变

1. 下次写成片报告，**第一节先填交付声明**（达到 L 几级 + 各级证据路径 + 未验证项）；只有 L0 证据时，禁止使用"达标""可发布""质量通过"。
2. 下次交付前，**先自我放映**：连续看一遍，不开任何文档，记下第一次困惑的时间点；这份记录要写在打开制作文档之前。
3. 下次需要评审时，**另开一个隔离会话**，优先用另一个模型家族；只给成片、接触表、转写和判据，不给提示词、修改轮次和指标面板；两两比较交换顺序各跑一次，并混入探针项。
4. 下次收到人类反馈，**先归维度、再搜全片、再回病灶**，最后做 8 维重查；禁止只改被点名的那一镜就重新提交。
5. 下次给任何指标写报告，**在旁边写一句"它证明不了什么"**；指标只能证明某种错误没有发生，不能作为观感结论的证据。
6. 下次同一问题换 seed 到第 3 次仍不行，**停止抽卡**，判为系统性问题，改设计或改参数；每次重试只改一个变量，并写进日志。
7. 下次被人类指出一个自己没先发现的问题，**把它写成一道找错题和一条判据**，回流到题库和清单；这是"实践反馈"那一项的唯一来源。

## 自测

1. 判断：我在同一个会话里把片子改完后，又让自己按学院 8 维量表重新打了一遍分，全部 ≥2，所以可以声明 L2。
<details><summary>答案</summary>错。同一 agent 自查自改不算外部验证（S-CASE-24、S-CASE-23）；L2 还要求 L1 的冷观众证据、隔离会话的独立评审意见和 R-PUB 合规（definition-of-done）。自评分数只能作为 8 维自查记录。对应找错题 DR-16。</details>

2. 简答：人类说"打斗还是不行"，你修了被点名的 SHOT-014。按 T10.3，完整的处理流程是什么？
<details><summary>答案</summary>① 把反馈归入维度（动作与打斗逻辑；可能牵连空间、节奏）；② 在全片搜同类：所有打斗段是否都有完整交手回合、真速度、战术链；③ 判断病灶阶段（动作设计 / 分镜，不是 seed），回到那里修；④ 修完对 Q1–Q8 全部重查，再提交。只改 SHOT-014 就是 F3 的补丁式迭代。对应找错题 DR-18。</details>

3. 简答：设计一次独立评审时，哪三类信息不能给评审会话？为什么？
<details><summary>答案</summary>生成提示词和制作文档（评审会按意图补全画面，还会产生自我偏好，S-CASE-23）；修改轮次和"已修复"说明（Refinement-Aware 偏差，S-CASE-25）；指标面板和"全绿"结论（Bandwagon 和权威偏差，S-CASE-25）。只给成片、接触表、转写和判据。</details>

4. 判断：MSAVBench 与人评的相关达到 0.915，所以可以用同类自动评测替代冷观众判 L1。
<details><summary>答案</summary>错。基准自己的结论是：现有系统在导演级控制和音画同步上最弱，生成器是"视觉插值器"而非世界模型（S-PIPE-11、S-PIPE-12）；高相关性是针对基准维度测出来的，不覆盖"陌生观众能不能复述因果"。自动评测只做预筛和排序；L1 必须有冷观众（或标注降级的替身）证据。</details>

5. 简答：用"能力 = 知识 × 实践反馈 × 标准内化"解释委托方 G3 的困惑，并给出装载学院后的第一步。
<details><summary>答案</summary>委托方装了 7 个技能，只做了"知识"一项；没有做题、判分、对照标准答案的回路，也没有好坏样例来形成判断，后两项接近 0，乘积就不会质变（F4）。第一步：开工前完成训练回路的最低学分（找错题 + 小任务 + 判分），并把每次被人类打回的点写成新的找错题回流。对应找错题 DR-19。</details>
