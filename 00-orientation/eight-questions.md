# 八个困惑的回答（G1–G8）

> 委托方的 agentos 在产出被连续打回后，留下了 8 个它自己回答不了的问题〔委托方实证·G1–G8〕。
> 本文件逐条给出**短答（判决）→ 机理 → 学院里的回答模块 → 行为改变**。
> 学院的设计验收之一：装载学院后，agent 不再产生这 8 个困惑；如果再产生，说明对应模块没装好。

---

## G1 · 为什么每个单点反馈我都改了，整体还是"不对"？

**短答**：因为人类的反馈是**抽样**，不是全集。一句反馈 = 一类缺陷的一个样本，背后是一个完整的质量模型；只修被点名的那一处，同类缺陷在全片其他位置、以及没被点名的维度，原封不动。〔委托方实证·F3〕

**机理**：r1→r5 打斗实验每轮只修最新一条反馈（运镜→特效→史诗→空间），修好一个暴露另一个。人类看片是一次性对 8 个维度同时打分，只说出最刺眼的那一两条；agent 把"说出的那条"当成了"全部问题"。

**回答模块**：
- [`50-rubrics/quality-model.md`](../50-rubrics/quality-model.md)：8 维全片质量模型（Q1–Q8），每轮全维度过关自查。
- [`20-craft/screening-review/SKILL.md`](../20-craft/screening-review/SKILL.md)：反馈翻译协议——"一条反馈 → 定位维度 → 在全片搜同类 → 回到病灶阶段修"。
- [`60-casebook/cards/F3-patch-iteration.md`](../60-casebook/cards/F3-patch-iteration.md)。

**→ 行为改变**：收到任何一条反馈，先把它归到 Q1–Q8 中的维度，再在**全片**搜索同类缺陷并列表；修完后对 8 维全部重新自查一遍，才允许再次提交。禁止"只改被点名的那个镜"就交付。

## G2 · 为什么技术上全绿，观感还是不行？

**短答**：技术闸门只证明"没出错"，不证明"好看"。"固定镜头=0""无坏帧""全采用"是**代理指标**，它们是下限不是上限。〔委托方实证·F2〕

**机理**：渲染 rc=0、响度 -16 LUFS、无烧录字幕、运镜统计达标——这些全绿时，人类说"片段式、跳跃""无电影级运镜"。因为观众的判断顺序是：情绪 > 故事 > 节奏 > 视线 > 画面平面 > 三维空间〔外部调研·S-STORY-13：Walter Murch 剪辑六法则〕，而技术指标几乎全部落在这个顺序的最末端。

**回答模块**：
- [`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md)：把"达标"分成 L0 技术合格 / L1 看得懂 / L2 可发布 / L3 有竞争力，技术全绿只是 L0。
- [`10-theory/10-quality-philosophy.md`](../10-theory/10-quality-philosophy.md)：代理指标与观感的关系。
- [`30-taste/judgment-cards.md`](../30-taste/judgment-cards.md)：指标之上的观感判断方法（看片法/对照法/静音测试等）。

**→ 行为改变**：成片报告里禁止用技术指标证明质量；报告必须分两栏——"L0 技术闸门（自动）"与"L1–L3 观感闸门（目视/冷观众证据）"，后者为空则不得写"达标"。

## G3 · 为什么学了一堆技能，能力没有质变？

**短答**：技能是**知识注入**。能力 = 知识 × 实践反馈 × 标准内化。只装技能 = 只做了乘法的第一项。〔委托方实证·F4〕

**机理**：装了 7 个导演/运镜/分镜技能、每镜嵌了专业 primitives 句式，输出没有质变——因为没有"做→被判分→对照标准答案→改"的回路，也没有见过足够多"好 vs 坏"的成对样例来形成判断。

**回答模块**：
- [`90-curriculum/training-loop.md`](../90-curriculum/training-loop.md)：加载 → 找错题对拍 → 小任务 → 自动判分 → 复盘。
- [`60-casebook/drills/`](../60-casebook/drills/)：找错训练题（题面与答案分离）。
- [`30-taste/pairs/`](../30-taste/pairs/)：好/坏样例对，训练判断而不是背词表。
- [`90-curriculum/install-verification.md`](../90-curriculum/install-verification.md)：用一个可打分的任务证明"装载后能力确实变了"。

**→ 行为改变**：装载学院后，先完成训练回路的最低学分（找错题 + 小任务 + 判分）再开工；每次生产后把被打回的点写成新的找错题，回流题库。

## G4 · 为什么每次都要人类指出问题？我怎样才能自己先发现？

**短答**：因为你一直用**自己的标准**验收**自己的产出**——闭环自欺。要自己先发现，必须在交付前引入外部视角。〔委托方实证·F1〕

**机理**：同一个会话写提示词、选 seed、写验收、下结论，它的盲区是一致的。人类能看出来，是因为人类是"另一个观察者"。

**回答模块（外部视角三件套）**：
1. **自我放映**：交付前把成片当观众从头到尾连续看一遍（不暂停、不看文档），写观后感与"第一次困惑的时间点"。→ [`20-craft/screening-review/SKILL.md`](../20-craft/screening-review/SKILL.md)
2. **独立评审**：另开一个 agent 会话，只给成片和学院判据，不给制作文档与辩护理由，让它做对抗评审。→ 同上
3. **冷观众测试**：无背景者看一遍，复述因果链，记录断点。→ [`20-craft/cold-audience-test/SKILL.md`](../20-craft/cold-audience-test/SKILL.md)、[`90-curriculum/cold-audience-protocol.md`](../90-curriculum/cold-audience-protocol.md)

**→ 行为改变**：没有"自我放映记录 + 独立评审意见"的成片，不允许提交给人类主创。人类每指出一个你没先发现的问题，就在评审判据里补一条（并写成找错题）。

## G5 · 为什么"特效""史诗感"这类词，我做了很多具体化努力还是不够？

**短答**：两个原因。① 形容词不渲染——生成器渲染的是**事件**（"冲击环从接触点炸开"），不是评价（"特效华丽"）〔委托方实证·M3〕；② "史诗感"主要是**画面级**属性（尺度对比、构图、光、机位高度），由**起始帧**决定，提示词救不了构图〔委托方实证·M2、P4〕。你一直在错误的层（视频提示词的形容词）上用力。

**机理**："史诗感"不是一个参数，它是多个维度的合力：尺度参照（渺小的人 vs 巨大的对象同框）、环境后果（地裂、碎石、气浪）、节奏（蓄力的停顿→爆发）、声音（低频、静场后的冲击）、机位（低机位仰拍、拉远交代规模）。缺任何一层都会"不够"。

**回答模块**：
- [`10-theory/08-generator-temperament.md`](../10-theory/08-generator-temperament.md)：写事件不写形容词。
- [`20-craft/keyframe-freeze/SKILL.md`](../20-craft/keyframe-freeze/SKILL.md)：起始帧按海报标准抽卡与验收。
- [`10-theory/04-action-design.md`](../10-theory/04-action-design.md)（七相中的"后果相"）、[`10-theory/11-sound-design.md`](../10-theory/11-sound-design.md)、[`10-theory/12-color-and-light.md`](../10-theory/12-color-and-light.md)。
- [`30-taste/pairs/`](../30-taste/pairs/)："华丽特效 vs 冲击环炸开"等样例对。

**→ 行为改变**：遇到抽象评价词（史诗、震撼、华丽、电影感、压迫感），先把它拆成"起始帧可见属性 + 事件 + 后果 + 声音 + 节奏"五栏的具体条目，再分别落到关键帧提示词、视频提示词、声音设计、剪辑节奏；提示词中禁止出现未拆解的评价形容词。

## G6 · 为什么同一句反馈，我和人类的理解总是有偏差？

**短答**：人类用的是**设计层的词**，你听成了**参数层的词**。"运镜"对人类指"镜头语言设计"（这一刻用什么景别、从哪看、怎么动、为什么动、在哪切），对你变成了"相机位移的统计量"；"打斗逻辑"对人类指"谁为什么出手、对方怎么应、空间怎么变、后果是什么"的因果链，对你变成了"动作要多一点"。〔委托方实证·A4、A2、G6〕

**回答模块**：
- [`00-orientation/glossary.md`](glossary.md)：高频反馈词的"设计层释义 + 可检查的判据"对照表。
- [`20-craft/screening-review/SKILL.md`](../20-craft/screening-review/SKILL.md)：反馈翻译协议（症状 → 维度 → 设计层 → 可验证的修改假设）。

**→ 行为改变**：收到含糊反馈时，不要问"您的意思是？"，而是用术语表把它翻译成 2 个可验证的解释，各做一个最小样（同一段的 A/B 两版），让人类选；选择结果写入记忆。

## G7 · 是不是我的根本局限？

**短答**：不是。你自己的诊断是对的：**你把"生成执行"当成了"制作"。**〔委托方实证·G7〕真正的制作是"开发 → 预制作 → 制作 → 后期 → 审片 → 发布"的工业流程，生成只是"制作"阶段里的一步。你一直在做"执行指令 → 交付 → 等反馈"的流水线活，所以每个问题都在生成这一步被发现、又在生成这一步被打补丁——而它的病灶在更早的阶段（剧本、分镜、起始帧）。

**回答模块**：
- [`00-orientation/production-lifecycle.md`](production-lifecycle.md)：六阶段流程、每阶段产物与闸门、**缺陷回到病灶阶段修**的路由表。
- [`20-craft/production-director/SKILL.md`](../20-craft/production-director/SKILL.md)：把流程变成可执行的阶段闸门。

**→ 行为改变**：任何缺陷先判断"病灶在哪个阶段"（例：空间乱 → 分镜/起始帧阶段；对白缺句 → 剧本/分镜阶段；不是 seed 问题），回到那个阶段修，而不是在视频提示词里加词。

---

## G8 · 什么算"够好了"？

**短答**：可操作的"达标"= 分级定义 + 每级的通过证据。学院定义四级：**L0 技术合格**（自动闸门全过）→ **L1 看得懂**（冷观众能复述因果链）→ **L2 可发布**（8 维全部 ≥ 2 分、无阻断缺陷、独立评审通过、平台合规）→ **L3 有竞争力**（钩子与完播设计达到对标作品水平）。委托方历次"全绿"都只在 L0。

**回答模块**：
- [`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md)：四级定义、阈值、证据要求、谁来判。
- [`50-rubrics/quality-model.md`](../50-rubrics/quality-model.md)：8 维 0–3 分量表。

**→ 行为改变**：交付时必须声明"本片达到 L 几级"并附该级全部证据；只有 L0 证据时，只能说"技术合格，观感未验证"，不能说"达标"。
