# 术语表（Glossary）

> 两部分：**A. 学院工作术语**（统一全库用词）；**B. 人类反馈词翻译表**（回答 G6：同一句反馈为什么总是理解偏差）。
> 规则：全库写作只用 A 中的词；收到人类反馈时用 B 翻译，**不要把人类的设计层词汇当成参数层词汇**。

---

## A. 学院工作术语

### 结构单位
| 术语 | 定义 | 本管线中的硬约束 |
|---|---|---|
| **集**（episode） | 一个可独立发布、以钩子开场、以悬念收尾的单元 | 委托方现规格：单集 90–110s〔T-4〕 |
| **场**（scene） | 同一时空内的一段连续戏 | — |
| **段**（sequence / segment） | 一条**完整动作链**或一个完整戏剧单元；本管线中通常 = 一次 H3 生成 | 8–15s；≥ 5.17s（124 帧）〔T-2、P10〕 |
| **拍**（beat） | 段内一次"状态改变"（攻→挡、问→答、平静→惊觉） | 段内 2–3 拍为常态〔P10〕 |
| **镜**（shot） | 一次生成 / 一个剪辑素材单位 | 不再等于"一个动作"〔A1〕 |
| **CUT** | 剪辑单中的一个入出点片段 | 可从一个镜中取多个 CUT |

> 判决：**节奏 KPI 是"有效拍数"，不是切镜数。**〔A1〕

### 资产与生成
| 术语 | 定义 |
|---|---|
| **锚点卡** | 每个角色/道具/场景/符号一张：锚点句 EN + 必现 + 禁用 + 方位属性 + 来源依据〔P1〕 |
| **锚点句 EN** | 一段英文描述，**逐字**嵌入所有含该资产的提示词，保证跨镜一致〔P1〕 |
| **板图** | 资产母版图（Qwen-Image，1696×2528，多 seed 抽卡定稿）〔P2、T-1〕 |
| **冻结提示词** | 描述某镜**起始画面完整状态**的英文提示词，验收通过后冻结不改〔P3〕 |
| **关键帧 / 起始帧** | 冻结提示词生成的图；作为视频 `first_frame` 送 H3，**决定方向、构图、灯光、轴线**〔P4、M2〕 |
| **链式参考** | 送视频时同时挂"角色板 + 同场已过关键帧"〔P5〕 |
| **帧网格** | H3 帧数 = 17k+5（k=7…21 → 124…362 帧，24fps 下 5.17…15.08s）〔T-2〕 |
| **对白容量** | 一镜能装下的台词字数 ≈ (时长 − 表演留白 − 停顿 − 换句气口) × 7.5 字/秒；**7.5 是塞得下的上限**〔T-2、D3〕，规划时按自然语速 ≈4.1 字/秒〔外部调研·S-ZEN-17〕，见 `dialogue_capacity.py` |
| **禁令包** | 每镜固定附加的约束句：`No captions…`、`Real-time speed…`、差异化句、绝对否定句〔M8〕 |
| **绝对否定句** | `no jewelry at all`、`no carved stone, no runes` 这类写在正向提示词里的否定；本管线 negative_prompt 无效，只能这样写〔C1〕 |
| **对抗约束** | 不只写"应该是什么"，还穷举"曾经错成什么"〔D4〕 |
| **三步闸门** | prepare（校验+预览）→ confirm → run〔P6〕 |

### 调度与运镜
| 术语 | 定义 |
|---|---|
| **单轴定侧** | 相机只做"高度与距离"维度的运动（缓推/顿挫/上摇/拉回），不做左右维度（truck/arc/orbit/weave）〔A5、M4〕 |
| **画面位置称呼** | 宽景中用 "the god on the LEFT" 指代角色，而非只用名字〔A5②〕 |
| **方位词审计** | 提示词定稿前全量排查 left/right/turn/toward/behind/front/arc/truck/orbit 等，与起始帧方位逐一核对〔A5〕 |
| **运镜因果句** | "因为发生了 X，所以镜头做了 Y"；说不出 = 炫技或脱钩〔A4〕 |
| **七相动作链** | 意图 → 预备 → 发力 → 接触 → 反应 → 回收 → 后果〔A2〕 |
| **交手回合** | 我攻 → 你挡/闪 → 我变招（至少一次往返）〔A2〕 |
| **战术链** | 把打斗写成战术步骤：诱敌 → 落空 → 抓隙 → 狂暴 → 闪避 → 击飞〔A2〕 |
| **速度层次** | 段内存在快-慢-爆-静的变化；"慢"必须是设计选择〔A3〕 |

### 验收与质量
| 术语 | 定义 |
|---|---|
| **逐特征放大核验** | 按锚点卡必现/禁用清单逐条裁剪放大比对，留下裁剪图证据〔C1、C2〕 |
| **双通道证据** | QC 结论需两个独立通道（转写 + 抽帧/听感），单通道不判决〔D5〕 |
| **随机缺陷 vs 结构性缺陷** | 换 seed 能解决的是随机缺陷；换 seed 无解的是结构性缺陷，必须改设计/参数〔D3〕 |
| **代理指标** | 可量化但不等于质量的指标（固定镜头数、坏帧数…）；是下限不是上限〔F2〕 |
| **自证循环** | 用自己的标准验收自己的产出〔F1〕 |
| **自我放映** | 交付前把成片当观众连续看一遍并写观后感〔F1〕 |
| **独立评审** | 另一个 agent 会话，只给成片和判据，做对抗评审〔F1〕 |
| **冷观众** | 无项目背景的观看者；测试其能否复述因果链〔F1、GAP-2〕 |
| **病灶阶段** | 缺陷产生的阶段（≠ 被发现的阶段），见 [`production-lifecycle.md`](production-lifecycle.md) |
| **L0–L3** | 达标分级：技术合格 / 看得懂 / 可发布 / 有竞争力，见 [`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md) |

### 平台（外部调研，非委托方实证）
| 术语 | 定义 |
|---|---|
| **开场钩子** | 开头数秒内让观众不划走的事件（冲突、悬念、反常画面） |
| **首反转** | 第一次"预期被打破"的时刻 |
| **集末悬念 / 卡点** | 每集结尾让观众想看下一集的未解问题；付费短剧中也指付费节点 |
| **完播率 / 留存曲线** | 看到结尾的观众比例 / 每一秒仍在观看的比例 |
| **追更** | 观众持续观看后续集 |

具体数字与平台规则以 [`10-theory/09-platform-publishing.md`](../10-theory/09-platform-publishing.md) 及其引用的 `80-sources` 条目为准。

## B. 人类反馈词翻译表（G6）

> 用法：人类说了左列的词 → 不要按"直觉参数"去改 → 按"设计层释义"理解 → 用"可检查判据"自查 → 不确定时做 A/B 两版让人类选。

| 人类说 | ❌ 参数层误读（委托方曾经的理解） | ✅ 设计层释义 | 可检查判据 | 溯源 |
|---|---|---|---|---|
| **"没有运镜""无电影级运镜"** | 相机位移次数太少 → 让每镜都动起来（固定镜头=0） | 镜头语言设计缺席：这一刻**为什么**用这个景别、从哪看、怎么动、在哪切。动机缺失比动得少更严重 | 每个运镜能写出因果句；景别有变化序列（远→中→近或反之有理由）；关键动作的接触瞬间有镜头响应（顿挫/震动） | A4, F2 |
| **"运镜耿直"** | 运动不够复杂 → 加环绕/横移 | 镜头只是平铺记录，没有随动作节拍改变（推近在接触时没有顿、爆发时没有震、收束时没有拉回） | 段内运镜至少随一个拍点改变状态 | A4 |
| **"打斗逻辑不合理""没有打斗逻辑"** | 动作不够多 → 加招式 | 因果链缺失：谁为什么出手 → 对方怎么应 → 空间怎么变 → 后果是什么；没有"交手回合" | 能写出战术链；至少 1 个完整交手回合；每次接触有反应与后果 | A2 |
| **"几乎没有打斗"** | 打斗镜头数量少 | 打斗被"动作瞬间 + 反应镜头"的含蓄策略**替代**了，观众没看到交手 | 至少一个镜头内能看到双方接触与反应 | A2 |
| **"慢镜头""死板"** | 动作幅度小 | 全片无速度层次，"慢"成了默认 | 每段有快-慢-爆-静变化；提示词写了实时速度 | A3 |
| **"片段式""剧情跳跃""切点跳脱"** | 转场不够顺 → 加转场特效 | 叙事单位错了：一个动作一个镜，没有"段"；因果链被切断 | 均镜长、段内拍数、冷观众复述因果 | A1 |
| **"乱跑""位置混乱"** | 方位词写得不够多 | 轴线被换边运镜词与起始帧打架搅乱；拍太多导致空间连续跳变 | 方位词审计通过；单轴定侧；拍数 ≤ 3 | A5 |
| **"穿帮"** | 某一帧出了错 | 一致性体系缺陷（脸、服装、道具、人群、背景元素跨镜不一致） | 正脸库比对；背景元素清单比对 | B1–B4 |
| **"特效不够""不够华丽"** | 特效形容词不够强 → 加 spectacular/epic | 没有**事件**：能量从哪来、在哪接触、怎么扩散、留下什么后果 | 提示词里特效写成"事件 + 后果"，无未拆解评价词 | M3 |
| **"不够史诗""没有史诗感"** | 加 epic/grand 等词 | 画面级问题：起始帧缺尺度对比、低机位、纵深、光；加上节奏与声音的蓄力-释放 | 起始帧海报测试；同框尺度参照物 | M2, P4 |
| **"看不懂""不知道在干嘛"** | 加字幕/字卡解释 | 因果链或空间关系没被画面建立；钩子缺失 | 冷观众复述；自我放映的"第一次困惑点" | F1, A1 |
| **"仍不够""还是不行"** | 再修最近那一处 | 反馈是抽样：8 维中还有未达标维度 | Q1–Q8 全量自查 | F3 |
| **"不像电影"** | 加电影感 LUT/宽银幕黑边 | 缺镜头语言设计 + 声音层次 + 色彩剧本 + 表演 | Q2/Q5/Q6/Q8 维度评分 | F2 |
