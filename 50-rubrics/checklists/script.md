# 剧本清单（R-SCR）

> **阶段**：1 预制作·剧本（[`00-orientation/production-lifecycle.md`](../../00-orientation/production-lifecycle.md)）。服务维度：Q1 叙事与钩子、Q3 动作与物理、Q8 声音与对白（[`50-rubrics/quality-model.md`](../quality-model.md)）。
> **何时跑**：每集 `script.md` 定稿前、分镜开工前；剧本任何一场改动后全量重跑。执行技能：[`20-craft/script-doctor/SKILL.md`](../../20-craft/script-doctor/SKILL.md)。
> **通过规则**：全部 `[自动]` 条目 0 error；每条 `[目视]` 条目的证据文件存在并写了结论（证据统一放 `review/script/`）。钩子类数字（5s / 20s / 30s / 10s）是外部行规与起点值，委托方从未发布过作品（GAP-1）——按起点执行，发布后用留存数据校准。
> **估时口径**：剧本阶段的"秒"= 按 `dialogue_capacity.py` 的规划语速（4.1 字/秒）+ 动作事件真实时长估出的时码，写在每场场头 `估时: 00:00–00:12`。

## 常见误判

- **"台词里说清楚了"≠ 首钩成立。** R-SCR-02 / R-SCR-08 专门防这一条：竖屏用户可能静音刷到，钩子必须是画面事件〔外部调研·F-STORY-20：开篇以最激烈冲突、近景特写抓人〕。字卡解释 = 把剧本问题推给剪辑（[`00-orientation/production-lifecycle.md`](../../00-orientation/production-lifecycle.md) §3 "看不懂"一行）。
- **"有悬念"≠ 集末卡点。** "未完待续""敬请期待"不是问题；R-SCR-06 要求能写出问句（"门外的人是谁？"）。惊奇式揭秘只留给以反转本身为看点的位置，其余默认"观众先看到炸弹"〔外部调研·F-STORY-06〕。
- **把 7.5 字/秒当规划语速。** 7.5 是塞得下的上限，按它排时长会被念得很赶、没有表演呼吸；剧本阶段一律按 4.1 字/秒估时（evidence-reconciliation R3）。见 [`60-casebook/cards/D3-dialogue-capacity.md`](../../60-casebook/cards/D3-dialogue-capacity.md)。
- **"含蓄"写法删掉了打斗。** "两人交手，尘土飞扬" 在剧本里看着完整，到分镜就只剩"动作瞬间 + 反应镜头"——R-SCR-10 在源头卡住它。见 [`60-casebook/cards/A2-missing-fights.md`](../../60-casebook/cards/A2-missing-fights.md)。
- **形容词在剧本里不拦，到提示词里就拦不住了。** 剧本里的"史诗般的一击"会被原样抄进分镜与提示词；R-SCR-11 在病灶阶段改成事件。见 [`60-casebook/cards/F3-patch-iteration.md`](../../60-casebook/cards/F3-patch-iteration.md)（特效 → 史诗两轮补丁）。
- **对标只看题材不看时间。** R-SCR-20 比的是首钩秒数、首转折秒数、卡点类型三个可测项，不是"风格像不像"。
