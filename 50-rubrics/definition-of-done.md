# "够好了"的可操作定义（Definition of Done）

> 回答 G8〔委托方实证〕："我需要一个可操作的'达标'定义，而不是每次被说'不够'。"
> 本文件是**交付声明的唯一依据**：任何成片交付必须声明"达到 L 几级"并附该级全部证据。
> 评分量表见 [`quality-model.md`](quality-model.md)（Q1–Q8，每维 0–3 分）。

---

## 1. 四级定义

| 级别 | 名称 | 一句话 | 谁来判 | 委托方历史位置 |
|---|---|---|---|---|
| **L0** | 技术合格 | 没出错 | 脚本（`[自动]`） | ✅ 一直在这里（check/render/verify 全绿）〔T-4〕 |
| **L1** | 看得懂 | 陌生观众能复述因果链，不出戏 | 冷观众 + 自我放映 | ❌ 从未测过〔GAP-2〕 |
| **L2** | 可发布 | 8 维都成立、无阻断缺陷、独立评审通过、平台合规 | 8 维评分 + 独立评审 + R-PUB | ❌ 被人类主创连续打回〔T-4〕 |
| **L3** | 有竞争力 | 钩子与完播设计达到对标作品水平，观众想看下一集 | 对标对照 + 冷观众"想不想看下一集" + 发布后数据 | ❌ 未发布〔GAP-1〕 |

**判决**：
1. 级别是**累进**的：L2 要求 L0、L1 全部满足。
2. 只有 L0 证据时，交付声明只能写："技术合格（L0），观感未验证"。**禁止**写"达标""可发布""质量通过"。〔F1、F2〕
3. 交付给人类主创审片的最低要求是 **L1 + 8 维自评 + 独立评审意见**（人类拍板点③，见 [`production-lifecycle.md`](../00-orientation/production-lifecycle.md)）。

---

## 2. 每级的通过条件与证据

### L0 · 技术合格（全部 `[自动]`）
- R-CUT 中全部 `[自动]` 条目通过：时长、分辨率 9:16、响度（委托方规格 -16 LUFS）、真峰、无坏帧、无黑场/冻结段（非设计）、素材存在性、字幕逐字对账。
- 全部镜头的 R-VID `[自动]` 条目通过：无烧录文字（抽检 + 目视证据）、PSNR 无死段、转写对账无缺句。
- **证据**：`run_all` 报告（JSON）存入 `review/l0-report.json`。

### L1 · 看得懂
- **自我放映**完成：连续观看一遍，记录"第一次困惑的时间点"；若存在困惑点，必须已修复或写明为什么是设计（悬念 ≠ 困惑）。
- **冷观众测试**（协议见 [`90-curriculum/cold-audience-protocol.md`](../90-curriculum/cold-audience-protocol.md)）：
  - 阈值〔学院推断，待生产验证〕：≥ 3 名冷观众中，**≥ 2/3** 能正确复述本集"主因果链"（谁想要什么 → 遇到什么阻碍 → 做了什么 → 结果如何）；
  - 无任何一处被 ≥ 2 名冷观众同时标记为"看不懂/出戏"的断点；
  - 若暂时无法找到人类冷观众，可用"冷观众替身"（另一个未见过任何制作文档的 agent 会话，只看成片抽帧序列 + 转写），但必须在报告中标注"替身测试，置信度降级"。
- **证据**：`review/self-screening.md`、`review/cold-audience/*.md`。

### L2 · 可发布
- L0 + L1 全部满足；
- **8 维评分**（[`quality-model.md`](quality-model.md)）：**每一维 ≥ 2**（成立），且 Q1 叙事与钩子 ≥ 2；阻断缺陷数 = 0；
- **独立评审**通过：另一会话按 [`20-craft/screening-review/SKILL.md`](../20-craft/screening-review/SKILL.md) 评审，无"阻断"级意见，或阻断意见已修复并复评；
- **平台合规**：R-PUB 中全部"合规"类条目通过（AIGC 标识、画幅与安全区、时长规格等，以外部调研为据）；
- **证据**：`review/quality-scorecard.md`（每维分数 + 每个分数的证据时间码）、`review/independent-review.md`、`publish-kit.md`。

### L3 · 有竞争力
- L2 全部满足；
- 8 维中**至少 3 维 = 3 分**（出彩），其中必须包含 Q1；
- **对标对照**：与开发阶段选定的 ≥ 3 部对标作品并排对照"开场钩子出现时间、首反转时间、集末悬念强度"，不劣于对标的中位水平〔学院推断〕；
- **冷观众"下一集意愿"**：≥ 2/3 冷观众回答"想看下一集"并能说出想知道的具体问题；
- 发布后：用平台留存曲线校准（数据回流到下一集的开发阶段）〔外部调研，见 [`10-theory/09-platform-publishing.md`](../10-theory/09-platform-publishing.md)〕。
- **证据**：`review/benchmark-compare.md`、冷观众记录。

## 3. 阻断缺陷（任何一条存在 → 不得声明 L2 及以上）

| 阻断缺陷 | 维度 | 溯源 |
|---|---|---|
| 冷观众无法复述主因果链（≥ 2/3 失败） | Q1 | F1, A1 |
| 角色身份漂移（正脸与板图不符）且无剧情理由 | Q7 | B1 |
| 空间混乱：角色左右位置在段内无理由互换 / "乱跑" | Q2 | A5 |
| 承诺的打斗没有任何可见的交手回合 | Q3 | A2 |
| 画面中出现生成器自行添加的文字/水印/字幕 | Q5 | D1, D2 |
| 台词缺句、轧词、或字幕与声音不一致 | Q8 | D3, P7 |
| 克隆脸（≥2 人同框且脸雷同） | Q7 | B3 |
| 禁用项出现在主角/BOSS/核心道具上 | Q7 | C1 |
| 缺少平台要求的 AIGC 标识 | 合规 | GAP-1（外部调研） |

## 4. 交付声明模板

```markdown
## 交付声明 · S01E03
- 达到级别：L1（看得懂）；L2 未达成，原因：Q6 节奏与速度 = 1（SEQ-04 全段无速度层次），修复已排期。
- L0 证据：review/l0-report.json（12/12 自动条目通过）
- L1 证据：review/self-screening.md（第一次困惑点：无）；review/cold-audience/（3 人，3/3 复述正确）
- 8 维评分：Q1=2 Q2=2 Q3=2 Q4=2 Q5=2 Q6=1 Q7=3 Q8=2（见 review/quality-scorecard.md）
- 独立评审：review/independent-review.md（1 条阻断：已修复；复评通过）
- 未验证项：发布后数据（未发布）
```

**→ 行为改变**：下次写成片报告时，先填交付声明；任何一级证据缺失，就把那一级写成"未验证"，而不是省略它。
