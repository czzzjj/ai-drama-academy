# 全片质量模型（Q1–Q8）

> 回答 F3 / G1〔委托方实证〕："反馈是抽样，不是全集——人类看到的每个问题背后有一个完整质量模型。"
> 本文件定义这个"完整质量模型"：8 个维度、每维 0–3 分、每个分数的**可观察锚点**、检查方法、阻断缺陷、评分卡模板，以及收到任何反馈后的**全维度自查协议**。
> 上游：[`50-rubrics/definition-of-done.md`](definition-of-done.md)（L2 = 8 维全部 ≥2 且无阻断；L3 = ≥3 维为 3 分且含 Q1）。下游：[`50-rubrics/README.md`](README.md) 中各阶段清单（R-SCR … R-PUB）与脚本。
> 执行技能：[`20-craft/screening-review/SKILL.md`](../20-craft/screening-review/SKILL.md)。

## 0. 怎么用（先读这一节）

1. **8 维同时打分，永远不单独打一维。** 任何一次自评、评审、返工后复评，都必须产出完整 8 行评分卡（§10）。只改被点名的那一维 = F3 补丁式迭代。〔委托方实证·F3〕
2. **分数必须挂证据。** 每个分数至少一条"时间码 + 证据文件"；没有证据的分数按 0 计。"看过了，挺好" 不是证据（C2）。〔委托方实证·C2、F1〕
3. **维度分 = 全片最差段的分（短板原则）。** 逐段（SEQ）打分后取最低值作为全片该维分数；只有 3 分例外（见第 4 条）。理由：观众在最差的那一段出戏，前后段再好也救不回来；一个 0 分段就是阻断。〔学院推断；验证：把逐段最低分与人类主创的整集结论对照，连续 3 集一致率 ≥2/3 则保留，否则改为"加权 + 阻断"口径〕
4. **3 分 = 全部段 ≥2，且至少 1 处被外部视角独立点名**（冷观众或独立评审在没有提示的情况下主动提到它）。自己觉得出彩不算 3 分。〔委托方实证·F1；外部调研·F-CASE-21：LLM 评审给自己生成的内容打分偏高〕
5. **技术指标只能证明"没有 0 分的技术原因"，不能证明 2 分。** `loudness_verify.py` 全绿 ≠ Q8 ≥2；"固定镜头 = 0" ≠ Q2 ≥2。〔委托方实证·F2〕
6. **空间（Q2）与一致性（Q7）是独立闸门。** Murch 排序（情绪 > 故事 > 节奏 > 视线 > 2D > 3D）只用于两个好选项冲突时取舍；AI 生成里越轴、乱跑、漂移是最高频缺陷，不得以"情绪对了"为由放过。〔外部调研·S-STORY-13；evidence-reconciliation R7〕
7. **绝对打分不可靠，3 分与跨轮比较一律用两两对照。** 多模态模型评审在两两比较上接近人类、在绝对打分上偏差明显；比较时交换顺序各看一次。〔外部调研·F-CASE-25、F-CASE-19〕

### 量表通则

| 分 | 名称 | 观众反应（判定口径） | 交付含义 |
|---|---|---|---|
| **0** | 缺席 / 错误 | 有致命缺陷：该维要求的东西不存在，或存在但错了；观众会直接说"看不懂 / 穿帮 / 没有 X" | 阻断，不得声明 L1 以上〔definition-of-done §3〕 |
| **1** | 存在但不成立 | 东西在，但观众会出戏：注意到"不对劲"、困惑、走神 | 不得声明 L2 |
| **2** | 成立 | 不出戏、看得懂；观众不会注意到这一维 | L2 要求每维 ≥2 |
| **3** | 出彩 | 会被记住 / 想分享：观众主动提起它 | L3 要求 ≥3 维 = 3 且含 Q1 |

方法标签：`[自动]` 脚本可判；`[目视]` agent 或评审 agent 亲自看/听并留证据文件；`[冷观众]` 无背景观看者（协议见 [`90-curriculum/cold-audience-protocol.md`](../90-curriculum/cold-audience-protocol.md)）。

## Q1 · 叙事与钩子

**管什么**：主因果链能否被复述；开场钩子、首反转、核心反转、集末悬念；每场是否"转"了。**不管**：画面好不好看（Q5）、剪得快不快（Q6）。

| 分 | 可观察锚点（满足全部才给该分） |
|---|---|
| 0 | 冷观众 ≥2/3 无法复述主因果链（谁想要什么 → 阻碍 → 做了什么 → 结果）；**或**本集没有任何未解问题收尾（停在解决之后）且开头 10s 无事件 |
| 1 | 因果链能复述，但：首个钩子出现在 5s 之后 / 首钩是台词或字卡而非画面事件 / 全集没有"有对手的反转" / 集末悬念是泛泛的"未完待续"而非具体问题 / ≥2 名冷观众在同一处标记"看不懂" 之一成立 |
| 2 | ≥2/3 冷观众正确复述主因果链；无 ≥2 人共同的"看不懂"断点；首钩 ≤5s 且静音可读；≥1 次有对手的反转；末 10s 内停在一个可被说出的具体问题上 |
| 3 | 2 分全部成立 + ≥2/3 冷观众回答"想看下一集"并能说出想知道的**具体**问题；开场钩子、首反转时间、集末悬念强度与 ≥3 部对标并排对照不劣于中位（两两对照） |

- 数字来源：首钩 ≤5s〔外部调研·F-ZEN-16，"起点，不是质量线"〕；"前三秒必有钩子""每 30 秒一个情绪拐点，每集一个核心反转"〔外部调研·F-STORY-19〕；"15–20 秒内设置一个剧情转折或高潮，每集最后 10 秒留下悬念"〔外部调研·F-STORY-18〕；卡点四类：揭示 / 反转 / 期限 / 闯入〔外部调研·F-STORY-22〕。全部是行规或起点值，委托方从未发布过作品〔委托方实证·GAP-1〕——阈值属〔学院推断〕，验证法：发布后用留存曲线的 dip 位置校准（YouTube 留存图 dip = 跳过或离开〔外部调研·F-CASE-16〕）。
- **检查方法**：
  - `[目视]` R-SCR 钩子类条目（[`50-rubrics/checklists/script.md`](checklists/script.md)，R-SCR-01 … R-SCR-08）在剧本阶段先过；成片阶段在 `review/self-screening.md` 写出钩子 / 首反转 / 核心反转 / 悬念的**实际时间码**，与剧本估时比较。
  - `[目视]` 静音放映：关声音和字幕看一遍，写出主因果链；写不出 → 是台词在讲故事，画面没讲（F2 卡判据 5）。
  - `[冷观众]` 复述主因果链 + "第一次困惑点" + "想不想看下一集、想知道什么"。
  - `[目视]` 季级：卡点类型不连续重复，见 [`50-rubrics/checklists/season.md`](checklists/season.md)。
- **常见反例**：[`60-casebook/cards/A1-fragmented-shots.md`](../60-casebook/cards/A1-fragmented-shots.md)（「片段式、剧情跳跃、无法理解」——因果链被一个动作一个镜号切断）、[`60-casebook/cards/F1-self-verification-loop.md`](../60-casebook/cards/F1-self-verification-loop.md)（从未测过冷观众，Q1 从来没被验证过）。
- **阻断缺陷**：冷观众复述主因果链失败率 ≥2/3〔F1、A1〕。

## Q2 · 空间与调度

**管什么**：谁在哪、朝哪、往哪移动；轴线与屏幕方向；镜头语言设计——景别序列、机位、运镜**为什么**在此刻这样动。人类说"运镜"时，指的是这一维，不是"相机位移次数"〔委托方实证·G6、A4；见 [`00-orientation/glossary.md`](../00-orientation/glossary.md) B 表〕。

| 分 | 可观察锚点 |
|---|---|
| 0 | 段内角色左右位置无理由互换 / "乱跑"；或 `direction_audit.py` 不通过却已出片；或冷观众 ≥2 人答错"谁在哪一侧、谁在追谁" |
| 1 | 方位不乱，但：运镜说不出因果（全段匀速同一运动 = "耿直"；或为动而动 = 炫技）/ 相邻镜屏幕方向不连续（画右出→画右入）/ 景别无序列（整段同一景别）/ 冷观众注意到"镜头在动"的位置没有对应因果句 之一成立 |
| 2 | 每段首/中/末格每个角色都在声明侧（接触表证据）；同场相邻镜守 180°；每个运镜有因果句且在产出中兑现（推近 → 末格主体明显更大）；关键接触有镜头响应（顿挫/震动）；冷观众能说出相对位置 |
| 3 | 2 分全部成立 + 调度本身在讲故事：景别/机位序列强化关键拍（接触顿挫、揭示上摇、收束拉回），被独立评审或冷观众主动提起；竖屏纵深分层清楚（前景/主体/背景各有职责） |

- **检查方法**：
  - `[自动]` `direction_audit.py`（R-VP-04、R-VP-05、R-VP-06）、`segment_rhythm.py` 的 `A4-cause` / `A5-beats-many`（R-SB-08、R-SB-06）。
  - `[目视]` `contact_sheet.py <clip> --keyframe <REF-SHOTnnn-START>`：首/中/末格逐人核对方位；运镜看首末格主体尺寸与机位高度变化。单张静帧不判动作，看连续格。
  - `[目视]` 成片切点逐帧：画右出 → 画左入；合法越轴只有三种（轴上缓冲镜、可见的跨轴运镜、角色自己走过轴线）〔外部调研·F-STORY-13〕。
  - `[冷观众]` 看完打斗段问"谁在哪一侧、谁在追谁、BOSS 在场地哪里"。
- **常见反例**：[`60-casebook/cards/A5-spatial-chaos.md`](../60-casebook/cards/A5-spatial-chaos.md)（「又变成苏晓乱跑、分镜和场地和 BOSS 位置混乱的效果了」：起始帧钉了神左苏晓右，提示词写 `trucks left`/`arcs around`）、[`60-casebook/cards/A4-unmotivated-camera.md`](../60-casebook/cards/A4-unmotivated-camera.md)（「苏晓冲击镜头过于耿直，没有运镜和合理的打斗逻辑」：固定镜头 = 0 全绿但无运镜设计）。
- **阻断缺陷**：角色左右位置在段内无理由互换 / 乱跑〔A5〕。

## Q3 · 动作与物理

**管什么**：承诺的打斗/动作是否真的发生；交手回合、战术链、七相动作链（意图 → 预备 → 发力 → 接触 → 反应 → 回收 → 后果）；重量、接触、后果是否可信。人类说"打斗逻辑"时指这一维的因果链，不是"动作多一点"〔委托方实证·G6、A2〕。**不管**：特效形态（Q4）、整片速度层次（Q6）。

| 分 | 可观察锚点 |
|---|---|
| 0 | 剧本承诺的打斗在成片里没有任何同框可见的交手回合（被"动作瞬间 + 反应镜头"替代）；或主体动作肢体崩坏/穿模且留在成片 |
| 1 | 有交手但不成立：接触是单动词（碰一下没反应）/ 接触后无可见后果 / 动作漂浮无重量（"月球重力"式慢落）/ 冷观众只能说"他们打了一架" 之一成立 |
| 2 | 每场打斗 ≥1 个完整交手回合（我攻 → 你挡/闪 → 我变招）在一个镜头内同框可见，含接触与反应；每次接触后有可见后果（位移、失衡、环境变化）；冷观众能复述战术链（谁先出手、怎么落空、怎么反制、为什么赢） |
| 3 | 2 分全部成立 + 战术链有变招与反转、利用环境；重量感来自停顿（"Weight comes from the stop, not the drop"）；某个动作瞬间被冷观众或独立评审主动复述 |

- 外部依据：武打拍可密（约 3 秒 8–9 招按顺序真速度完成〔外部调研·F-H3-17〕）；双人接触写全"接近—接触—施力—结果"才有效，只写一个动词最差〔外部调研·F-ZEN-13〕；动作与反应同框、"疼痛让人像人"〔外部调研·F-STORY-12〕；真实摔倒约 0.4–0.6s，写长时长会被执行成慢动作〔外部调研·F-H3-23〕。
- **检查方法**：
  - `[目视]` 动作设计文档：每场打斗的战术链（≥3 环）+ 每次接触的七相表（R-SCR-10、R-SB-19、R-SB-20）。
  - `[自动]` `prompt_lint.py` `VP-realtime` 0 error（R-VP-03）。
  - `[目视]` `contact_sheet.py` 接触表上标出攻 / 挡 / 变招 / 后果的格号；`psnr_scan.py` 相邻帧 PSNR 长期落在"呼吸级"区间 → 疑似没动起来，回接触表确认（A3 卡判据 3，阈值待校准）。
  - `[冷观众]` 复述战术链。
- **常见反例**：[`60-casebook/cards/A2-missing-fights.md`](../60-casebook/cards/A2-missing-fights.md)（「几乎没有做 BOSS 打斗」：防御性策略被当成叙事语言）、[`60-casebook/cards/A3-slow-motion-default.md`](../60-casebook/cards/A3-slow-motion-default.md)（「全是几个简单动作的慢镜头」）。
- **阻断缺陷**：承诺的打斗没有任何可见的交手回合〔A2〕。

## Q4 · 特效与事件

**管什么**：能量 / 魔法 / 破坏 / 符号等"非日常事件"是否写成**事件**——来源 → 接触 → 扩散 → 后果；关键符号与质感是否正确；"史诗感"的事件与尺度部分。人类说"特效不够""不够史诗"时先看这一维，再看 Q5/Q6/Q8〔委托方实证·G5、M3〕。

| 分 | 可观察锚点 |
|---|---|
| 0 | 剧情关键符号/特效形态错误（多一根横线成十字、火纹成霓虹/激光）；或生成器自行加入具象光柱/光源物件并留在成片 |
| 1 | 特效存在但是"贴上去的光"：看不出能量从哪来、在哪接触、留下什么；提示词里仍有未拆解的评价词（epic / spectacular / 华丽）；特效与动作节拍不同步 |
| 2 | 每个特效在画面中可见 来源 → 接触 → 扩散 → 后果 中至少三相（"冲击环从接触点炸开" 而不是 "特效华丽"）；关键符号与对抗约束清单逐条一致（放大裁剪证据）；质感与锚点卡一致 |
| 3 | 2 分全部成立 + 尺度对比（渺小的人 vs 巨大对象同框）、环境后果（地裂、碎石、气浪）、蓄力停顿 → 爆发、低频冲击声四层合力；冷观众或独立评审主动说出"震撼/史诗"一类评价并能指出时间点 |

- **检查方法**：
  - `[自动]` `prompt_lint.py` `VP-adjective`（未拆解评价词）、`VP-symbol`（符号对抗约束）、`VP-light`（具象光柱物件）（R-VP-12、R-VP-14、R-VP-16）。
  - `[目视]` `contact_sheet.py --crop sym=x:y:w:h` 放大符号区域，与锚点卡对抗约束清单逐条比对。
  - `[目视]` "史诗感"五栏拆解表：起始帧可见属性 / 事件 / 后果 / 声音 / 节奏，任一栏为空则 Q4 ≤2〔学院推断，来自 G5 机理；验证：对同一段做"五栏齐 vs 缺一栏"A/B，让独立评审两两对照〕。
- **常见反例**：[`60-casebook/cards/D4-symbol-errors.md`](../60-casebook/cards/D4-symbol-errors.md)（"ф"印记画成十字；火纹写成霓虹/激光）、[`60-casebook/cards/B3-clone-faces.md`](../60-casebook/cards/B3-clone-faces.md)（同镜被添加不存在的具象斜光柱）、[`60-casebook/cards/F3-patch-iteration.md`](../60-casebook/cards/F3-patch-iteration.md)（r1→r5 中"特效→史诗"两轮各修一点仍"不够"）。
- **阻断缺陷**：剧情关键符号画错（观众会读错信息）〔D4〕——归入 L2 阻断时按 Q4 = 0 处理。

## Q5 · 美术与密度

**管什么**：构图、主体可读性、色彩剧本与光态、画面信息密度（前中后景层次）、画面中**不该有的东西**（生成器自加的文字/水印/人群扩写）、画幅规格。**不管**：角色是否和板图一致（Q7）。

| 分 | 可观察锚点 |
|---|---|
| 0 | 画面出现生成器自行添加的文字 / 水印 / 字幕；或交付画幅不是 9:16（2:3 图被拉伸挤压，正圆变椭圆） |
| 1 | 眯眼去色后主体剪影读不出 / 同场相邻镜光源方向或色温跳变 / 无色彩剧本（每镜光色随模型发挥）/ 人群或背景被扩写出无关具象物 / 画面空洞或塞满到主体被淹没 之一成立 |
| 2 | 每镜眯眼去色后主体剪影可读；同场光源方向与色温一致；色彩剧本存在且每段主色/光态与之相符；起始帧通过海报测试（单看这一帧知道谁、在哪、发生什么）；无多余具象元素 |
| 3 | 2 分全部成立 + 起始帧可直接作封面/海报；色彩随情绪弧有可说出的变化；前中后景各有职责；被冷观众或独立评审主动提起画面 |

- 外部依据：关键帧官方 9:16 尺寸 1536×2752，`first_frame` 不保比例直接拉伸〔外部调研·S-COMFY-01、F-H3-07〕；有动机布光 = 光有来源〔外部调研·S-CRAFT-14〕；一场统一光与色温后关键帧亮度离散度 18.3→6.6〔外部调研·F-ZEN-15〕。
- **检查方法**：
  - `[自动]` `burnin_text_scan.py`（`D1-burnin-text` / `D2-watermark`；无 OCR 时明确降级 → 必须补目视）；`loudness_verify.py` `T3-aspect`（成片 >1% 偏离 9:16 → error）；`contact_sheet.py` `T2-aspect`（单镜 >2% → warn）。
  - `[目视]` 眯眼去色测试（接触表转灰度、缩小到 1/8）；同场关键帧并排看光向与色温。
  - `[目视]` 板图/关键帧阶段清单：`R-BRD`、`R-KF`（海报级）、`R-COL`（色彩灯光）。

- **阻断缺陷**：画面中出现生成器自行添加的文字/水印/字幕〔D1、D2〕。

## Q6 · 节奏与速度

**管什么**：段/拍/镜结构（有效拍数，而非切镜数）；段内速度层次（快-慢-爆-静）；情绪拐点间隔；切点位置（动作中切）；音乐节拍与剪辑点。人类说"片段式""切点跳脱""慢镜头""死板""拖"时看这一维。

| 分 | 可观察锚点 |
|---|---|
| 0 | 碎镜症：生成镜均长 <5s 且无短镜理由（`A1-mean-short`），冷观众或自我放映标出"跳跃/片段式"；**或**全片单一速度（所有动作都是慢镜，没有一处实时速度） |
| 1 | 段结构成立，但：某段内无速度层次 / ≥2 名冷观众在同一段标"拖/走神" / 切点不在动作中（静止切静止、跳切）/ 相邻情绪拐点间隔 >30s / 音乐重音与剪辑点无关 之一成立 |
| 2 | 每个动作段有 ≥2 种速度层次且"慢"处写明设计理由；相邻情绪拐点 ≤30s；无共同"拖/跳"标记；切点在动作进行中；配乐进出与剪辑点对齐 |
| 3 | 2 分全部成立 + 停-爆-停结构清楚，独立评审或冷观众主动描述某段"节奏带劲/一口气看完"；冷观众无任何"拖"标记 |

- 外部依据：港片 12 分钟约 490 镜仍"totally intelligible"，靠动作匹配与 180° 规则〔外部调研·F-STORY-09〕——**短剪不是罪，碎镜症是罪**（evidence-reconciliation R6）；pause/burst/pause 结构〔外部调研·F-STORY-10〕；"每 30 秒一个情绪拐点"〔外部调研·F-STORY-19〕。
- **检查方法**：
  - `[自动]` `segment_rhythm.py`：`A1-short-no-reason` / `A1-mean-short` / `A1-short-share` / `T2-over-max`（R-SB-01 … R-SB-04）；成片 `psnr_scan.py --mode final --edit-list edit-list.md` 列出切点（`P8-cut-*`）。
  - `[目视]` 速度层次标注（R-SB-18）、事件时长预算（R-SB-19）；成片切点帧序列逐个看是否 cutting on action。
  - `[冷观众]` 记录"拖 / 慢 / 走神 / 跳"的时间点。
- **常见反例**：[`60-casebook/cards/A1-fragmented-shots.md`](../60-casebook/cards/A1-fragmented-shots.md)（29 镜均长 2.96s；「切片太短，切点跳脱感强」）、[`60-casebook/cards/A3-slow-motion-default.md`](../60-casebook/cards/A3-slow-motion-default.md)（慢成为默认，没有节拍设计）。
- **阻断缺陷**：无独立阻断项；Q6 = 0（碎镜症或全片单速）时本维 <2，按 L2 规则不得声明可发布。

## Q7 · 一致性与连续性

**管什么**：角色身份（脸、发、服装、标志物）跨镜跨集一致；≥2 人同框可区分；禁用项不出现；关键帧 → 视频的背景元素一致；道具/伤痕/状态连续；提示词与已验收产出是同一事实；季内音色绑定（与 Q8 共管）。人类说"穿帮"时先看这一维。

| 分 | 可观察锚点 |
|---|---|
| 0 | 主角/BOSS 正脸与板图不符且无剧情理由；或 ≥2 人同框脸雷同（克隆脸）；或禁用项出现在主角/BOSS/核心道具上 |
| 1 | 主角稳，但次要角色/道具跨镜漂移、视频中出现关键帧没有的背景元素（"第二骨架"）、服装细节或伤痕状态跨镜变化可被注意到、提示词描述与已验收产出不一致（E4） 之一成立 |
| 2 | 正脸库：每集主角 ≥1 个正脸镜与板图逐特征比对通过（裁剪证据）；≥2 人镜每张脸可区分；禁用项放大核验零命中；关键帧与视频前中后段背景元素清单一致；道具与伤痕状态跨镜连续 |
| 3 | 2 分全部成立 + 跨集连续（服装破损、伤、道具持有、音色）全部对得上；连续性成为叙事资产（伏笔道具在回收时精确一致），被独立评审确认 |

- 外部依据：同一人给两张脸参考可能生成两个人〔外部调研·F-H3-22〕；平台治理"高频 AI 脸"，要求主要角色有清晰区分度——克隆脸从质量问题升级为下架风险〔外部调研·S-PLAT-07〕；连续性锁须逐字出现在图片、关键帧、视频提示词中〔外部调研·F-ZEN-23〕。
- **检查方法**：
  - `[自动]` `prompt_lint.py` `VP-anchor`（锚点句逐字）、`VP-distinct`（差异化句）（R-VP-09、R-VP-08）。
  - `[目视]` `contact_sheet.py <clip> --keyframe <REF> --crop face=…`：脸、方位属性（左右臂）单独放大并与板图并排；高风险资产第二遍复验由独立会话做〔C2〕。
  - `[目视]` 背景元素清单：关键帧列出的元素 vs 视频首/中/末格。
  - `[目视]` 季级：锚点句跨集 diff、正脸库、状态账本、音色绑定（[`50-rubrics/checklists/season.md`](checklists/season.md)）。
- **常见反例**：[`60-casebook/cards/B1-character-drift.md`](../60-casebook/cards/B1-character-drift.md)（苏晓漂成"粗犷成熟脸"）、[`60-casebook/cards/B3-clone-faces.md`](../60-casebook/cards/B3-clone-faces.md)、[`60-casebook/cards/B4-duplicate-artifacts.md`](../60-casebook/cards/B4-duplicate-artifacts.md)、[`60-casebook/cards/C1-banned-items-violated.md`](../60-casebook/cards/C1-banned-items-violated.md)（宝石、全套铠甲、金色颈饰、左右臂反了）、[`60-casebook/cards/C2-lenient-acceptance.md`](../60-casebook/cards/C2-lenient-acceptance.md)、[`60-casebook/cards/E4-prompt-output-mismatch.md`](../60-casebook/cards/E4-prompt-output-mismatch.md)。
- **阻断缺陷**：身份漂移（无剧情理由）〔B1〕；克隆脸〔B3〕；禁用项出现在主角/BOSS/核心道具上〔C1〕。

## Q8 · 声音与对白

**管什么**：台词完整、不轧词、口型落在对的人身上、字幕与声音逐字一致；声音层次（环境 / 拟音 / 音效 / 音乐 / 静场）；音乐↔剪辑点；音色可分；响度与真峰。委托方只有"对白 + 基础拟音 + 非叙事配乐"〔委托方实证·GAP-3〕——本维 2 分以上的方法全部来自外部调研。

| 分 | 可观察锚点 |
|---|---|
| 0 | 缺句 / 轧词 / 字幕与声音不一致；或口型落在不说话的人身上；或无对白镜出现模型自配的人声/乱语留在成片 |
| 1 | 台词齐，但：声音只有对白 + 通用配乐、没有环境层 / 关键接触无拟音或音效 / 两个角色音色难以区分 / 配乐与剪辑点无关、段间响度跳变 / 对白被念得很赶（`D3-rushed` 未处理）之一成立 |
| 2 | 对白逐字齐全、口型对人；每段有环境层；每次关键接触有拟音/音效；配乐进出点落在剪辑点；同场说话人盲听可区分；成片 -16 LUFS ±1、真峰 ≤ -1 dBTP |
| 3 | 2 分全部成立 + 声音承担叙事：静场后的冲击、画外声引出新信息、J/L cut 让声音先于画面带人进场；冷观众闭眼只听一段仍能说出情绪走向 |

- 外部依据：响度 GY/T 377-2023 与真峰 ≤ -1 dBTP〔外部调研·S-COMFY-12〕；非说话人写 `lips remain completely closed` 后口型 3/3 正确〔外部调研·F-ZEN-08〕；`non_diegetic_music` 省略时 3 次中 2 次自配乐〔外部调研·F-ZEN-07〕；L/J cut 用声音控制时间〔外部调研·S-CRAFT-04〕；Murch "dense clarity / clear density"：同一时刻可清楚分辨的声音层有限〔外部调研·S-CRAFT-01〕。
- **检查方法**：
  - `[自动]` 设计期 `dialogue_capacity.py`（`D3-capacity` / `D3-margin` / `D3-split` error，`D3-rushed` warn）（R-SB-14、R-SB-15）；`prompt_lint.py` `VP-lipsync`、`VP-music`、`VP-dialogue`（R-VP-17 … R-VP-19）。
  - `[自动]` 出片后 `transcript_reconcile.py`（`TR-missing` / `TR-script-prompt` / `TR-speaker`）；成片 `loudness_verify.py`（`T4-lufs` / `T4-true-peak`）。
  - `[目视]` 双通道：转写异常必须配抽帧口型或听感，单通道不判决〔D5〕；低置信做 `--windows` 三窗复核。
  - `[目视]` 声音层次表：每段列 环境 / 拟音 / 音效 / 音乐 / 静场 五栏（`R-SND`）。
- **常见反例**：[`60-casebook/cards/D3-dialogue-capacity.md`](../60-casebook/cards/D3-dialogue-capacity.md)（同一镜换 3 个 seed 各缺不同句——换 seed 无解）、[`60-casebook/cards/D5-qc-tools-lie.md`](../60-casebook/cards/D5-qc-tools-lie.md)（无对白镜被转写成"字幕by索兰娅"；低笑气声被误听为"救我"）。
- **阻断缺陷**：台词缺句、轧词、或字幕与声音不一致〔D3、P7〕。

## 11. 全维度自查协议（收到任何反馈后必走；回答 F3 / G1）

> 触发：人类主创反馈、独立评审意见、冷观众断点、自我放映困惑点——**任何一条**。
> 禁止：只修被点名的那一处就重新提交。〔委托方实证·F3：r1→r5 每轮只修最新一条（运镜→特效→史诗→空间），修好一个暴露另一个〕

1. **逐字记录**：反馈原话逐字写进 `review/defects.md`，一条一行；不改写、不概括。
2. **翻译到维度**：用 §12 映射表把每个词归到主维度 + 次维度；翻译不确定（两种设计层解释都说得通）→ 对同一段做 A/B 两版最小样，让人类选，结果写入记忆〔G6〕。
3. **全片同类搜索**：在全片所有段里搜同类缺陷（例：反馈点名 SHOT-012 方位乱 → 跑全集 `direction_audit.py` + 看全部多人段的接触表），结果写 SHOT 列表或"已搜，无"；为空则该条不得标"已修"。
4. **病灶路由**：按 [`00-orientation/production-lifecycle.md`](../00-orientation/production-lifecycle.md) §3 判断病灶阶段，回到那个阶段修（空间乱 → 分镜/起始帧；缺句 → 剧本/分镜容量；不是 seed 问题）。同一症状第二次出现且处置仍是"重抽" → 不允许，必须改设计〔D3〕。
5. **修复后重跑全集 `[自动]`**：生成前 6 个脚本 + 出片后 4 个 + 成片 2 个（链见 [`50-rubrics/README.md`](README.md) §5），`--json` 留档；与上一轮 JSON 比较，出现上一轮没有的 error 代码 = 回归。
6. **8 维全部重打分**：不是只打被点名的那一维。任一维低于上一轮 = 回归，修复前不得提交。
7. **独立评审复评**：新开会话，只给成片 + 本文件 + 阶段清单，不给缺陷单与辩护理由；自评与复评取低分。
8. **按反馈涉及的层补外部视角**：改动触及剧本或分镜层 → 重跑冷观众；上一轮断点不得在原位置复现。
9. **提交说明**：写全 8 维本轮/上轮分数与变化，而不是"已按意见修改 X"。
10. **回流**：本轮人类指出、而自查没先发现的问题 → 在对应阶段清单新增一条 R-xxx（溯源写本次反馈对应的案例编号），并写成找错题回流题库〔G4〕。

**最低分优先**：人类只说"仍不够""还是不行"时，不要猜它指哪一处——直接把评分卡里**最低分的维度**当成本轮主修对象；若多维同为最低，先修上游（Q1 → Q2/Q3 → Q6 → 其他），因为上游维度的缺陷会掩盖下游〔学院推断；验证：记录每轮主修维度与人类下一次反馈的维度，若人类反馈仍集中在已"修好"的维度，说明评分偏高，收紧锚点〕。
