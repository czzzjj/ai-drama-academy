# 审美判据卡（TJ-01 – TJ-18）

> 用途：把"好不好看"拆成**能做、能留证据、能判真假**的测试。它们补的是指标之上的观感判断：技术全绿以后，人类为什么还说不行（F2、G2）。
> 每张卡的结构：**检查句**（可判真假）→ **怎么做**（命令和步骤）→ **通过标准** → **常见误判** → **溯源** → **挂在哪道闸门**。
> 证据文件：镜头级放 `qc/<SHOT>/`，成片级放 `review/taste/`，文件名写进验收记录。没有证据文件的 TJ 结论，一律视为没做（C2）。
> 诚实标注：多数阈值是〔学院推断〕，卡内写了怎么验证。委托方实证只覆盖与 A–F 案例直接对应的部分。
> 涉及的脚本（只用其真实选项）：[`50-rubrics/scripts/contact_sheet.py`](../50-rubrics/scripts/contact_sheet.py)、[`50-rubrics/scripts/psnr_scan.py`](../50-rubrics/scripts/psnr_scan.py)、[`50-rubrics/scripts/burnin_text_scan.py`](../50-rubrics/scripts/burnin_text_scan.py)、[`50-rubrics/scripts/direction_audit.py`](../50-rubrics/scripts/direction_audit.py)。
> 命令里的路径（`kf.png`、`final/ep03.mp4`、`clip.mp4`）是占位，替换成实际路径。

## TJ-01 · 眯眼去色层级测试
- **检查句**：画面缩小、模糊、去色之后，第一眼落点仍是设计的主体，明度能分出 ≥3 个层级（主体 / 次要 / 背景）。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i kf.png -vf "scale=iw/8:-2,format=gray,gblur=sigma=2,scale=270:-2:flags=neighbor" qc/SHOT-012/kf-squint.png
  ffmpeg -v error -y -i kf.png -vf "scale=270:-2,format=gray" qc/SHOT-012/kf-poster270-gray.png
  ```
  看图回答三问并写进记录：① 第一眼落在哪？② 那里是不是设计的主体？③ 数得出几个明度层级？视频镜头先跑 `contact_sheet.py clip.mp4`，再对接触表做同样的去色处理。
- **通过标准**：第一眼落点 = 设计主体；层级 ≥3；冲突双方的相对关系可读（R-KF-07）。程度类属性（如黑臂与白臂的对比）去色后一眼可辨（R-BRD-07）。
- **常见误判**：① 拿"颜色好看"当层级，去色后红绿同明度，层级就消失了；② 在原尺寸上看，手机上实际看到的是缩略效果；③ 低调画面一片黑，不等于有层级。
- **溯源**：C1-7（黑臂对比弱被放行）、M2、Q5；阈值 3 层与 1/8 缩放比例为〔学院推断。验证：对人类判过"平""看不清"的历史帧和已通过的帧各跑一次，能把两组分开才算成立〕。
- **闸门**：R-KF-07、R-BRD-07、R-COL-08。

## TJ-02 · 剪影可读性
- **检查句**：主体二值化成纯黑剪影之后，仍能说出"是谁、在做什么动作、朝哪边"。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i kf.png -vf "scale=270:-2,format=gray,lutyuv=y='if(lt(val,110),0,255)'" qc/SHOT-012/kf-silhouette.png
  ```
  阈值 110 按画面调整，低调画面降到 60–80。角色板版本：把每个主要角色的剪影并排（用 `hstack`），检查两两能否区分。
- **通过标准**：动作剪影里，四肢、武器和躯干之间留有负空间，动作方向一眼可读；二维、Q 版、三维风格中，主要角色的剪影两两可分〔外部调研·S-ZEN-20：二维动态漫的剪影测试〕。
- **常见误判**：① 主体和背景明度相同，剪影糊成一团。这是主体与背景的分离问题（要靠轮廓光、纵深解决），不是动作设计问题；② 把阈值反复调到"刚好能看出"，然后判通过。
- **溯源**：S-ZEN-20、A2（动作看不清就等于打斗缺席）、B3；〔学院推断：二值化阈值法。验证：同一画面在 3 个阈值下结论一致，才算可靠〕。
- **闸门**：R-BRD-16、R-KF-07。

## TJ-03 · 画面密度
- **检查句**：画面里能被单独叫出名字的元素中，只有 1 个主焦点、≤2 个次焦点，其余都是纹理或虚化背景；没有设计之外的具象物。
- **怎么做**：对关键帧，或 `contact_sheet.py clip.mp4 --keyframe kf.png` 的接触表，逐格写一份"元素清单"：人、道具、建筑、光源、文字，每项标上 主 / 次 / 背景。再与分镜 `内容` 和锚点卡对比，清单里多出来的就是生成器自己加的（B2 人群扩写、B4 第二骨架、C1 装饰物）。
- **通过标准**：主焦点 1 个；次焦点 ≤2 个；自加物 0 个；画面的空白区域写得出它承担什么（留白要有职责，不是没画完）。
- **常见误判**：① 把纹理细节（锁子甲花纹）当成独立元素去数；② 把设计过的留白当成空洞。先查 `visual-bible.md` 有没有登记这片留白。
- **溯源**：Q5（"画面空洞或塞满到主体被淹没"计 1 分）、B2、B4、C1；〔外部调研·S-ZEN-20：背景密度过高抢走注意力〕；阈值"1 主 + ≤2 次"为〔学院推断。验证：独立评审盲选同场的两个版本，看选择是否与密度结论一致〕。
- **闸门**：R-KF、R-VID-02（背景元素清单）。

## TJ-04 · 第一帧海报测试
- **检查句**：只看这一帧（缩到 270 宽），能写出三句话：主体是谁、在哪里、正在发生或即将发生什么冲突。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i final/ep03.mp4 -frames:v 1 -vf scale=270:-2 review/taste/ep03-frame0.png   # 集首帧
  ffmpeg -v error -y -i keyframes/REF-SHOT012-START.png -vf scale=270:-2 qc/SHOT-012/poster270.png  # 镜起始帧
  ```
  把图交给一个**没看过剧本**的独立会话，只给图，让它写三句话。
- **通过标准**：三句都写得出来，且与分镜里"这一镜改变了什么"一致。集首帧另加一条：冲突主张可见（R-PUB-17）。封面候选帧还要满足：脸带复杂情绪，画面 ≤3 人〔外部调研·S-CASE-18〕。
- **常见误判**：① 制作者自己读图。知道剧情的人一定能读懂，这是自证循环（F1）；② 把"精美"当成"海报"，画面漂亮但没有冲突，照样不通过。
- **溯源**：M2、P4（起始帧决定画面级）、Q5、S-CASE-18。
- **闸门**：R-KF-07、R-KF-08、R-PUB-20。

## TJ-05 · 随机截帧测试
- **检查句**：从成片里随机抽 10 帧，每一帧单独拿出来都"像这部剧的剧照"：身份认得出、没有崩坏、没有文字、构图有主体。
- **怎么做**：
  ```bash
  dur=$(ffprobe -v error -show_entries format=duration -of csv=p=0 final/ep03.mp4)
  for i in $(seq 1 10); do
    t=$(python3 -c "import random; print(round(random.uniform(0, $dur), 2))")
    ffmpeg -v error -y -ss "$t" -i final/ep03.mp4 -frames:v 1 -vf scale=360:-2 "review/taste/rand-$i-$t.png"
  done
  ```
  逐帧打一个标签：OK / 崩坏 / 糊 / 漂移 / 文字 / 无主体。
- **通过标准**：10 帧中 ≥9 帧 OK。任何一帧出现文字或水印，都是阻断缺陷（D1、D2）；出现漂移，回 Q7 处理。
- **为什么要随机**：`contact_sheet.py` 的取样是均匀的，并固定包含首、中、尾帧。抽样位置固定，agent 就会只修被检查的那几个位置（F2：拿代理指标当质量）。随机抽样破坏这种"针对考点"的优化。
- **常见误判**：① 只在"好看的段"里抽，不是真随机，所以时间戳必须写进文件名留证；② 把运动模糊帧判成崩坏。抽相邻 ±2 帧确认后再判。
- **溯源**：P8、B1、B4、D1、F2；阈值 9/10 为〔学院推断。验证：与人类主创逐帧标注的结果对比一致率〕。
- **闸门**：R-CUT（审片包）、R-VID-07。

## TJ-06 · 静音观看测试
- **检查句**：关掉声音，只看画面和硬字幕，连续看一遍，能复述主因果链四项（谁想要什么 → 阻碍 → 做了什么 → 结果）中的 ≥3 项。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i final/ep03.mp4 -an -c:v copy review/taste/ep03-mute.mp4
  ffmpeg -v error -y -i review/taste/ep03-mute.mp4 -vf "fps=2,scale=270:-2,tile=8x6" review/taste/mute-strip-%02d.png
  ```
  agent 按顺序读帧序列（每张 24 秒），把它当成连续观看：不跳读，不打开剧本。写下复述，并标出"靠声音才懂"的时间点。
- **通过标准**：复述 ≥3/4 项；每个"靠声音才懂"的点都已补上字幕，或改成了画面事件。
- **常见误判**：① 看过剧本的会话来做这个测试，会自动脑补剧情，所以由独立会话做；② 字幕把什么都说了，也算通过。这种情况要接着做 TJ-07。
- **溯源**：〔外部调研·S-PLAT-22：超过 30% 的受访者静音观看、依赖字幕〕、R-SCR-08、F1、GAP-1。
- **闸门**：R-PUB-19。

## TJ-07 · 关声音只看字幕测试（画面是否在讲故事）
- **检查句**：画面本身（不看字幕、不听声音）能交代 ≥2/4 个因果项；字幕里没有"解说画面"和"宣告情绪"的句子。
- **怎么做**：
  1. 只读字幕：从剪辑单导出 `字幕` 列（列的顺序不固定，按表头定位；下面示例假定 `字幕` 是第 5 列）：
     `grep -E '^\| CUT-' edit-list.md | awk -F'|' '{gsub(/^ +| +$/,"",$6); print $6}' > review/taste/subs.txt`
     只读这份文本，记下能复述的因果项，记为 S。
  2. 只看画面：用压字幕之前的装配稿，按 TJ-06 的方法抽帧序列，复述能交代的因果项，记为 P。
  3. 逐句标记 subs.txt：解说画面的句子（"他冲过来了！"）、宣告情绪的句子（"我好恨你"）。
- **通过标准**：P ≥2/4；解说画面句和宣告情绪句都是 0（R-SCR-17）。如果 S ≥3 而 P ≤1，判为"广播剧化"：故事全在台词里，画面只是配图。要回剧本和分镜，把关键信息改成画面事件。
- **常见误判**：以为"字幕讲得清楚就是好"。字幕清楚只能证明台词写全了，证明不了这是一部剧。
- **溯源**：R-SCR-08、R-SCR-17、A1（"看不懂"）、F2、GAP-5；〔学院推断：P ≥2/4 阈值。验证：冷观众在无声无字幕条件下的复述率与 P 是否一致〕。
- **闸门**：R-SCR（回流）、R-PUB-19。

## TJ-08 · 3 秒划走测试
- **检查句**：只看前 3 秒（静音），能用一句话说出"谁 + 想要什么 / 受到什么威胁"。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i final/ep03.mp4 -t 3 -vf "fps=4,scale=180:-2,tile=12x1" review/taste/ep03-first3s.png
  ```
  只把这张 12 格条图交给独立会话或冷观众，问两个问题："这一集要讲什么冲突？""你会继续看吗？"
- **通过标准**：一句话说得出冲突主张；剧名、编号、AI 标识叠加在剧情画面上，不单独占秒数（R-PUB-17）；冷观众 ≥2/3 答对〔学院推断〕。**每一集**都要测，不只测第 1 集。
- **常见误判**：① 把"画面好看、有特效"当成钩子，但画面里没有冲突主张；② 只测第 1 集。追更的观众每一集都可能划走。
- **溯源**：GAP-1（委托方没有发布经验，全部依据外部调研）、〔外部调研·S-PLAT-12：有效播放门槛 3 秒〕、〔外部调研·S-PLAT-21、S-PLAT-22、S-ZEN-21〕、R-SCR-01。
- **闸门**：R-PUB-17、R-SCR-01。

## TJ-09 · 因果复述测试
- **检查句**：看完一遍、不翻任何文档，能写出本集主因果链（谁想要什么 → 遇到什么阻碍 → 做了什么 → 结果如何），并且与 `episode-map.md` 里这一集的那句话一致。
- **怎么做**：自我放映（R-CUT-17：先写观后感，再打开制作文档）→ 写复述 → 打开 `episode-map.md` 对照。冷观众版按 [`90-curriculum/cold-audience-protocol.md`](../90-curriculum/cold-audience-protocol.md) 执行。替身版：新开一个会话，只给帧序列（命令同 TJ-06，但用带声音的成片）加转写，并在报告中标注"替身测试，置信度降级"（见 definition-of-done 的 L1 条款）。
- **通过标准**：自我放映要求四项全对；冷观众要求 ≥2/3 复述正确，且没有任何一处被 ≥2 人同时标为"看不懂"（L1）。
- **常见误判**：① 制作者自己复述。知道剧本的人必过，这是自证循环（F1）；自评只能用来找"第一次困惑点"，判定必须交给冷观众或独立会话；② 把"然后……然后……"的情节顺序当成"因为……所以……"的因果。
- **溯源**：F1、A1、GAP-2、R-SCR-07；〔外部调研·S-CASE-13、S-CASE-14：出声思考法；5 名用户约可发现 85% 的问题〕。
- **闸门**：R-CUT-17、R-CUT-19、R-SEA-20。

## TJ-10 · 视线引导（跨切点）
- **检查句**：相邻两个 CUT 之间，前一个 CUT 末帧的注意力落点，与后一个 CUT 首帧的注意力落点，相距不超过画面宽或高的 1/3；如果跳得更远，那是设计好的冲击切，并且写了理由。
- **怎么做**：先用 `psnr_scan.py --mode final final/ep03.mp4 --edit-list edit-list.md --json` 拿到切点时间 t，再取切点两侧的帧并排：
  ```bash
  ffmpeg -v error -y -ss "$(python3 -c "print($t-0.05)")" -i final/ep03.mp4 -frames:v 1 a.png
  ffmpeg -v error -y -ss "$(python3 -c "print($t+0.05)")" -i final/ep03.mp4 -frames:v 1 b.png
  ffmpeg -v error -y -i a.png -i b.png -filter_complex "[0]scale=270:-2[a];[1]scale=270:-2[b];[a][b]hstack" review/taste/cut-$t.png
  ```
  在两张图上分别标出注意力落点：人脸、最高反差处、视线的终点。
- **通过标准**：落点距离 ≤1/3，或已写明是冲击切；同场相邻镜的左右顺序不反转（R-SB-13）；视线方向连续，画左的人看向画右（R-PRF-06）。
- **常见误判**：① 只检查动作是否匹配，不管注意力落在哪；② 竖屏的横向空间窄，上下方向的跳跃同样要算进去。
- **溯源**：〔外部调研·S-STORY-13：Murch 六法则中的"视线"〕、A5、M4；1/3 阈值为〔学院推断。验证：冷观众断点记录里的"跳""晃"标注，是否集中在超过阈值的切点〕。
- **闸门**：R-SB-13、R-PRF-06、Q2。

## TJ-11 · 尺度参照
- **检查句**：凡是要表达"巨大 / 渺小 / 史诗"的镜，画面里同时有一个大小已知的参照物（人、门、树、马），而且参照物和主体的大小比例一眼可读。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i kf.png -vf "scale=270:-2,drawgrid=w=iw/10:h=ih/10:t=1:c=red@0.5" qc/SHOT-012/kf-grid.png
  ```
  在网格上数格子：参照物占几格高，主体占几格高。另外检查两点：机位是否低于参照物的视线高度；纵深层数是否 ≥3。
- **通过标准**：参照物可辨认（用 TJ-01 去色后仍可见）；史诗镜的比例 ≥1:3〔学院推断〕；低机位和三层纵深至少成立一项。
- **常见误判**：① 只是把主体画大，没有参照物，观众感知不到大小；② 参照物被雾吞掉，去色后看不见。
- **溯源**：M2、P4、G5（"史诗感"是画面级属性）；比例阈值为〔学院推断。验证：同一场景做"有参照 / 无参照"两版关键帧，交独立评审盲选"哪张更有压迫感"〕。
- **闸门**：R-KF-07、R-KF-08。

## TJ-12 · 空白安排（视线空间与安全区）
- **检查句**：人物视线或运动方向的前方留有空间；字幕、标识和关键人脸都不落进平台 UI 遮挡带；画面里的留白写得出它承担什么。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i kf.png -vf "drawbox=x=0:y=0:w=iw:h=ih*0.14:color=red@0.4:t=fill,drawbox=x=0:y=ih*0.65:w=iw:h=ih*0.35:color=red@0.4:t=fill,drawbox=x=0:y=0:w=iw*0.06:h=ih:color=red@0.4:t=fill,drawbox=x=iw*0.94:y=0:w=iw*0.06:h=ih:color=red@0.4:t=fill" qc/SHOT-012/safezone.png
  ```
  成片版：对 `contact_sheet.py final/ep03.mp4` 生成的接触表逐格叠加同样的框。
- **通过标准**：关键人脸和字幕全部落在红框以外；视线前方的空间 ≥ 后方。例外是设计好的"压迫 / 被困"构图，需写明理由。
- **常见误判**：① 把横屏三分法的左右留白习惯搬进竖屏。竖屏真正可用的空白主要在上下方向；② 以为平台都有官方百分比。实际上只有 Meta Reels 给了官方百分比（顶部约 14%、底部约 35%、左右各约 6%），国内平台没有官方值时借用这组数（R-PUB-18 的立场）。
- **溯源**：〔外部调研·S-PLAT-20、S-STORY-11（looking space）、S-ZEN-20（水墨留白）〕、Q5。
- **闸门**：R-PUB-18、R-KF。

## TJ-13 · 色彩一致性（同场跨 CUT）
- **检查句**：同一场景里相邻的 CUT 之间，肤色和白平衡没有跳变。
- **怎么做**：
  ```bash
  for f in clips/SEQ04/*.mp4; do
    ffprobe -v error -f lavfi -i "movie=$f,signalstats" \
      -show_entries frame_tags=lavfi.signalstats.YAVG,lavfi.signalstats.UAVG,lavfi.signalstats.VAVG -of csv=p=0 \
    | awk -F, -v f="$f" '{y+=$1;u+=$2;v+=$3;n++} END {printf "%s Y=%.1f U=%.1f V=%.1f\n", f, y/n, u/n, v/n}'
  done
  ```
  输出的三列依次是 Y、U、V 的均值（8-bit）。关键帧（png）也可以用同一命令。然后用 `contact_sheet.py` 生成接触表，把相邻 CUT 的脸部裁剪并排，目视确认。
- **通过标准**：同场相邻 CUT 的 U、V 均值差 ≤3，Y 均值差 ≤10，而且并排目视肤色没有跳变（两项都要满足）〔学院推断阈值〕。不通过时，用场景参考帧做 ColorMatch，或全集统一套一份 `.cube`（R-COL-07）。
- **常见误判**：① 剧情里交代了光线变化（灯灭了），被误判为跳变。先查色彩脚本；② 指标通过就判通过。这是 F2，必须并排目视。
- **溯源**：B1、R-SEA-16；〔外部调研·S-ZEN-17：每场统一光与色温后，关键帧亮度离散度从 18.3 降到 6.6〕、〔外部调研·S-CRAFT-17〕；阈值验证：对人类说过"颜色跳"的 CUT 对和没说过的 CUT 对各算一次，两组能分开才算成立。
- **闸门**：R-COL-05、R-COL-07。

## TJ-14 · 色彩脚本情绪对照
- **检查句**：每隔一段抽一帧排成一条色条，色相、饱和度、明度、光比的变化，与情绪弧的变化同步；全片不是同一个色调。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i final/ep03.mp4 -vf "select='isnan(prev_selected_t)+gte(t-prev_selected_t\,8)',scale=120:-2,tile=12x1" -frames:v 1 review/taste/ep03-color-strip.png
  ```
  （约每 8 秒取一帧。也可以按剪辑单的段首时间逐个 `-ss` 取帧。）把色条和 `visual-bible.md` 的色彩脚本表并排对照。
- **通过标准**：情绪不同的相邻段，至少有一项（色相、饱和、明度、光比）不同（R-COL-03）；色条与色彩脚本每格的声明一致（R-COL-01、R-COL-02）。
- **常见误判**：① 把"颜色漂亮"当成有色彩脚本；② 全片统一青橙，被当成"有风格"。
- **溯源**：GAP-4；〔外部调研·S-CRAFT-13：皮克斯色彩脚本，危险段转为灰浊〕、〔外部调研·S-CRAFT-16：青橙是分离手段，不是默认 LUT〕。
- **闸门**：R-COL-01、R-COL-03。

## TJ-15 · 选角对照（区分度 + 同一性）
- **检查句**：所有主要角色的正脸裁成同尺寸并排后，任意两人至少有 3 项可见特征不同；同一角色在本集各镜的脸部裁剪和板图并排，看得出是同一个人。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i boards/CHR-A.png -i boards/CHR-B.png -i boards/CHR-C.png -filter_complex \
    "[0]crop=600:600:548:300,scale=240:240[a];[1]crop=600:600:548:300,scale=240:240[b];[2]crop=600:600:548:300,scale=240:240[c];[a][b][c]hstack=inputs=3" qc/casting-lineup.png
  python3 50-rubrics/scripts/contact_sheet.py clips/SHOT-044.mp4 --crop face=X:Y:W:H --out-dir qc/SHOT-044/
  ```
  crop 参数按每张图中脸的实际位置调整。再写一张两两差异表（发型轮廓、脸型、体格、年龄感、服色）。
- **通过标准**：两两差异 ≥3 项（R-BRD-16）；每个镜的脸部裁剪都和板图是同一人（R-VID-05）。
- **常见误判**：① 衣服不同就算区分开了，换装后就认不出谁是谁；② 拿全身图判断脸像不像。
- **溯源**：B1、B3；〔外部调研·S-PLAT-07：平台治理"高频 AI 脸"〕。
- **闸门**：R-BRD-16、R-SEA-12、R-VID-04、R-VID-05。

## TJ-16 · 接触三帧测试
- **检查句**：每一次打击接触，取接触前、接触时、接触后各一帧，三帧能读出"接近 → 接触 → 结果"，而不是挥空，或碰一下没有反应。
- **怎么做**：从分镜或目视确认接触时刻 t，然后：
  ```bash
  ffmpeg -v error -y -ss "$(python3 -c "print($t-0.25)")" -i clips/SHOT-031.mp4 -t 0.5 -vf "fps=6,scale=270:-2,tile=3x1" -frames:v 1 qc/SHOT-031/contact3.png
  ```
- **通过标准**：同一帧里能看到攻方的武器或肢体与受方身体接触；下一帧受方有位移或姿态变化；后果（碎石、后退、跪地）在 1s 内可见。
- **常见误判**：① 运动模糊里"看起来碰到了"，就判通过；② 把另一个镜里的反应当成这次接触的结果。这正是 A2 的含蓄策略。
- **溯源**：A2、R4（打击拍要密）；〔外部调研·S-ZEN-17：只写一个动词时，掌掴三次都只是碰一下〕、〔外部调研·S-STORY-16：动作与反应同框〕。
- **闸门**：R-SB-20、Q3。

## TJ-17 · 速度曲线测试
- **检查句**：每个动作段的相邻帧变化曲线有起伏，能分出快、慢、爆、静中的至少 2 种，而不是一条平线。
- **怎么做**：`python3 50-rubrics/scripts/psnr_scan.py --mode clip clips/SHOT-031.mp4 --json > qc/SHOT-031/psnr.json`，读报告里的 ASCII 走势线：PSNR 低表示变化大（快、爆），高表示变化小（慢、静）。把曲线上的区段和 `action-design.md` 的速度层次行逐段对照。
- **通过标准**：曲线能分出 ≥2 种速度区段，位置与速度层次行对得上；"慢"的区段写了设计理由（R-SB-18）。
- **常见误判**：① PSNR 只是代理指标（F2）。运镜、雨雪、颗粒都会拉低 PSNR（脚本会报 `P8-low-baseline`），必须抽帧确认那一段是动作快，而不是相机在晃（D5：单通道不判）；② 对白镜的曲线本来就该平，本测试只适用于动作段。
- **溯源**：A3、D5、F2；〔学院推断：拿 PSNR 当速度代理。验证：对人类判过"慢镜"的段和已通过的段各跑一次曲线，两组能分开才成立〕。
- **闸门**：R-SB-18、R-VID-15、Q6。

## TJ-18 · 闭眼听测试
- **检查句**：只听声音，不看画面，能分辨出环境（在哪里）、动作事件（接触、落地）和情绪节拍（紧张 → 爆发 → 静）；任何时刻能听清的同类声音不超过 2 层。
- **怎么做**：
  ```bash
  ffmpeg -v error -y -i final/ep03.mp4 -vn -c:a copy review/taste/ep03-audio.m4a
  ffmpeg -v error -y -i final/ep03.mp4 -filter_complex "showwavespic=s=1600x240" -frames:v 1 review/taste/ep03-wave.png
  ```
  对照波形图和 `sound-plan.md`，确认爆发点在哪、静场在哪。agent 如果没有听觉通道，就用"波形 + 转写 + sound-plan 声音层表"代替，并在报告中标注"降级：未实听"。
- **通过标准**：每场有连续的环境床（R-SND-01）；每个爆发之后有 ≥1s 的静场（R-SND-07）；重拍对准接触（R-SND-03）。
- **常见误判**：把响度合规（-16 LUFS、真峰 ≤-1 dBTP）当成声音设计做好了。那只是 L0 指标（F2）。
- **溯源**：GAP-3、GAP-6（委托方薄弱项，没有实证）；〔外部调研·S-CRAFT-01：Murch，dense clarity〕、〔外部调研·S-CRAFT-02〕；"同类 ≤2 层"为〔学院推断。验证：冷观众断点记录里的"吵""听不清"标注，是否集中在层数超标处〕。
- **闸门**：R-SND-01、R-SND-02、R-SND-07、Q8。
