# 30-taste · 审美层

> 一句话：能力 = 知识 × 实践反馈 × **标准内化**〔委托方实证·F4〕。委托方装了 7 个专业技能，只补上了"知识"这一项。本层补的是"标准内化"：先定一个风格，再用成对样例练出判断，最后靠能留证据的观感测试，把"好不好看"变成能判真假的结论。
> 回答的困惑：G2（技术全绿、观感不行）、G3（学了技能没有质变）、G5（"史诗""特效"越具体化越不够）。
> 路径约定：文中 `50-rubrics/...` 等路径都相对于学院根目录。

| Q 版 | [`30-taste/style-cards/chibi.md`](style-cards/chibi.md) | 头身比是硬约束；一拍只承载一个因果单位 |

**选卡流程（必须按顺序做）**：
1. **题材 → 候选**：按每张卡的"适用题材 / 不适用"列出 2–3 张候选卡。
2. **约束过滤**：
   - H3 能力：大场面动作和物理互动偏弱〔外部调研·S-CASE-10〕。题材靠群战取胜的，降低写实卡的优先级。
   - 合规：写实卡要先答合规三问。
   - 运动预算：有限运动的形态更省生成量。
3. **写"风格决定记录"**（写进 `visual-bible.md`），内容包括：
   - 选定的卡，以及另外两张为什么没选；
   - 填好变量的风格锁句；
   - 本剧的身份锚点载体；
   - 运动预算（哪类镜给全动作）；
   - 本剧版的负面词改写表。
4. **试做验证**：3 个主要角色 × 3 seed 出板图，跑 TJ-02（剪影）、TJ-15（选角对照）和 TJ-13（色彩一致性）。不过就改锁句，或者换卡。
5. **人类拍板**：在拍板点①、②确认风格（见 [`00-orientation/production-lifecycle.md`](../00-orientation/production-lifecycle.md)）。

**判决**：
- **删词测试**：从风格描述里删掉任何一条，提示词如果一个字都没变，说明这条只是标签，不是规格〔外部调研·S-ZEN-20〕。「电影感」「唯美」「水墨感」「可爱风」都过不了删词测试，禁止写进任何提示词（R-VP-16）。
- **风格锁句是第二种锚点句**〔委托方实证·P1 的机制〕：先登记，再逐字嵌入所有板图和冻结提示词。改动锁句等于改动全部资产，受影响的镜必须全量重出，并重新验收。
- **混用规则**：
  - 一季只用一张**底色卡**（写实 / 国漫 / 三维 / 动态漫 / 水墨 / Q 版选一）。
  - **叠加卡**（dark-fantasy-epic）只管光、尺度、事件，身份层由底色卡决定。
  - **插段换卡**（水墨回忆、Q 版小剧场）必须在 `visual-bible.md` 声明切换点、切换理由和层级拆分。
  - **禁止**同一个镜让两张卡同时决定身份层。混合形态最常见的失效就是身份边缘被两层同时决定，结果边缘抖动，改也改不动〔外部调研·S-ZEN-20〕。
- **negative_prompt 在本管线无效**〔委托方实证·T-2、C1；外部调研·S-COMFY-05〕。每张卡的"负面词改写"一节都按 [`00-orientation/evidence-reconciliation.md`](../00-orientation/evidence-reconciliation.md) R1 改写：先写正向可见状态句，只对已被证实会自加的物件追加绝对否定，并用 A/B 证明。

**盲判协议（装载后必做一遍，之后每次被打回后复训相关对）**：
1. 只读 ❌ 那一行，不看 ✅、点评和判据。
2. 写出四项：
   - ① **病灶层**：剧本 / 分镜 / 关键帧 / 提示词 / 生成设置 / 后期 / 审片，选一个；
   - ② 根因；
   - ③ 可以直接执行的改写；
   - ④ 你会用哪条 R 或 TJ 判据抓住它。
3. 展开 ✅ 和点评对照，每项 1 分，满分 4。病灶层判错，整题记 0，因为补丁打在错误的层上，就是委托方 G7 的根病。
4. 得分 <3 的对子写入记忆（[`40-memory/README.md`](../40-memory/README.md) 的写入方法），下次开工前复训。

**生产中的用法**：
- **写作时**：写分镜或提示词之前，先读同类 TP 的 ✅，把它当作写法基线。
- **审片时**：每条缺陷都匹配到一个 TP，写成"SEQ-04 SHOT-031 犯 TP-08（换边运镜词）"。匹配不上，说明这是新缺陷类型，走回流。
- **回流**：人类每打回一处你自己没先发现的问题，就新写一个 TP（编号从 TP-36 续起）。❌ 用真实现场，✅ 用修正后的版本，溯源写对应的案例编号。人类原话只能逐字引用档案或新证据文件里的「」原句。

## 3. 审美判据卡：审片时的用法

- **每道闸门做哪些 TJ**：见 [`30-taste/judgment-cards.md`](judgment-cards.md) 开头的"闸门速查"。
- **结论格式**（一行一条，写进 `qc/<SHOT>.md` 或 `review/quality-scorecard.md`）：
  `TJ-04 ✘ 首帧三句写不出冲突（证据：review/taste/ep03-frame0.png；读图者：独立会话）`
  没有证据文件名的 TJ 结论无效（C2：一句"通过"不可复核）。
- **谁来读图**：
  - 凡是涉及"能不能看懂"的 TJ（TJ-04、06、07、08、09），读图者必须是**没看过制作文档的独立会话**或冷观众。制作者自己读，是自证循环〔委托方实证·F1〕。
  - LLM 评审偏爱自己生成的内容〔外部调研·S-CASE-23〕。
- **TJ ↔ Q 维度**（打分时，每个 Q 至少引用一张 TJ 的证据；维度定义见 [`50-rubrics/quality-model.md`](../50-rubrics/quality-model.md)）：

| Q | 对应 TJ |
|---|---|
| Q1 叙事与钩子 | TJ-04、TJ-06、TJ-07、TJ-08、TJ-09 |
| Q2 空间与调度 | TJ-10、TJ-02 |
| Q3 动作与物理 | TJ-16、TJ-02 |
| Q4 特效与事件 | TJ-16（后果相）、TJ-11 |
| Q5 美术与密度 | TJ-01、TJ-03、TJ-04、TJ-11、TJ-12、TJ-14 |
| Q6 节奏与速度 | TJ-17、TJ-08 |
| Q7 一致性与连续性 | TJ-13、TJ-15、TJ-05 |
| Q8 声音与对白 | TJ-18、TJ-06、TJ-07 |

- **指标不得压过眼睛**：TJ 里出现的数字（PSNR、YUV 均值、比例），只是产出证据的手段，不是判决本身〔委托方实证·F2〕。数字和目视结论冲突时，以目视为准，并把冲突记下来，用于校准阈值。

## 4. 诚实边界
- 委托方实证覆盖的范围是：A–F 案例对应的 TP，以及风格卡里引用的 C1、D4、B3 等现场。
- 风格卡的英文词包、TJ 的阈值，多数是〔学院推断〕，每处都写了验证方法。在本管线跑过 A/B 之后，把结果写回对应的卡。
- 声音、发布、冷观众相关内容（TP-29、30、33–35，TJ-08、18），依据都是〔外部调研〕。委托方在这些方面没有经验（GAP-1、GAP-2、GAP-3），**禁止**写成"经验表明"。

## → 行为改变
- 下次开新剧，先按第 1 节的流程选卡，写出风格决定记录和锁句，再开板图。没有锁句，禁止出任何关键帧。
- 下次装载学院，在开工前完成 TP-01 – TP-35 的盲判，并把得分 <3 的对子写入记忆。
- 下次交审片包，每个 Q 维度的分数旁边都要附 TJ 证据文件。没有附证据的维度，按"未验证"处理，不得给 ≥2 分。
