# EX-05 · 正向优先的禁令改写：从 "no gemstone, no armor" 到 正向可见状态句 + 绝对否定

> 阶段：1 预制作（锚点卡）→ 2 制作（提示词）｜ 难度：★★☆ ｜ 建议用时：30 分钟 ｜ 对应技能：[`20-craft/casting-and-canon/SKILL.md`](../../20-craft/casting-and-canon/SKILL.md)、[`20-craft/video-prompting-h3/SKILL.md`](../../20-craft/video-prompting-h3/SKILL.md)
> 训练案例：C1（禁用项被违反：negative_prompt 恒空 + cfg=1.0 无效；绝对否定句 + 多 seed + 逐特征放大验收修好）、B3、D1〔委托方实证〕，见 [`60-casebook/cards/C1-banned-items-violated.md`](../../60-casebook/cards/C1-banned-items-violated.md)。裁决见 [`00-orientation/evidence-reconciliation.md`](../../00-orientation/evidence-reconciliation.md) R1：**首选正向可见状态句；对已被证实会自加的物件，在正向句之后追加绝对否定句；禁止只靠否定句，禁止写 negative_prompt**。判据：R-VP-10、R-VP-11、R-VP-14。外部旁证〔外部调研·S-COMFY-08、S-COMFY-05〕。
> 运行位置：学院根目录。产物放 `training/exercises/EX-05/`。

## 目标

学会把"只有否定句"的锁定改写成两层：①正向可见状态句（写下**画面上看得见的样子**）；②仅对已被证实会自加的物件追加绝对否定句；并设计一个能证伪这条做法的 A/B（"否定句本身没有把 X 招进来"）。

## 输入

`anchors.md`（存为 `training/exercises/EX-05/anchors.md`；锚点句里唯一的"锁定"是末尾两个 no）：

```markdown
## ANCHOR: CHR-SUXIAO
- 类型: 角色
- 锚点句 EN: `a slender 17-year-old Chinese swordswoman with a high black ponytail tied with a plain red cord, sharp dark eyes, wearing a fitted dark-teal cross-collar tunic with leather bracers, holding a single-edged straight Chinese dao in her right hand, no gemstone, no armor`
- 必现: 高马尾 + 红色细绳；墨绿交领短衣；皮护腕；右手持单刃直刀；护手为素面抛光钢
- 禁用: no gemstone on the sword guard; no armor
- 方位属性: 刀在右手（关键帧需单独放大核验）
- 来源依据: 学院构造的训练素材
- 板图: assets/boards/CHR-SUXIAO-BOARD.png（seed 4 定稿）
```

`video-prompts.md`（存为 `training/exercises/EX-05/video-prompts.md`）：

背景（C1 的事实）：生成器在这类镜里**曾反复自加**宝石与铠甲；本管线 cfg=1.0，`negative_prompt` 无效。

## 任务

1. 先对输入运行 `python3 50-rubrics/scripts/prompt_lint.py training/exercises/EX-05/video-prompts.md --anchors training/exercises/EX-05/anchors.md > training/exercises/EX-05/lint-before.txt`，记下 `VP-anchor`（info：禁用项未写进提示词）；说明为什么脚本这里只能报 info——它看不出"只有否定句"这件事本身，这要靠 R-VP-10 的目视。
2. 改 `anchors.md`：把 `锚点句 EN` 末尾的 `no gemstone, no armor` 删掉，换成**正向可见状态**（护手长什么样、躯干穿什么、护腕在哪）；整句仍是一行、反引号包裹。`禁用` 保持绝对否定句（`no X`，分号分隔）。若新增的正向描述与板图实际画面不符，以板图为准（E4）。
3. 改 `video-prompts.md`：`subject_definitions` 逐字换成新锚点句；`detailed_description` 里先写本镜的正向状态句，再把绝对否定句写在其后，且逐字包含 `禁用` 里的每一条；不写 `negative_prompt`。
4. `locks.md`：锁定项对照表，列 `锁定项 | 正向可见状态句 | 追加的绝对否定句 | 是否已被证实会自加（证据）`。对**没有证据会自加**的物件只写正向句、不写否定（R-VP-14：提到即生长）。
5. `ab-plan.md`：写一份 A/B 验证计划——同一镜、同一组 ≥3 个 seed；A = 仅正向句，B = 正向句 + 否定句；用 `contact_sheet.py` 并排取证（写出你将运行的命令，不要求执行）；指标 = 宝石、铠甲在各 seed 上的出现率，以及"B 组是否反而多出现了被点名的物件"；写明决策规则（B 不比 A 好 → 删掉否定句；B 出现率更高 → 删掉并上报）。

## 期望产出

`anchors.md`、`video-prompts.md`（改后）、`locks.md`、`ab-plan.md`、`lint-before.txt`、`lint-after.txt`。

## 自动判分

```bash
D=training/exercises/EX-05
python3 50-rubrics/scripts/prompt_lint.py $D/video-prompts.md --anchors $D/anchors.md > $D/lint-after.txt; echo "exit=$?"
grep -cE "VP-(anchor|negative|ban|realtime|struct|dialogue|distinct|sync|frames|picture)" $D/lint-after.txt
```

再把下面的小检查存为 `training/exercises/EX-05/check.py`，运行 `python3 training/exercises/EX-05/check.py`（只用标准库，退出码 0 = 全过）：

```python
import re, sys
D = "training/exercises/EX-05/"
a = open(D + "anchors.md", encoding="utf-8").read()
p = open(D + "video-prompts.md", encoding="utf-8").read()
ok = True
def chk(name, cond):
    global ok
    print(("PASS " if cond else "FAIL ") + name)
    ok = ok and bool(cond)
m = re.search(r"锚点句 EN:\s*`([^`]+)`", a)
chk("锚点句存在且为一行反引号", m)
s = m.group(1) if m else ""
chk("锚点句内不含任何否定词（否定只放 禁用）", not re.search(r"\b(no|not|without|never)\b", s, re.I))
chk("锚点句有护手的正向状态", "sword guard" in s and re.search(r"plain|polished|smooth|unadorned|simple", s))
chk("锚点句逐字出现在提示词里", s and s in p)
d = re.search(r"detailed_description:\n(.*?)\noverall_soundscape:", p, re.S)
body = d.group(1) if d else ""
sents = [x.strip() for x in re.split(r"(?<=[.;])\s+|\n", body) if x.strip()]
pos = [i for i, x in enumerate(sents) if re.search(r"unadorned|plain polished|smooth|bare", x, re.I) and not re.match(r"no\b", x, re.I)]
neg = [i for i, x in enumerate(sents) if re.match(r"no\b", x, re.I)]
chk("detailed_description 有正向状态句", pos)
chk("detailed_description 有绝对否定句", neg)
chk("正向句在否定句之前", pos and neg and min(pos) < min(neg))
bans = re.search(r"禁用:\s*(.+)", a)
chk("禁用项逐条出现在提示词里", bans and all(b.strip().rstrip(".").lower() in p.lower() for b in bans.group(1).split(";")))
chk("没有 negative_prompt", "negative_prompt" not in p + a)
sys.exit(0 if ok else 1)
```

通过线（全部成立）：
1. `prompt_lint` `exit=0`，且 `grep -cE` 输出 `0`（`VP-anchor` info 清零 = 禁用项逐条写进了提示词；其余是不能因改写而破坏的结构项）。
2. `check.py` 全 PASS。
3. 对**输入原文件**运行同一组命令的预期：`prompt_lint` `exit=0`，但 `VP-anchor` info 非 0；`check.py` 至少 FAIL"锚点句内不含任何否定词"与"锚点句有护手的正向状态"——说明"lint 绿"不等于"锁定做对了"（F2）。

## 人工 / 评审判分点

- 正向句写的是**画面事实**（`plain polished steel, smooth and unadorned`），不是把否定换个说法（"lacking any jewels"仍是否定）。
- 否定句只追加在宝石、铠甲这类 C1 已证实会自加的物件之后；没有给每个想得到的物件都配一个 no（"提到即生长"，R-VP-14）。
- `locks.md` 的"证据"列写得出处（C1 / 某次抽卡记录 / 无），不能写"可能会加"。
- `ab-plan.md` 能证伪：B 组有"否定句招来 X"的判据，有 seed 数与并排取证命令，有决策规则；不是"试试看"。
- 没有写 `negative_prompt`、没有把"no text"之类写进正文去管字幕之外的文字（D1 禁令包末行保持原样）。

## → 行为改变

下次要锁定某个外观，先写它**看得见的样子**，再只对 C1 式已证实会自加的物件追加 `no X`；改动锚点句后立刻重跑 `prompt_lint.py --anchors`，并用 ≥3 seed 的 A/B 证明否定句没有把它招进来。
