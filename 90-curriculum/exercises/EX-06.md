# EX-06 · AIGC 显式标识叠层规格：字高、时长、位置，与 ffmpeg drawtext 草案

> 阶段：3 后期 → 5 发布 ｜ 难度：★★☆ ｜ 建议用时：30 分钟 ｜ 对应技能：[`20-craft/edit-and-assemble/SKILL.md`](../../20-craft/edit-and-assemble/SKILL.md)、[`20-craft/publish-prep/SKILL.md`](../../20-craft/publish-prep/SKILL.md)
> 性质：**本题全部依据外部调研**（委托方从未发布过作品，GAP-1），不构成法律意见。训练案例：D2（文字/纯色由剪辑程序化叠加，不交给生成器）〔委托方实证〕。依据：〔外部调研·S-PLAT-02〕GB 45438-2025 §5.4（F-PLAT-03）、〔外部调研·S-PLAT-01〕《微短剧发展管理办法》第三十四条；合规优先级与判据见 [`50-rubrics/checklists/publish.md`](../../50-rubrics/checklists/publish.md) R-PUB-01 – R-PUB-05；裁决见 [`00-orientation/evidence-reconciliation.md`](../../00-orientation/evidence-reconciliation.md) 第四部分。
> 运行位置：学院根目录。产物放 `training/exercises/EX-06/`。

## 目标

把"标识要有"变成**可检查的数字**：字高多少像素、显示多少秒、放在画面哪里，并写出 ffmpeg `drawtext` 草案与取证命令。要能回答：为什么不是"字号 54"，为什么不能放右下角，为什么取 2.5s 而不是 2s。

## 输入

1. 成片规格：`final/ep03.mp4`，1080×1920（严格 9:16），24 fps，约 84s，第 0 帧就是剧情画面（无黑场）。
2. 标准摘录（逐条核对原文请开 [`80-sources/catalog/platform-publishing-traffic.md`](../../80-sources/catalog/platform-publishing-traffic.md) 的 S-PLAT-02）：视频显式标识用**文字提示**，同时含人工智能要素（"人工智能"或"AI"）与生成合成要素（"生成"和/或"合成"）；应位于**视频起始画面**；位于画面的**边或角**；字型清晰可辨；文字高度**不应低于画面最短边长度的 5%**；正常播放速度下持续**不应少于 2s**。
3. 平台遮挡带（1080×1920）：上 269px、下 672px、左右各 65px——取自 Meta Reels 广告规格的 14% / 35% / 6%〔外部调研·S-PLAT-20，F-PLAT-13〕；国内平台没有官方安全区数值，此处按它执行属〔学院推断〕（R-PUB-04、R-PUB-18）。
4. 字体：用一款许可明确可商用的中文字体（如〔外部调研·S-CRAFT-31〕Adobe 思源黑体，SIL OFL 1.1；字体文件路径由你的环境决定，写成占位 `<fontfile>`）。
5. 约束：叠层由剪辑程序化叠加，**不交给生成器**（D2、D1）；路径与文件名用英文 kebab-case（E3-1：中文路径在 cmd 下会吞输出）；中文文本放 UTF-8、无 BOM、LF 的文本文件里用 `textfile=` 读入，避免命令行转义。

## 任务

1. `label-spec.md`：写出规格表——标识文字（含哪两个要素）、字高下限计算（短边 × 5% = ?px）、字号取值与"字号 ≠ 字形实高"的说明、位置（x / y，说明避开了哪几条遮挡带、为什么是左侧边而不是右下角）、起止时间（从第几秒到第几秒，帧数）、每一项的出处标签（〔外部调研·S-PLAT-02〕或〔学院推断〕）。**标准给出的数字与你自己加的余量必须分开标注**。
2. `aigc-label.txt`：标识文字（一行）。
3. `make-label.sh`：一条 `ffmpeg … -vf "drawtext=…"` 命令草案，输入 `final/ep03.mp4`，输出 `final/ep03.labeled.mp4`，视频重新编码、音频 `-c:a copy`。`enable` 必须用 `between(t,起,止)` 写法。
4. `verify-label.sh`：取证命令——在 0 / 1 / 2 / 2.4s 四个时间点各抽一帧原尺寸 PNG（R-PUB-03，见 publish.md"证据命令"），再抽一帧 2.8s（应已无标识）。
5. 在 `label-spec.md` 末尾加"这条规格没覆盖的事"：隐式标识（元数据 `AIGC` 字段，R-PUB-06）、平台 AI 声明（R-PUB-08）、片头剧名与节目编号（R-PUB-07）——各一句，并写明哪些值只能由人类提供，**不得自己编 ProduceID / 节目编号**。

## 期望产出

`label-spec.md`、`aigc-label.txt`、`make-label.sh`、`verify-label.sh`。

## 自动判分

本题的数值部分可以机械检查；"为什么"由评审判。把下面的检查存为 `training/exercises/EX-06/check.py`，运行 `python3 training/exercises/EX-06/check.py`（标准库；退出码 0 = 全过）：

```python
import re, sys, pathlib
D = pathlib.Path("training/exercises/EX-06")
s = (D / "make-label.sh").read_text(encoding="utf-8")
def num(pat):
    m = re.search(pat, s)
    return float(m.group(1)) if m else None
fs, x, y = num(r"fontsize=(\d+)"), num(r":x=(\d+)"), num(r":y=(\d+)")
w = re.search(r"between\(\s*t\s*,\s*([\d.]+)\s*,\s*([\d.]+)\s*\)", s)
t0, t1 = (float(w.group(1)), float(w.group(2))) if w else (None, None)
m = re.search(r"text='([^']+)'", s)
if m:
    text = m.group(1)
else:
    f = re.search(r"textfile=([^:'\" ]+)", s)
    pth = pathlib.Path(f.group(1)) if f else None
    text = pth.read_text(encoding="utf-8").strip() if pth and pth.exists() else ""
ok = True
def chk(name, cond):
    global ok
    print(("PASS " if cond else "FAIL ") + name)
    ok = ok and bool(cond)
chk("用 drawtext 且指定 fontfile", "drawtext=" in s and "fontfile=" in s)
chk("文字含 AI/人工智能 与 生成/合成", re.search(r"AI|人工智能", text) and re.search(r"生成|合成", text))
chk("fontsize >= 54（字形实高另须实测）", fs is not None and fs >= 54)
chk("从第 0 秒开始", t0 == 0)
chk("持续 >= 2.0s", t0 is not None and t1 - t0 >= 2.0)
chk("x >= 65 且 y >= 269（避开左右 6%、顶部 14%）", x is not None and y is not None and x >= 65 and y >= 269)
chk("文字块下沿 <= 1248（避开底部 35%）", fs is not None and y is not None and y + fs <= 1920 - 672)
chk("文字块右沿 <= 1015（避开右侧 6%）", fs is not None and x is not None and x + fs * len(text) <= 1080 - 65)
chk("音频直通", "-c:a copy" in s)
v = (D / "verify-label.sh").read_text(encoding="utf-8")
chk("verify-label.sh 用 -ss 抽 0/1/2/2.4 四个时间点", "-ss" in v and re.search(r"0\s+1\s+2\s+2\.4", v))
if t0 is not None and t1 - t0 < 2.5:
    print("WARN 建议 >= 2.5s 留余量（学院取值）")
sys.exit(0 if ok else 1)
```

通过线：`check.py` 全 PASS（WARN 不影响退出码，但评审会扣"余量"一项）。你可以另外对一条合成视频真跑 `make-label.sh`，再跑 `verify-label.sh` 看 0–2.4s 四帧有标识、2.8s 无标识；真跑结果须附 PNG 路径。

## 人工 / 评审判分点（满分 10，≥8 分才算通过）

- 字高下限算对：1080 × 5% = 54px；并明确"54px 是字形实高，不是 `fontsize`"，字号取值留了余量（例如 64）并给出实测方法或读数（2 分）。
- 时长：标准 ≥2s，学院取 2.5s（= 60 帧）留编码与取帧误差余量，且标注哪个是标准、哪个是学院余量（2 分）。
- 位置：起始画面、边或角、不落平台遮挡带；解释了为什么不用标准附录示例里的右下角（底部 35% 是平台 UI 带，挡住等于没标，publish.md"常见误判"）（2 分）。
- 文字：同时含两个要素；没有用"AI 辅助制作"（只有单一来源转述，且缺"生成/合成"要素，〔外部调研·S-PLAT-06〕，R-PUB-01）（1 分）。
- 每集都要标，不止第一集（S-PLAT-01 第三十四条，R-PUB-05）（1 分）。
- 来源标签诚实：标准数字标〔外部调研〕，安全区与余量标〔学院推断〕；声明不构成法律意见；隐式标识的值不编造（2 分）。

- 参考命令（占位 `<fontfile>` 由环境决定）：

```bash
ffmpeg -y -i final/ep03.mp4 \
  -vf "drawtext=fontfile=<fontfile>:textfile=training/exercises/EX-06/aigc-label.txt:fontsize=64:fontcolor=white:borderw=4:bordercolor=black@0.85:x=72:y=300:enable='between(t,0,2.5)'" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a copy final/ep03.labeled.mp4
```

  `aigc-label.txt` 内容：`人工智能生成合成`（8 个字，64px × 8 = 512px，x 从 72 到 584，远在右沿 1015 内；y 300–364，顶部遮挡带 269 之下、底部遮挡带 1248 之上）。
- 数字：短边 1080 → 54px 下限；`fontsize=64` 给 CJK 方块字留约 7–10px 余量〔学院推断：字形实高约为字号的 0.9–1.0 倍，须在 `label-t0.png` 上量一次〕；一种近似测量法是在纯黑画布上用同样的 `drawtext`（去掉描边）渲染一帧，再用 `cropdetect=limit=24:round=2` 读非黑区域外框高度（〔学院推断〕：近似字形实高，以截图原尺寸读数为准）。`between(t,0,2.5)` ≈ 61 帧含端点；0 / 1 / 2 / 2.4s 四帧都有，2.8s 无。
- 取证命令（来自 publish.md）：`for t in 0 1 2 2.4; do ffmpeg -v error -y -ss $t -i final/ep03.labeled.mp4 -frames:v 1 review/publish/label-t$t.png; done`，另加 `-ss 2.8` 一帧。
- 常见错答：`fontsize=54`（实高不足 54）；`enable='lt(t,2)'`（刚好 2s，无余量，且 `check.py` 读不到 between）；放右下角照抄标准示例（落进底部 35% 带）；只加 "AI" 不含"生成"；只在第一集叠；把标识交给生成器出（D2）；把中文直接写进命令行导致 cmd 乱码（E3-1）；为 `ContentProducer`/`ProduceID` 编一个看起来像真的值（须由属主提供）。
