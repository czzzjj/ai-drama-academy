# EX-07 · 反馈翻译：把「无电影级运镜」「没有合理的打斗逻辑」翻成设计层释义 + 可做 A/B 的假设

> 阶段：4 审片（缺陷单回流）｜ 难度：★★☆ ｜ 建议用时：30 分钟 ｜ 对应技能：[`20-craft/screening-review/SKILL.md`](../../20-craft/screening-review/SKILL.md)、[`20-craft/storyboard-long-take/SKILL.md`](../../20-craft/storyboard-long-take/SKILL.md)、[`20-craft/action-choreography/SKILL.md`](../../20-craft/action-choreography/SKILL.md)
> 训练案例：A4、A2、F2〔委托方实证·G6：人类用设计层词汇说话，agent 按参数层理解〕，见 [`60-casebook/cards/A4-unmotivated-camera.md`](../../60-casebook/cards/A4-unmotivated-camera.md)、[`60-casebook/cards/A2-missing-fights.md`](../../60-casebook/cards/A2-missing-fights.md)。判分基准：[`00-orientation/glossary.md`](../../00-orientation/glossary.md) 部分 B「人类反馈词翻译表」；质量维度映射见 [`50-rubrics/quality-model.md`](../../50-rubrics/quality-model.md)。
> 运行位置：学院根目录。产物放 `training/exercises/EX-07/`。

## 目标

学会收到一句人类反馈后**不按直觉调参数**：先把它翻成设计层释义，写出可检查判据，再把"不确定的释义"做成可以 A/B 的假设让证据说话。本题的两句反馈逐字取自人类主创（client-dossier A4）。

## 输入

人类反馈原话（逐字）：「无电影级运镜」「苏晓冲击镜头过于耿直，没有运镜和合理的打斗逻辑」。

生产 agent 当时的处理（学院构造的训练素材，不是项目原件）：统计到"固定镜头 = 0、每镜都有位移"，判定运镜达标；对打斗，打算"多加几个招式并在提示词里加 epic fight"。

现场分镜片段（存为 `training/exercises/EX-07/storyboard-excerpt.md`，学院构造）：

```markdown
| 段号 | 镜号 | 时长(s) | 拍数 | 内容 | 运镜 | 运镜因果 | 起始帧方位 | 对白 | 短镜理由 |
|---|---|---|---|---|---|---|---|---|---|
| SEQ-05 | SHOT-031 | 5.88 | 1 | 苏晓冲向石神 | 缓推 | 增强动态 | 石神=LEFT; 苏晓=RIGHT | — | — |
| SEQ-06 | SHOT-032 | 5.88 | 1 | 苏晓一刀砍向石神 | 缓推 | 增强动态 | 石神=LEFT; 苏晓=RIGHT | — | — |
| SEQ-07 | SHOT-033 | 5.88 | 1 | 石神倒地 | 缓推 | 增强动态 | 石神=LEFT; 苏晓=RIGHT | — | — |
```

## 任务

写 `translation.md`，对**两句反馈各一节**（共两节），每节包含：

1. **参数层误读**：agent 会怎么错读它（一句话，要具体到"会去改什么"）。
2. **设计层释义**：它真正指向的设计缺失（1–2 句；用 glossary 部分 B 的概念，不要照抄表格原句）。
3. **可检查判据**：≥2 条，每条能判真假（如"每个运镜能写出因果句"，不是"更有电影感"）。
4. **质量维度与病灶阶段**：主 / 次 Q 维度；回到 production-lifecycle §3 的哪个阶段修。
5. **两个可做 A/B 的假设**，固定格式（共 4 个假设，标题 `### 假设 1-1`、`### 假设 1-2`、`### 假设 2-1`、`### 假设 2-2`）：

```markdown
### 假设 1-1 · <一句话>
- 变量：<只改一个设计变量>
- 对照：A=<现状>；B=<改后>
- 固定条件：<同 seed、同起始帧、同时长……>
- 观测：<谁来判、看什么、n 多大>
- 病灶阶段：<回到哪里修>
```

另写 `ask-human.md`：若释义仍不确定，你会给人类看哪两版（A / B 各一行说明），让他在"你想要的是哪一种"里选（glossary 部分 B 的用法）。不超过 5 行。

## 期望产出

`translation.md`、`ask-human.md`。

## 自动判分

只有结构可以机械检查；释义对不对由评审判（见下）。

```bash
F=training/exercises/EX-07/translation.md
grep -c "^### 假设" $F
for k in 变量 对照 固定条件 观测 病灶阶段; do echo "$k: $(grep -c "^- $k：" $F)"; done
grep -nE "^- 变量：.*(数量|次数|幅度|更多|epic|spectacular|环绕|横移)" $F
wc -l training/exercises/EX-07/ask-human.md
```

通过线：
1. 第一条输出 `4`；五个字段计数各为 `4`。
2. 第三条 `grep` **无输出**（假设的变量必须是设计变量——运镜因果、起幅端、战术链、同镜或拆镜——而不是"运镜次数/幅度/招式数量/加 epic"这类参数）。
3. `ask-human.md` ≤ 5 行。
4. 评审得分 ≥ 8/10（下一节）。

## 人工 / 评审判分点（满分 10）

- 「无电影级运镜」：识别出"镜头语言设计缺席（为什么用这个景别、从哪看、怎么动、在哪切），动机缺失比动得少更严重"，**不是**"位移次数太少"；判据含"每个运镜能写出因果句""关键动作接触瞬间有镜头响应"（glossary 部分 B，A4）。（3 分）
- 「没有合理的打斗逻辑」：识别出"因果链缺失：谁为什么出手→对方怎么应→空间怎么变→后果是什么，没有交手回合"，**不是**"招式不够多"；判据含"能写出战术链""至少 1 个完整交手回合""每次接触有反应与后果"（A2）。（3 分）
- 4 个假设各只改一个设计变量、有固定条件、观测方式可执行（含冷观众或接触表证据），并说明"若 B 胜 / 无差异"各自怎么办。（2 分）
- 病灶阶段正确：运镜 → 1 分镜（重写运镜因果）；打斗 → 1 动作设计；没有写"在剪辑里调"或"在提示词里加 epic"（production-lifecycle §3 的"不要做的事"）。（1 分）
- 对输入素材里的事实作了利用：三镜 `运镜因果` 都是"增强动态"（说不出事件）、"砍"与"倒地"被拆成两镜（出招与受击不同镜）。（1 分）

- 运镜（A4）：误读 = 每镜都加 orbit / truck、让位移更复杂；释义 = 运镜没有动机（因果句缺失：三镜都写"增强动态"，说不出画面内可见的 X）；判据 = 每镜 `运镜因果` 是"因为 X，所以镜头 Y"且 X 是可见事件；接触瞬间有镜头响应（顿挫）；景别有序列变化；Q2（空间与调度）主、Q6 次（参照 quality-model 映射表）；病灶 = 1 分镜。
- 假设 1-1：变量 = 运镜是否挂在事件上；A = `缓推 / 增强动态`，B = `缓推，接触帧顿挫 / 因为刀锋接触石膝，所以推近在接触帧顿住`；同 seed、同起始帧、同时长；观测 = 评审在接触表里找得到 X 与 Y 对应的帧 + 3 位冷观众盲评"哪版更像电影、哪版让你觉得打中了"。假设 1-2：变量 = 推近镜起幅取宽端还是紧景（〔外部调研·S-H3-08〕：必须收紧的镜得从宽景起）；A = 关键帧已是中近景再推近，B = 宽景起幅再推近到同一终景；观测 = 接触表首 / 末格景别差与推近幅度；病灶 = 2 起始帧 + 1 分镜。
- 打斗（A2）：误读 = 多加招式、写 epic fight；释义 = 因果链缺失，没有交手回合，"冲击"与"倒地"之间没有可见的接触、反应；判据 = 写得出战术链（≥3 环）、≥1 个同镜同框的完整交手回合、每次接触有反应与后果；病灶 = 1 动作设计（action-choreography）。
- 假设 2-1：变量 = 是否写入战术链；A = 现状（冲击→倒地），B = 诱敌→落空→抓隙→击飞压入同一镜；观测 = 冷观众复述"谁为什么出手、对方怎么应、结果是什么"，≥2/3 复述正确。假设 2-2：变量 = 出招与受击同镜或拆两镜；A = SHOT-032 + SHOT-033 拆开，B = 合并为一镜；各 2 seed，盲评"哪版打中了"（〔学院推断〕，验证法见 action-choreography 步骤 2）。
- `ask-human.md` 示例：「你说的"没有运镜"，是 A（镜头在接触瞬间有顿挫、起幅有景别变化）还是 B（镜头位移更多更复杂）？我各出一版给你看。」——给的是 A/B 两版片段，不是让人类解释术语。
- 常见错答：翻译成"增加运镜数量 / 加更多招式"；把 A/B 的变量写成"运镜幅度 0.3 vs 0.6"；假设里同时改两个变量；用"人类说好看就行"当观测；打斗假设只改提示词形容词。

## → 行为改变

下次人类用"没有运镜 / 打斗逻辑 / 不像电影"这类词反馈，先查 glossary 部分 B 翻成设计层释义并写出可判真假的判据；仍不确定就做 A/B 两版让人类选，禁止凭直觉改参数，也禁止"再修最近那一处"。
