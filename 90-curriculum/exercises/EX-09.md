## 目标

写出一条合格的**英文冻结提示词**：固定六行结构（风格锁 → 构图句 → 位置句含逐字锚点句 → 场景 → **一句**光 + 命名色 → 差异化 / 禁用），每个人用画面位置开头，尺寸 1536×2752，不写质量咒语、不写 `negative_prompt`、不点名灯具。这一帧要钉死后面视频的空间和构图。

## 任务

1. `diagnosis.md`：列出坏草稿的问题（≥7 条），每条对应一个判据或案例（质量咒语、negative_prompt、多光源与具象灯具、无位置句、无构图句、尺寸与画幅、"epic cinematic"形容词、没有动作链起点、没有嵌入锚点句……）。
2. `keyframe-prompts.md`：按模板写 SHOT-004：元数据（`关键帧`、`尺寸`、`画面级目标`、`起始帧方位`、`动作链起点`、`锚点`、`seed 记录`）+ 一个 ```` ```text ```` 块，六行以 `[1 风格锁]` … `[6 差异/人群/禁用]` 起头、顺序固定、每行一句类型。要求：
   - 起始帧取动作链的**意图 / 预备相**（石神双拳高举，苏晓后撤半步、刀低垂），不是接触相（R-KF-14）；推近镜，起幅取**宽**的一端（R-KF-09）。
   - 每个人用 `On the LEFT` / `On the RIGHT` 开头，左右与分镜 `起始帧方位` 一致；三个资产的锚点句 EN 逐字嵌入。
   - 光只写**一句**，被动描述（光从哪来、色温、光比），并逐字带上本段命名色；不点灯具。
3. `poster-test.sh`：写出海报测试命令（缩到 270 宽 + 去色）和多 seed 并排命令（`hstack`），可参考 keyframe-freeze 步骤 6–7；不要求执行。
4. 在 `diagnosis.md` 末尾用一句话说明：若你用的是 2:3 的 1696×2528 出图，送 `first_frame` 之前必须怎么处理，为什么（写出裁切命令）。`keyframe-prompts.md` 里只出现 1536×2752。

## 自动判分

把下面的检查存为 `training/exercises/EX-09/check.py`，运行 `python3 training/exercises/EX-09/check.py`（标准库；退出码 0 = 全过）。脚本里没有对应的 `50-rubrics/scripts/` 检查器——关键帧的结构由此检查，画面本身由评审目视。

```python
import re, sys
D = "training/exercises/EX-09/"
t = open(D + "keyframe-prompts.md", encoding="utf-8").read()
a = open(D + "anchors.md", encoding="utf-8").read()
vb = open(D + "visual-bible.md", encoding="utf-8").read()
A = {}
for b in re.split(r"^## ANCHOR:\s*", a, flags=re.M)[1:]:
    m = re.search(r"锚点句 EN:\s*`([^`]+)`", b)
    if m:
        A[b.split("\n", 1)[0].strip()] = m.group(1)
style = re.search(r"风格锁句:\s*`([^`]+)`", vb).group(1)
colors = [c.strip() for c in re.search(r"本段命名色:\s*(.+)", vb).group(1).split(";")]
L, order = {}, []
for line in t.splitlines():
    m = re.match(r"\[(\d) [^\]]*\]\s*(.*)", line)
    if m:
        L[m.group(1)] = m.group(2)
        order.append(m.group(1))
ok = True
def chk(name, cond):
    global ok
    print(("PASS " if cond else "FAIL ") + name)
    ok = ok and bool(cond)
chk("六行标签齐全且顺序固定", order == list("123456"))
chk("尺寸 1536×2752 且无 1696/2528", re.search(r"尺寸:.*1536\s*[×xX]\s*2752", t) and not re.search(r"1696|2528", t))
chk("[1] 风格锁逐字", style in L.get("1", ""))
chk("[2] 以 Vertical 9:16 frame 开头", L.get("2", "").startswith("Vertical 9:16 frame"))
l3 = L.get("3", "")
i1, i2 = l3.find("On the LEFT"), l3.find("On the RIGHT")
chk("[3] LEFT 先 RIGHT 后", 0 <= i1 < i2)
chk("[3] 石神锚点句在 LEFT 段、苏晓锚点句在 RIGHT 段", i1 >= 0 and i2 > i1 and A["CHR-STONEGOD"] in l3[i1:i2] and A["CHR-SUXIAO"] in l3[i2:])
chk("[4] 逐字嵌入场景锚点句", A["LOC-RUINEDHALL"] in L.get("4", ""))
l5 = L.get("5", "")
chk("[5] 光只有一句（恰好一个句号）", l5.count(".") == 1)
chk("[5] 逐字含全部命名色且有光向 LEFT/RIGHT", all(c in l5 for c in colors) and re.search(r"\b(LEFT|RIGHT)\b", l5))
l6 = L.get("6", "")
chk("[6] 有差异化句", re.search(r"clearly (different|distinct)", l6))
nm = re.search(r"\bno\b", l6, re.I)
pm = re.search(r"smooth|bare|plain|unadorned", l6, re.I)
chk("[6] 正向状态句先于绝对否定句", nm and pm and pm.start() < nm.start())
chk("无质量咒语 / negative_prompt / 具象灯具", not re.search(r"masterpiece|best quality|\b[48]k\b|ultra[- ]?detailed|highly detailed|award[- ]winning|trending on|hyper[- ]?realistic|negative_prompt|flashlight|spotlight|torch|light beam|god rays|volumetric", t, re.I))
chk("无评价形容词 epic / cinematic / dramatic", not re.search(r"\b(epic|cinematic|dramatic|stunning|spectacular)\b", t, re.I))
p = open(D + "poster-test.sh", encoding="utf-8").read()
chk("poster-test.sh 含 scale=270、format=gray、hstack", "scale=270" in p and "format=gray" in p and "hstack" in p)
sys.exit(0 if ok else 1)
```

通过线：`check.py` 全 PASS。对"坏草稿"所有检查都应 FAIL（它没有六行结构），这正是本题的起点。

## 人工 / 评审判分点（满分 10，≥8 分才算通过）

- 构图句一句写清**机位高度、景别、主体占画比例与分区**（`low camera at knee height, wide shot; the stone god fills the LEFT two-thirds…`），能回答画面级目标"BOSS 压迫感"在图上看哪里取证（R-KF-08）。（2 分）
- 起始帧是意图 / 预备相而不是接触相；推近镜取宽端起幅（R-KF-09、R-KF-14）。（2 分）
- 光是**被动一句**：能在画面里指认主光源或由场景推断，没有 flashlight / spotlight / god rays；命名色逐字（R-KF-13、R-COL-02、R-COL-04）。（2 分）
- 禁用项先正向后否定：先写"石神胸口是裸露的裂纹花岗岩、光滑无装饰"，再对 C1 式会被自加的物件追加 `no armor`……（R1，R-VP-10 的同款思路）。（1 分）
- `diagnosis.md` 每条问题能对到判据 / 案例，且指出"质量咒语稀释锚点句权重、无可见内容"〔学院推断：同镜 3 seed 有 / 无咒语 A/B，若无差异即证实无用〕。（1 分）
- 画幅处理说清：`MiniMaxH3ImageToVideo` 的 `first_frame` 是 plain stretch，2:3 图送 9:16 画布会被横向挤压约 16%〔外部调研·S-H3-03；挤压比例为〔学院推断·待核〕〕；给出裁切命令 `ffmpeg -i kf-2x3.png -vf "crop=1422:2528:137:0,scale=1536:2752" keyframes/REF-SHOT004-START.png`（来自 keyframe-freeze 步骤 5）。（1 分）
- 关键帧上不要求出现任何文字（R-KF-12）。（1 分）
