# 冷观众测试协议

> 回答 G4〔委托方实证·F1〕：你一直用自己的标准验自己的产出。冷观众 = 唯一不共享你上下文的观察者，是 L1"看得懂"的核心证据（[`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md) §2）。
> **诚实声明**：委托方**从未做过**冷观众测试（GAP-2）；本协议的方法全部是〔外部调研〕（见 [`80-sources/catalog/ai-film-cases-audience-testing.md`](../80-sources/catalog/ai-film-cases-audience-testing.md)：S-CASE-13 边看边说、S-CASE-14 样本量、S-CASE-15 复述/完形理解阈值借用、S-CASE-19 试映），所有阈值是〔学院推断，待生产验证〕。**不得**把本协议写成"经验表明"。
> 可执行技能：[`20-craft/cold-audience-test/SKILL.md`](../20-craft/cold-audience-test/SKILL.md)；记录模板：[`70-playbooks/templates/cold-audience-sheet.md`](../70-playbooks/templates/cold-audience-sheet.md)；缺陷单模板：[`70-playbooks/templates/defect-ticket.md`](../70-playbooks/templates/defect-ticket.md)。

---

## 1. 前提与产出

- **前提**：L0 已过（`review/l0-report.json`）；自我放映已完成。冷观众不负责找穿帮细节，只回答"看得懂吗、想继续吗"。
- **产出**（每集）：`season-01/epNN/review/cold-audience/viewer-<nn>.md`（每人一份）+ `summary.md` + 缺陷单 `review/defects.md` 中的新增条目。
- **谁来组织**：做冷测的是制作 agent 的**主持角色**，但观看者与判定记录必须来自观众本人的原话，不得由制作 agent 代写或"润色"。

## 2. 招募（≥3 名冷观众）

| 规则 | 内容 | 来源 |
|---|---|---|
| 人数 | **≥3 人**是 L1 最低线；每轮 5 人更好；人数不足时**不得**把阈值按比例放宽，写"样本不足，L1 未验证" | 5 人约发现 85% 的可用性问题、3 人为最低线〔外部调研·S-CASE-14〕 |
| 冷 | 从未读过剧本、看过分镜/样片/板图，未参与任何制作讨论；**也不能是做过独立评审的人或会话** | 〔学院推断〕 |
| 目标观众 | 尽量贴近发布平台的目标观众（竖屏短剧的惯常观看者），而不是同行 | 〔学院推断〕 |
| 季内集 | 至少 1 人未看过前集（测"单集可读"，R-SEA-20）；追更观众另计一类，每类 3–4 人 | 〔外部调研·S-CASE-14〕 |
| 不复用 | 同一集修改后的复测，用**没看过旧版**的新观众；看过旧版的人只能当"断点是否消失"的辅助 | 〔学院推断〕 |

找不到人类 → 走 §7 的替身降级，并在交付声明里写明。属主是否愿意充当冷观众：属主若参与过剧本讨论即不算冷。

## 3. 设置（环境固定，写进每份记录的"观看方式"）

1. **设备**：手机竖屏全屏（或桌面 9:16 窗口），有声；观众自带耳机或外放均可，但记录是哪种。
2. **版本**：看**成片** `final/epNN.mp4`（与将发布版本一致，含字幕与片头标识），不看分镜、不看样片、不看抽帧。
3. **单次连续观看**：1× 速、**不暂停、不回看、不拖进度条**；观看前主持人只说一句："请像刷到一样看完，不用评价，看完我会问你几个问题。"——**不介绍**剧情、人物、题材、集数、制作方式（尤其不说"这是 AI 做的"，以免改变观看方式；是否告知放到访谈最后）。
4. **主持人全程沉默**：观看中不回答问题、不解释；观众的疑问本身就是断点证据。
5. **环境**：安静、无第三人旁观；一人一次，不让观众互相听到对方的复述（会互相污染）。

## 4. 记录流程（固定四步，顺序不可颠倒）

**步骤 A · 观看中：标记断点（不暂停）**
观众感到"没看懂 / 被拉出来 / 想划走 / 无聊"时，**说出"标记"二字**（不停播放，不解释）。主持人看播放时钟记下时间码（精确到秒）。用边看边说的做法时，主持人只在观众沉默过久时说"想到什么都可以说出来"，不引导方向〔外部调研·S-CASE-13：主持人的干预会改变观众行为〕。

**步骤 B · 看完立即：复述因果链**
问 Q1，**逐字记录**原话（录音转写优先）：
> 「用几句话讲讲刚才发生了什么？」

追问只用中性句：「还有吗？」「能多说一点吗？」**禁止**提角色名、道具名、因果（"他是为了救她吗？"）、也禁止纠正观众。

判定（对照制作方写好的本集主因果链：**谁想要什么 → 遇到什么阻碍 → 做了什么 → 结果如何**，四段齐全）：

| 判定 | 条件 |
|---|---|
| 正确 | 四段都对，人物与因果没搞错（不要求用词一致、不要求记住名字） |
| 部分 | 缺一段，或结果对但原因错位 |
| 错误 | 人物身份或因果关系搞错，或只能复述画面碎片 |

L1 计数**只认"正确"**；"部分"记录但不计入 2/3〔学院推断：保守口径〕。判定写在记录表的"复述判定"字段，附一句对照说明（缺的是哪一段）。

**步骤 C · 断点补全：看帧条指认**
复述记录完毕**之后**（防止污染复述），给观众一张带时间码的抽帧条（`python3 50-rubrics/scripts/contact_sheet.py final/epNN.mp4 --out-dir review/cold-audience/frames` 产出的接触表），问 Q2：
> 「刚才有没有哪里没看懂、被拉出来、或者想划走？大概是哪一段？」

观众指认的位置与步骤 A 的标记合并，每个断点记：`时间码 + 观众原话 + 类型（看不懂 / 出戏 / 无聊）`。

**步骤 D · 下一集意愿**
问 Q3：
> 「想不想看下一集？你最想知道的是什么？」

记"是/否"与原话。**具体问题**的判据：说出的问题指向本集里出现过的人物/事件/悬念（例"谁在门外""她为什么没杀他"）；"后面会怎么样""不知道"不算具体。可选加问一个类型识别题："前 3 秒你觉得这是什么类型的故事？"（用于发现开场类型误导〔外部调研·S-CASE-19〕）。

写入 [`cold-audience-sheet.md`](../70-playbooks/templates/cold-audience-sheet.md)：字段 = `观众编号 | 类型 | 背景 | 观看方式 | 复述原文 | 复述判定 | 断点 | 下一集问题 | 想看下一集`。

## 5. 判定阈值（来自 definition-of-done，〔学院推断，待生产验证〕）

| 级别 | 条件 | 备注 |
|---|---|---|
| **L1 看得懂** | ≥3 人中**≥2/3**复述"正确"；**且**没有任何一处断点被 ≥2 名观众同时标记 | "同一处"= 不同观众的标记时间码相差 ≤3s，或指认同一镜（3s 窗口为〔学院推断〕，可按首批数据调整） |
| **L3 想追** | ≥2/3 观众回答"想看下一集"**并**能说出具体问题 | 仅限人类冷观众；替身不得用于 L3 |

阻断：≥2/3 观众复述失败 = Q1 阻断缺陷（[`definition-of-done.md`](../50-rubrics/definition-of-done.md) §3，F1、A1），不得声明 L2 及以上。样本不足 / 只有替身 → 写"L1 未验证"或"替身测试，置信度降级"，**不得写"L1 通过"**。

汇总写 `summary.md`（模板末尾的汇总块）：人数与类型、复述正确率 k/n、断点聚类（时间码区间 → 人数 → 共同原话）、想看下一集 k/n、判定。

## 6. 断点 → 缺陷单（按病灶阶段路由）

规则：**每个 ≥2 人同标的断点簇开一张缺陷单**；只有 1 人标记的断点记为"观察"，同一位置在复测中再出现才升级。缺陷单按 [`defect-ticket.md`](../70-playbooks/templates/defect-ticket.md) 写，顶部"反馈原话"逐字放观众原话。**病灶阶段按下表（来自 [`00-orientation/production-lifecycle.md`](../00-orientation/production-lifecycle.md) §3）定，不由"我能在哪里最快补上"定**：

| 观众的断点/原话类型 | 病灶阶段 | 回到哪里修 | 禁止的补丁 |
|---|---|---|---|
| 复述不出因果、"片段式""跳来跳去""没懂为什么" | 分镜（段/拍结构）、剧本主因果链 | 重做段/拍结构；补因果环节 | 在剪辑里调转场、加字卡解释 〔A1、GAP-1〕 |
| "谁在哪""怎么又跑到那边""分不清谁打谁" | 分镜 + 起始帧 | 单轴定侧、重出起始帧 | 在视频提示词里堆方位词 〔A5〕 |
| "没看懂他们在打什么 / 谁赢了 / 为什么" | 动作设计 | 战术链与交手回合 | 在提示词里加 "epic fight" 〔A2、A3〕 |
| "没听清说了什么""话说一半没了" | 剧本/分镜（对白容量） | 核算容量、延长镜或删句 | 换 seed 〔D3〕 |
| "这人怎么变了""两个人长得一样""多了个东西/字" | 锚点卡/板图、关键帧、生成验收 | 链式参考、多 seed、放大验收 | 只换 seed 碰运气 〔B1、B3、C1、D1〕 |
| "无聊""拖""想划走"且无具体困惑 | 开发 + 剧本（钩子、节奏、首反转） | 重写钩子/信息密度；回 R-SCR | 加特效、加配乐 〔GAP-1、F1〕 |
| 没人想看下一集 / 说不出问题 | 开发 + 剧本（集末悬念） | 重写集末钩子 | 加"未完待续"字卡 〔GAP-1〕 |

处理后：回流修复 → 对**同一病灶的其他镜/集**做回归 → 用**新的**冷观众复测；判据是"上一轮断点不得在原位置复现"（[`SKILL.md`](../20-craft/cold-audience-test/SKILL.md)）。

## 7. 替身降级：无法招募人类时的 agent 替身

仅当找不到 ≥3 名人类冷观众时使用；产出的是**降级证据**，不是等价替代〔definition-of-done §2 L1〕。

1. **隔离**：每个替身 = 一个**全新会话**，未装载本集任何制作文档、未参与过任何评审；不给剧本、分镜、提示词、锚点卡、作者说明、缺陷单。最好换用与制作 agent 不同的模型，同模型的盲区高度相关〔学院推断〕。
2. **只给两样东西**：成片抽帧序列（`contact_sheet.py final/epNN.mp4 --out-dir review/cold-audience/frames`，按时间码排列）+ 按时间码对齐的字幕/转写文本。
3. **同一套问题**：Q1 复述、Q2 断点（"这里看不懂/不连贯/拖"并给时间码）、Q3 下一集意愿与具体问题；同样**逐字记录**，不润色。
4. **≥3 个独立替身会话**，各写一份 `viewer-<nn>.md`，"类型"字段写"替身（置信度降级）"。
5. **标注**：每份记录、`summary.md`、交付声明中均写 **"替身测试，置信度降级"**；判定最多写"L1（替身测试，置信度降级）"，不得用于 L3，不得单独支撑拍板点③的"看得懂"结论。
6. 替身看不到声音与表演细节（抽帧+文字），所以对"声音/情绪/节奏"类断点天然失明；报告里必须写"未覆盖：声音、运动质感"。

## 8. 校准回写

每次冷测结束，向 `training/cold-audience-calibration.md` 追加一行：`日期 | 集号 | 人数(人类/替身) | 复述正确率 | 同标断点数 | 想看下一集 | 人类主创随后的评价（逐字）| 阈值是否需要调整`。积累 ≥3 集后检查：冷测"通过"的集是否仍被人类主创说"看不懂"（阈值太松），或"不通过"的集人类主创觉得没问题（阈值太紧）。校准结论写回 [`50-rubrics/definition-of-done.md`](../50-rubrics/definition-of-done.md) 并改〔学院推断〕标注。发布后用平台留存曲线的 dip/spike 对齐剪辑时间码，校验断点预测〔外部调研·S-CASE-16〕。

## 9. 主持人逐字脚本（直接照读）

| 时机 | 只能说 |
|---|---|
| 开始前 | 「请像刷到一样看完，不用评价，看完我会问你几个问题。」 |
| 观看中（观众沉默过久且在边看边说模式） | 「想到什么都可以说出来。」 |
| Q1 | 「用几句话讲讲刚才发生了什么？」→ 追问只用「还有吗？」「能多说一点吗？」 |
| Q2（复述记录完之后，给抽帧条） | 「刚才有没有哪里没看懂、被拉出来、或者想划走？大概是哪一段？」 |
| Q3 | 「想不想看下一集？你最想知道的是什么？」 |
| 结束 | 「谢谢。」——告知是否 AI 制作放在最后，且不再追问。 |

禁止：提角色名/道具名/因果、纠正观众、替观众总结、"你有没有注意到……"、观看中答疑。

## → 行为改变

- 下次想声明 L1 时：先招 ≥3 名没见过任何制作材料的观众，单次连续观看，记原话；没有人类就走替身并写"替身测试，置信度降级"，不得省略这一标注。
- 下次看到"≥2 人同标的断点"时：先查 §6 的病灶阶段表再动手，禁止在剪辑里加字卡或换 seed 打补丁。
- 下次写"冷观众测试通过"时：附 `viewer-<nn>.md` 的路径与逐字原话；只有制作方转述 = 没做过。
